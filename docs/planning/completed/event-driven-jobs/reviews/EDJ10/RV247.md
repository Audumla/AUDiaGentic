# Prompt context builder is not integrated into direct launches

## Notes



## Findings

EDJ10 step 10 requires prompt_launch.py to integrate AgentJobPromptContext between parse/validation and render/build job record so all launch paths use the same injection path. Current launch_prompt_request/_build_job_from_request in src/audiagentic/components/agent_jobs/prompt_launch.py:274-301 and 165-219 never imports or calls build_prompt_context_from_request, never renders prompt-body/prompt-template-file with context, and never loads session input by session id. Direct CLI/MCP/API launches therefore bypass the new context layer entirely.

Additional schema gap: prompt-launch-request.schema.json still requires prompt-body and has no agent-profile-id, context, or prompt-template-file fields in both component and foundation copies, despite EDJ10 step 9 and EDJ11 step 1/6. This means the completed code cannot validate or accept the new direct-launch capabilities.

## Conclusion

Wire direct launch parsing through shared template source resolution, build_prompt_context_from_request, optional session_input_store loading, and dotted-path rendering. Update both prompt-launch-request schema copies byte-identically with context, agent-profile-id, and prompt-template-file oneOf/XOR constraints.
