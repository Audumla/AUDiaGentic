# Foundation module integration and workflow compatibility verification

## Notes



## Findings

1. **Missing touched file: foundation/__init__.py** — The plan adds `foundation/templates.py` as a new module but does not mention updating `foundation/__init__.py` exports. New foundation modules should be exported so consumers can import via `from audiagentic.foundation import ...` rather than deep paths.

2. **Missing impacted code: workflow.actions.render compatibility** — Step 1 says 'do NOT modify workflow.actions.render semantics' but does not verify whether existing callers of `render()` would inadvertently pick up the new dotted-path behavior if both modules are imported together. Add a validation test: run all existing workflow.actions consumers with the new templates.py present and confirm no behavioral change.

3. **Missing touched file: prompt_templates.py integration** — The files list includes `agent_jobs/prompt_templates.py` but the steps don't detail what changes there. Does this module currently do its own string replacement? If so, EDJ06 must refactor it to delegate to `foundation/templates.py`. Add an explicit step to audit existing template rendering in `prompt_templates.py`.

4. **Missing impacted component: Error code namespace** — The plan says 'Reject missing placeholders with AudiaGenticError' but does not assign a VAL-* code. Existing agent-jobs errors use codes in the VAL-AGJ range. Suggest reserving specific error codes for template rendering failures (e.g., VAL-TPL-001 for missing placeholder).

5. **Missing validation test: Hyphenated key round-trip** — The plan mentions 'hyphenated keys' support but does not clarify the access syntax. For `{metadata.correlation_id}` the dotted path works, but what about `{event.payload.trigger-id}`? Suggest specifying whether hyphens require bracket notation or are auto-converted.

6. **Missing touched file: foundation/templates.py error handling** — Should missing key errors include a list of available keys in the error message for debugging? This helps when templates reference stale context keys.

## Conclusion

Handled: foundation export, workflow render compatibility, prompt_templates delegation, VAL-TPL errors, hyphenated syntax, and diagnostics folded into EDJ06.
