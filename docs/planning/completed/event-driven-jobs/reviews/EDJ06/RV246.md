# Template rendering errors are swallowed into empty prompts

## Notes



## Findings

EDJ06 step 5 requires missing placeholders to raise AudiaGenticError with VAL-TPL-* diagnostics. src/audiagentic/foundation/templates.py does raise VAL-TPL-001, but event dispatch catches every render exception at src/audiagentic/components/agent_jobs/event_observer.py:310-318, logs a warning, and dispatches an empty prompt. That converts config/template defects into silent bad LLM jobs instead of failed firings/dead-letter records.

Standards impact: arch-standards §8 says AudiaGenticError at public boundary and async failures converted to durable dead-letter. This path suppresses the domain error and creates work with invalid instructions.

## Conclusion

Let render AudiaGenticError propagate to _on_trigger_match so EDJ12 dead-letter handling records the failed firing, or explicitly dead-letter and abort dispatch in the render block. Add a test where {missing.path} produces VAL-TPL-001 dead-letter and no gateway request.
