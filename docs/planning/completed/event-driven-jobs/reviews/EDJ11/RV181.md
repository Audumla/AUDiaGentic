# Path containment guards traversal and absolute paths but validation omits symlink/junction escape test

## Notes

This is a security guardrail that ships with the feature — not deferred. The step mentions 'symlink escape' but the validation section doesn't include it as a test case.

## Findings

EDJ11 step 3: 'Reject resolved paths that escape the project root (traversal / absolute / symlink escape) with AudiaGenticError.'

The validation section tests '../ escape' and 'absolute path outside root' but not symlink escape. An attacker (or misconfigured user) can place a symlink inside `.audiagentic/prompts/events/` that points outside the project root. Python's `os.path.join()` + string prefix check doesn't follow symlinks.

On Windows, NTFS junctions and symbolic links behave similarly. The workspace at H:\development\projects\AUDia\AUDiaGentic is on a Windows filesystem where symlink support varies by privilege level.

Recommended implementation:
1. Resolve with `pathlib.Path.resolve(strict=False)` (follows symlinks)
2. Check the resolved path is within project root using `.is_relative_to()`
3. Explicitly test symlink escape in validation (not just traversal)

## Conclusion

MUST-FIX: Path containment in step 3 blocks traversal but doesn't address symlink escape or Windows junctions. Use os.path.realpath() for final resolution check; add explicit symlink rejection test case.
