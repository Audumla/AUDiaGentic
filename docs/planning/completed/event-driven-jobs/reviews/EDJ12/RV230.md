# Shared append-only operational records needed before dead-letter/audit split

## Notes



## Findings

EDJ12 and EDJ14 both introduce append-only ndjson sidecar records (dead-letter and trigger audit). Current primitives are split between `foundation.observability.record_timeline_event` for timelines and `foundation.io.atomic_write_ndjson` for generic files; the latter rewrites the whole file on append and has no per-path lock. Without a shared helper/standard, EDJ12 and EDJ14 are likely to grow duplicate writer/redaction/locking logic.

Required correction: add or depend on a shared foundation helper for observable append-only sidecar records, then have dead-letter and trigger audit call it. Observability standard should distinguish timelines from operational sidecar records and require redaction/correlation fields consistently.

## Conclusion

Create a separate EDJ plan item for shared operational record helper + observability standard update; EDJ12/EDJ14 should depend on it or explicitly consume it.
