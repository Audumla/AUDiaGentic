# Dead-letter payload summaries are not redacted

## Notes



## Findings

EDJ12 and ARCHITECTURE_STANDARDS §14 require dead-letter entries to never contain raw prompts, API keys, tokens, or LLM outputs; payload_summary must be redacted. The failure path in src/audiagentic/components/agent_jobs/event_observer.py:203-215 writes payload_summary = str(payload)[:500]. That directly serializes inbound payload content into dead-letter.ndjson. src/audiagentic/components/agent_jobs/dead_letter.py:60-63 only truncates length, and append_operational_record only rejects top-level denylisted field names, so secrets inside payload_summary or metadata pass through.

Concrete failure: a malformed event payload containing {'prompt-body': '...', 'api_key': '...'} would be written as text in payload_summary despite the redaction boundary.

## Conclusion

Replace str(payload) with a redacted structural summarizer that drops denylisted keys recursively and emits bounded shape/counts, not raw values. Redact metadata too or whitelist allowed metadata keys. Add tests with prompt-body/token/api_key values proving they do not appear in dead-letter.ndjson.
