# Register agent-jobs observer through component lifecycle

## Notes



## Findings

src/audiagentic/config/components/agent-jobs.yaml has no lifecycle-observer entry, while EDJ02 step 1 requires idempotent registration through the component descriptor lifecycle-observer mechanism. src/audiagentic/components/agent_jobs/event_observer.py defines get_event_observer(), but nothing in the descriptor imports it during register_all_components(); compare providers.yaml/planning.yaml/agents.yaml. Result: configured triggers do not subscribe in normal component bootstrap, so EDJ02's core behavior is only reachable from tests or manual calls.

Standards impact: component-creation lifecycle observer mechanism not applied; feature is config-defined but not wired by component lifecycle.

## Conclusion

Add lifecycle-observer: audiagentic.components.agent_jobs.event_observer (or a small bootstrap module) and make import self-register/initialize using the established lifecycle pattern. Add a bootstrap test that register_all_components imports the observer and subscribes enabled triggers exactly once.
