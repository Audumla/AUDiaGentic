# Disabled trigger suppression audit cannot occur

## Notes



## Findings

EDJ02 step 6 requires a trigger-firing audit entry for every match, including suppressed(disabled), and validation requires disabled trigger records 'suppressed' audit entry and does not dispatch. src/audiagentic/components/agent_jobs/event_triggers.py:271-273 skips disabled triggers in the loader, so EventObserver never subscribes them and _on_trigger_match's disabled branch at event_observer.py:170-186 is unreachable for config-loaded triggers.

This makes the implementation internally contradictory: EDJ01 loader skip behavior was kept, but EDJ02's observable suppressed audit requirement was marked complete without a path that can produce it.

## Conclusion

Either retain disabled triggers in observer state and subscribe/audit suppression deliberately, or revise the spec before completion. Current completed implementation does not satisfy EDJ02 validation.
