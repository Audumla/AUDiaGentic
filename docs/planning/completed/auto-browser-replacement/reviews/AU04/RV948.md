# Remove speculative empty-response failure watchdog

## Notes



## Findings

Confirmed the sustained empty-response watchdog inferred failure solely from a 120-second absence of recognized activity. This could terminate legitimate long tool calls or reasoning pauses.

## Conclusion

Removed the watchdog implementation and configuration entirely. Empty or unrecognized response states remain non-terminal. Explicit DOM error/authentication signals, positive completion evidence, cancellation, and the 60-minute overall backstop remain the only terminal paths. Focused validation passed: 27 tests, Ruff clean, Pyright zero errors for production and live monitor scope.
