# Fix false completion and corrupted follow-up input in gpt-auto

## Description

Correct the live defect exposed after AU01: a timed-out response with zero events/null output was projected as completed, allowing same-session follow-ups while browser/composer state was unsafe and producing corrupted English prompt text.

## Steps

- Reproduce and trace turn, snapshot, transport, and Gateway completion semantics.
- Make response completion require positive assistant-output evidence and reject timeout/empty output.
- Make composer entry atomic and verify the exact prompt text before submission.
- Prevent follow-up turns until the prior provider turn is demonstrably idle.
- Add deterministic regression tests for corrupted input, empty timeout, and same-session sequencing.
- Run static/regression checks and a live three-turn SH10 review through a fresh Gateway process.
