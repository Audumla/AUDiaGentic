# Replace gpt-auto with shared workflow-based browser runtime

## Description

Implement the greenfield gpt-auto replacement defined by GPT_AUTO_GREENFIELD_E2E_IMPLEMENTATION_PLAN.md. Gateway owns durable sessions; one provider runtime owns browser/CDP; each Gateway session maps to one PersistentChat; each request uses an explicit no-double-submit turn workflow. The checked-in legacy implementation is guidance only and must be archived/removed after parity.
