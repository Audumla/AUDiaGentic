# Unify per-component path-resolution modules into a foundation helper

## Description

Standard 3 violation: planning_paths.py, ledger/paths.py, and agents_paths.py each re-implement the same _DEFAULT_PATHS + _load_paths + _resolve fallback pattern, and each with a different config source. Shared logic in 2+ files must move to foundation. Also standard 8: both _resolve implementations raise raw ValueError instead of AudiaGenticError.

DECIDED canonical config source (verified against the repo): both sources already exist as YAML — ledger declares a paths: block in its component config (config/components/agent-ledger.yaml), planning declares paths: in its implementation descriptor (config/components/planning/planning-local-docs.yaml). The foundation helper therefore resolves with a fixed precedence: (1) active implementation descriptor's paths: block via the features registry, if the component declares implementations; (2) the component config YAML's paths: block (.audiagentic/components/<component-id>.yaml); (3) caller-supplied defaults dict. This preserves both components' existing behavior without migrating either YAML layout.

## Steps

1. Create src/audiagentic/foundation/paths/component_paths.py with: resolve_component_path(project_root: Path, component_id: str, key: str, defaults: dict[str, str]) -> Path, plus load_component_paths(project_root, component_id, defaults) -> dict[str, str] implementing the decided precedence (implementation-descriptor paths → component-config paths → defaults). Export from foundation/paths/__init__.py.
2. Undefined key after all fallbacks → raise via make_error(prefix='VAL', component='PATHS', number=1, ...) (AudiaGenticError, code VAL-PATHS-001) — not ValueError. Grep callers of the current _resolve functions to confirm none catch ValueError specifically; fix any that do.
3. Rewrite planning_paths.py, ledger/paths.py, and agents_paths.py internals to call the helper, keeping every existing public accessor function (ledger_sync_dir, agent_profiles_path, etc.) with identical signatures and return values. Delete the three private _DEFAULT_PATHS/_load_paths/_resolve implementations in the same change (keep each component's defaults dict, passed to the helper).
4. Note _active_implementation_id resolution inside planning_paths.py: use the AR15 shared helper if it exists by then; otherwise keep planning's copy for now and leave AR15 to remove it (do NOT create a fourth copy in foundation/paths).
5. Run planning, ledger, and agents component tests.
