# Phase 1: Unify duplicate AgentContext dataclasses across pi and opencode harness runners

## Description

Standard 3 violation: runtime/harness/pi/runner/context.py and runtime/harness/opencode/runner/__init__.py define two AgentContext dataclasses with >80% field overlap (project_root, agent_work, agent_log_dir, endpoint, model, model_profile, profile_name, provider, rig_pid, manages_rig, enable_mcp, ...). Duplicate dataclasses must unify to one canonical type.

Codex review (RV66): context unification and shared-runner-helper extraction are distinct efforts with different risk profiles — split into two phases. This item (Phase 1) covers only the dataclass unification, since it is the foundation the Phase 2 shared helpers build on. See AR17 for Phase 2 (runner helper hoist).

## Steps

1. Create src/audiagentic/runtime/harness/context.py defining the canonical @dataclass AgentContext with the union of fields: project_root, agent_work, agent_log_dir, endpoint, model, model_profile, profile_name, provider, rig_pid, manages_rig, enable_mcp, server_version (default None), harness_cfg (default_factory=dict), and the pi-only fields as optional-with-None defaults: agent_runtime, agent_home, agent_dir, agent_bin (Path | None = None). Also move require_smoke_timeout here from pi/runner/context.py.
2. Delete the AgentContext definitions in runtime/harness/pi/runner/context.py and runtime/harness/opencode/runner/__init__.py; update both runners and all importers (rg 'AgentContext' src/ tests/) to the canonical class. pi code that requires the optional fields asserts them non-None at its construction site (it always sets them).
3. Verify no field-usage regression: rg every ctx.<field> access in both runner trees against the canonical field list.
4. Run both harness launch paths end-to-end including smoke mode (pi and opencode); run harness test suite.
5. STOP here — shared-helper extraction is AR17 (Phase 2), a separate change.

ACCEPTANCE: (a) rg 'class AgentContext' src/ returns exactly one definition (runtime/harness/context.py); (b) both harness launch paths pass including smoke mode; (c) no helper extraction bundled in (diff touches only context definition + imports).
