# Document providers API as approved platform seam

## Notes



## Findings

The standards need an explicit approved-cross-component-API rule. Providers is the current platform component exception: requesters and runtime orchestration may use providers_api, while provider internals remain forbidden. The rule must generalize to future platform components without permitting informal exceptions.

## Conclusion

Incorporated. Standards now define approved cross-component APIs as explicit platform seams, list providers_api with permitted callers and constraints, and permit runtime orchestration to use approved platform APIs.
