## Findings

The helper extraction is well-scoped, but step 2 still bundles two concerns: observer dedupe and event-vocabulary relocation. Because AR19 is actively moving lifecycle into foundation, moving constants now can create churn twice unless the destination package is frozen. Consider either making the constant move a required sub-step of AR19, or explicitly pinning the final destination path now with a no-reexport migration so AR13 does not guess at execution time. Acceptance should also assert zero remaining `COMPONENT_*` constant imports from the old lifecycle module path.
