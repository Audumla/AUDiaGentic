# Review AR18: force ownership decision for session paths before code move

## Notes



## Findings

Step 3 still allows an implementation-time decision on whether session path helpers belong to `agent_jobs` or `session`. That is the main architectural question in this item, so leaving it open risks a mid-refactor dependency reversal. Decide ownership before edits using one criterion: which component owns creation, retention, and cleanup of those files. Then make the move atomic to that owner. Also widen validation to prove `launcher.py` remains the only composition-root importer crossing both moved domains, preventing new cross-component bleed.

## Conclusion

Strong ownership-driven move; the session-path owner must be decided up front.
