# Finish component-ID constant migration — delete deprecated COMPONENT_* constants

## Description

Standards 5+10: foundation/components/ids.py keeps deprecated COMPONENT_* constants for optional components (agent-jobs, agent-ledger, providers, release, source-control, coding-lsp) that duplicate the IDs in the YAML descriptors — exactly the 'parallel Python constants' std 5 prohibits — and the module's own docstring calls them a transition shim, which the migration doctrine (std 10) forbids leaving behind. ~23 import sites remain. Core IDs (project, session) legitimately stay since they have no descriptor.

## Steps

1. Build the call-site taxonomy: rg -n 'components\.ids import|components.ids import' src/ tests/ and classify every site into exactly one of: (A) SELF-ID — a component referencing its own ID (e.g. coding_lsp importing COMPONENT_CODING_LSP) → replace with a module-level _COMPONENT_ID string constant local to that component (matching the existing pattern in memory_api/planning_api; the component's own ID in its own module is not a prohibited parallel list); (B) ENUMERATION — iterating/validating optional components → replace with get_optional_component_ids() or all_descriptors(); (C) METADATA LOOKUP — needing descriptor fields → all_descriptors()[cid]; (D) CORE — uses of COMPONENT_PROJECT/COMPONENT_SESSION → keep unchanged.
2. Record the taxonomy table (site → class → replacement) in the PR description.
3. Migrate all A/B/C sites in one change; delete the six deprecated optional-component constants (COMPONENT_AGENT_JOBS, COMPONENT_AGENT_LEDGER, COMPONENT_PROVIDERS, COMPONENT_RELEASE, COMPONENT_SOURCE_CONTROL, COMPONENT_CODING_LSP) from ids.py.
4. Rewrite the ids.py docstring: remove the deprecation/transition language; document that COMPONENT_PROJECT and COMPONENT_SESSION remain because they are core components with no YAML descriptor (the canonical-source exception), and that all other component IDs come from descriptors.
5. Guard against early-bootstrap ordering: any B/C site that can run before descriptors load must handle get_optional_component_ids() returning an empty frozenset — check each site's call timing during migration.
6. Full test suite.
