# Decompose lsp_api.py (917 lines): split utilities, session resolution, and table-drive thin ops

## Description

Standard 3 violation: lsp_api.py mixes at least four concerns — URI/position utilities and result normalization (parse_position, file_to_uri, normalize_*), project/language root resolution, session acquisition/PATH-refresh plumbing, and ~30 public op functions. Many ops (definition, hover, references, type_definition, implementation, ...) are near-identical three-line wrappers around _open_file_session + lsp_protocol_ops, differing only in method name — a (key, delegate) table or a generic dispatcher can collapse them while preserving the typed MCP-facing signatures in lsp_mcp.py.

## Steps

1. CONTRACT FREEZE: the 23 @mcp.tool functions in lsp_mcp.py are the public contract — their names, signatures, and return shapes must not change. List the lsp_api names lsp_mcp.py imports; that set must remain importable from lsp_api after the split.
2. Annotate every function in lsp_api.py as PUBLIC (in the step-1 list) or INTERNAL before moving code; record the map in the PR.
3. Consolidate normalization + URI/position helpers (parse_position, file_to_uri, uri_to_repo_relative, normalize_location/symbol/hover/workspace_edit) into the existing components/coding_lsp/uri_utils.py (check its current importers first: rg 'uri_utils' src/ tests/ — extend, don't rename existing functions).
4. Create components/coding_lsp/lsp_session_resolution.py: _open_file_session, _get_session_or_none, resolve_project_root, resolve_language_root, _walk_up_to_marker, discover_servers, discover_servers_multi, _resolve_language_servers_for_file, pick_capable, all_sessions_for_file, plus the PATH-refresh helpers (_refresh_path_after_install, _find_binary_after_install).
5. Collapse the trivial position-based ops (definition, hover, references, type_definition, implementation, signature_help, and similar 3-line delegates) through one generic dispatcher: _positional_op(method: str, file: str, position: str, **kwargs) with a module-level table mapping op-name → (protocol method, result normalizer). Ops with unique parameter shapes stay explicit functions: call_hierarchy, type_hierarchy, completion, code_actions, format_preview, organize_imports_preview, diagnostics, file_diagnostics, changed_diagnostics (note: file-list parameter), symbol_context, rename_preview, apply_workspace_edit, workspace_symbols, document_symbols, server_capabilities.
6. lsp_api.py remains the facade re-exporting the frozen step-1 set; run the LSP test suite.
