# Migrate agent_jobs/approvals.py onto foundation.interaction as a job-approval specialization

## Description

agent_jobs/approvals.py (components/agent_jobs/approvals.py) hand-rolls the exact pending/answered durable-request pattern FI01 generalizes into foundation.interaction, but hardcodes source_kind='job-service', binary approve/reject, its own file layout (.audiagentic/runtime/approvals/{id}.json), and its own schema (approval-request.schema.json). Once FI01 lands, this becomes the first real caller proving the generic primitive actually works for a caller other than itself, and stops being the only thing in the codebase capable of durable ask/answer.

## Steps
