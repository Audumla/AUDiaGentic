# Reconcile system-installed CLI resolution with managed installation

## Description

Reconcile system-installed CLI resolution with managed installation.

Pi runtime currently resolves the executable from PATH. Managed installation must ensure the installed binary becomes resolvable through the declared mechanism.
Avoid implying that 'system-installed' means 'outside AUDiaGentic management.'
Document where AG installs binaries, how PATH/probes find them, and how uninstall ownership is established.
