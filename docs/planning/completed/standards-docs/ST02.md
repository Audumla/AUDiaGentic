# Make installation claims consistent — AUDiaGentic may install harnesses

## Description

Make installation claims consistent.

AUDiaGentic can install and configure supported harnesses. "AUDiaGentic never installs harnesses" is incorrect.
The more precise rule:
- Harnesses may support managed installation
- Some harnesses may only support detection/configuration
- Capability declarations and recipes determine which lifecycle operations exist

Audit source comments, standards, Docker guidance, provider capability references, and old release text.

## Steps

["Audit all source comments for incorrect 'never installs' claims", "Update standards to say 'may support managed installation'", 'Fix Docker guidance to reflect correct installation model', 'Update provider capability references', 'Remove or update old release text with incorrect claims']
