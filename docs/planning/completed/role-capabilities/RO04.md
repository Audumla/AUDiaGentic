# Migrate from generic all-capabilities agents to explicit role presets and policy gates

## Description

Introduce approved role presets and migration tooling only after real job evidence identifies useful capability bundles. Replace generic all-or-nothing launches where safe, retain an explicitly named unrestricted compatibility role during a bounded transition, and add policy gates preventing silent capability escalation.

## Steps

1. Collect current job/workflow capability usage and derive candidate role presets from evidence. 2. Review and approve minimal presets such as reviewer, implementer, researcher, and operator where justified. 3. Add migration/status tooling that reports unresolved or excess capabilities before changing behavior. 4. Require explicit authorization for privileged capabilities and record safe audit/timeline facts. 5. Migrate selected workflows incrementally with rollback. 6. Remove the compatibility default once all consumers are explicit or document an approved external obligation.
