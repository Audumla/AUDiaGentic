# Wire EventLayerConfig into EventBus constructor and get_bus()

## Description

EventLayerConfig loads max_depth, correlation_tracking, and worker count from `.audiagentic/event/config.yaml`. EventBus.__init__() hardcodes `max_workers=4` and `max_depth=10`, ignoring loaded config. `get_bus()` has no config parameter.

**Affected files:**
- `src/audiagentic/foundation/event/event_bus.py:109-126` — hardcoded defaults
- `src/audiagentic/foundation/event/event_config.py` — config loader (unused by bus)
- `src/audiagentic/foundation/event/lifecycle_observer.py:73` — calls get_bus() without config

## Steps

['Add optional `EventLayerConfig` parameter to `EventBus.__init__()`\n- If provided, use config values for `max_depth`, async executor `max_workers`, and correlation tracking toggle\n- Default remains current hardcoded values when no config is passed', 'Update `get_bus(config=None)` to accept optional config parameter\n- Add double-checked locking with a module-level lock for thread safety (see EV16)\n- Store config reference on bus instance for potential hot-reload', 'Wire into `reset_bus()`: close old bus, create new with same or updated config\n- Ensure `_DISPATCHERS` in lifecycle_observer are re-subscribed to the new bus\n- Drain and clear `_DISPATCHERS` list before re-subscription to avoid duplicate subscriptions', 'Update callers that construct EventBus directly: pass loaded config from `load_event_config(root)`\n- Affected: tests/unit/foundation/event/test_bus.py, any component bootstrap that creates explicit EventBus instances']

## Files

['src/audiagentic/foundation/event/event_bus.py', 'src/audiagentic/foundation/event/event_config.py']

## Validation

1. `get_bus()` returns an EventBus whose internal config matches loaded values
2. When config file is missing, get_bus() raises AudiaGenticError (code: VAL-EVT-001)
3. Double-checked locking eliminates race condition under concurrent startup
4. reset_bus() closes old bus and re-subscribes lifecycle observers without duplicates
