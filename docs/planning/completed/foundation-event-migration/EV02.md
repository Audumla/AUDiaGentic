## Description

CORRECTED per review RV98/RV110 (2026-07-05): this is a direct relocation, not a lifecycle-event trigger -- the function is invoked as an explicit, user/CLI-initiated batch action (components/providers/services/reconcile.py's reconcile-all-providers path, itself reached from the 'reconcile providers' CLI prompt), not as a reaction to a lifecycle.component.* event.
