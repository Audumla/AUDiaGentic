# Add close(), wait_idle(), publish_envelope() to EventBusProtocol

## Description

EventBusProtocol defines only `publish()`, `subscribe()`, `unsubscribe()`. The concrete EventBus adds `close()`, `wait_idle()`, `publish_envelope()` that are not on the protocol. An external MQ implementation would not know shutdown semantics are expected.

**Affected files:**
- `src/audiagentic/foundation/event/event_bus.py:59-85` — incomplete abstract interface
- `src/audiagentic/foundation/event/event_bus.py:264-277` — missing methods

## Steps

['Add abstract `close()`, `wait_idle(timeout=None)`, `publish_envelope(envelope, mode=...)` to EventBusProtocol', 'Document that MQ implementations must implement graceful shutdown in `close()` and support envelope passthrough for `publish_envelope()`', 'Update `__init__.py` exports if needed (no new symbols required)']
