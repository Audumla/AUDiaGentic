# Valid but subsumed by EV07 (which lists the same double-checked locking); merge or make EV10 the prerequisite; validation empty

## Notes



## Findings

1. CORE CLAIM CONFIRMED: get_bus() has no lock (event_bus.py:292-295); concurrent first-callers can each construct an EventBus and one set of subscriptions is silently lost. reset_bus() also swaps the global without a lock.
2. OVERLAP: EV07 step 2 says 'Add double-checked locking with a module-level lock (see EV10)' — the two items implement the same lock on the same function. Either fold EV10 into EV07, or land EV10 first as the minimal P1 fix (it is simple and standalone) and strip the locking language from EV07.
3. GAP: Validation section is empty. Minimum: a concurrent-startup test (N threads call get_bus barrier-released; assert single instance identity and no lost subscription) and a reset_bus atomic-swap test.

## Conclusion

Recommend: land EV10's lock as part of the EV07 implementation (one change to the same lines), then mark EV10 completed alongside it — do not implement twice. Add the concurrency validation to whichever item carries the code.
