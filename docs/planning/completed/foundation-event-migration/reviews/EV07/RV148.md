# Still valid; two spec errors (worker count not in config, fail-fast conflicts with loader) and a stale EV16 ref

## Notes



## Findings

1. CORE CLAIM CONFIRMED: EventBus.__init__ hardcodes max_depth=10/max_workers=4 (event_bus.py:109-117); load_event_config exists but no caller wires it into the bus; get_bus() takes no config; reset_bus() (event_bus.py:298-307) drops the old bus WITHOUT close() — executor threads leak on every reset.
2. SPEC ERROR — worker count: the description says EventLayerConfig loads 'worker count'; it does not. EventLayerConfig (event_config.py:39-45) has event_store/cycle_detection(max_depth, correlation_tracking)/replay only — no worker setting. Wiring workers requires ADDING a config field (and config.yaml schema), which the item should state explicitly.
3. SPEC CONFLICT — fail-fast: validation #2 requires get_bus() to raise VAL-EVT-001 when the config file is missing, but load_event_config deliberately returns defaults on missing file (event_config.py:79-80) and on parse failure (77). Making get_bus fail-fast would break every context without .audiagentic/event/config.yaml (most tests, fresh projects). Decide one behavior: either defaults-on-missing stays (drop validation #2) or the loader changes project-wide (bigger scope, needs its own justification).
4. STALE REF: step 2 still says 'see EV16'; notes already corrected it to EV10 but the step text was not updated.
5. Correlation_tracking toggle exists in config but the bus has no such toggle at all — wiring it is new behavior (skip tracking when False), worth an explicit step + test.

## Conclusion

Keep the item (P1 justified by the reset_bus leak + dead config). Amend: remove the 'worker count' claim or add a config field step; resolve the fail-fast contradiction (recommend defaults-on-missing, drop validation #2); fix the EV16→EV10 step text; add explicit correlation_tracking-toggle step. Coordinate with EV10 (see RV on EV10 re subsumption).
