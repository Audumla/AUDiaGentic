# Introduce TypedDict payloads and generic handler types for type-safe subscriptions

## Description

Handler signature is `Callable[[str, dict[str, Any], dict[str, Any]], None]` — untyped payload and metadata dicts. Consumers that want type safety (like `subscribe_component_lifecycle`) must manually validate payloads inside the handler.

**Affected files:**
- `src/audiagentic/foundation/event/event_bus.py:79-80` — untyped Callable
- `src/audiagentic/foundation/event/lifecycle_observer.py:28` — manual payload validation
