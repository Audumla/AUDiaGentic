# Add thread-safe double-checked locking to get_bus() singleton

## Description

`get_bus()` uses a bare `if _bus_instance is None: _bus_instance = EventBus()` check without locking. If two threads call concurrently at startup (e.g., harness bootstrap + component observer init), two EventBus instances can be created, and the first one is silently discarded with its subscriptions lost.

**Affected files:**
- `src/audiagentic/foundation/event/event_bus.py:284-295` — no lock on singleton creation
