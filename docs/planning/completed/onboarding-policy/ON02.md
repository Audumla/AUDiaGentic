# Enforce reconciliation-policy in reconcile_provider and expose a setter

## Description

ON01 adds the `reconciliation-policy` schema/storage. This item wires it into the actual auto-enable decision in reconcile_provider (src/audiagentic/components/providers/services/reconcile.py:156) and exposes a way to change it without hand-editing YAML.

## Steps

1. In reconcile_provider, before the `cli_available and not currently_enabled` branch, consult get_reconciliation_policy(project_root):
   - mode=auto (default): unchanged behavior — enable whenever CLI is detected.
   - mode=allowlist: only auto-enable if provider_id is in allowed-providers; otherwise leave disabled and emit a progress note ('skipped — not in allowlist') instead of silently enabling.
   - mode=prompt: reconcile_provider itself does not prompt (that's interactive, handled by the next item) — it should behave like allowlist against whatever has already been decided, treating not-yet-decided providers as skipped.
2. Add a `providers_api.set_reconciliation_policy(project_root, mode, allowed_providers=None)` public entry point (mirrors the existing set_provider_enabled pattern) and a CLI subcommand (e.g. `audiagentic providers policy --mode allowlist --allow claude,codex,opencode,pi`) plus an MCP tool if the providers component already exposes an MCP surface for provider config.
3. Update components/providers/README.md with the CLI/MCP usage.
