# Bound gateway trace and request journal growth

## Description

Add configurable byte limits and safe compaction/rotation for durable gateway timelines, observation/recovery journals, and the global operator console trace. Preserve terminal diagnostics, active request safety, index consistency, and documented operator access.

## Steps

- Define configurable defaults sized for roughly 100 ordinary requests and environment overrides.
- Implement safe request-journal compaction with index rebuild under the existing mutation lock.
- Implement bounded console-trace rotation without disrupting the managed service.
- Add focused size/rotation/active-request tests and document retention/access behavior.

## Detailed Solution & Technical Design

Extend the machine-owned gateway retention policy with a default 100 resolved-history rolling limit and independent byte caps for timeline, observation, recovery, and console trace files. Compact indexed request journals under existing mutation locks, preserving newest rows and terminal evidence while atomically rebuilding byte indexes. Rotate the global console trace to one bounded .1 backup. Rolling retention never recursively deletes request directories and excludes active, unresolved, recovery-required, and pinned records.
