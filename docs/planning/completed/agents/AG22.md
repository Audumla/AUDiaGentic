# Inject admitted agent prompts and roles into gateway templates

## Description

Make agent definitions behavioral at gateway admission. Resolve an agent's prompt and roles, render/sanitize them against the frozen template context, persist an immutable instruction snapshot, and expose it to the provider execution template without replacing the caller's required task body.

## Steps

- Fix composition resolution: preserve agent-declared role order and include prompt-profile identity in definition/composition fingerprints.
- Materialize PromptDefinition text/includes/files once at admission from the same global snapshot, with include-cycle, path-containment, NUL, and size checks.
- Record the architectural standards ruling for bounded private configuration-owned instruction snapshots and prove they cannot enter public projections.
- Build and persist one closed immutable composition snapshot, including rendered instructions and all behavioural digests; direct-profile requests receive the stable empty snapshot.
- Bind the instructions digest and composition digest into the admitted runtime digest.
- Migrate legacy records on read to the canonical composition shape; new dispatch code reads composition only.
- Expose an admission-owned reserved {agent.*} namespace to provider templates; keep prompt_body separate and mandatory.
- Use the same admitted prompt renderer for stateless dispatch and gateway session/GPT-auto dispatch; neither path may reread agent configuration.
- Update global templates so an empty agent instruction block leaves direct-profile prompt output unchanged.
- Add role-order, profile-fingerprint, materialization, literal-brace, session-path, retry/recovery, private-projection, and no-post-admission-catalog-read tests.

## Detailed Solution & Technical Design

Resolve exactly one global agents catalog snapshot during gateway admission. Keep configuration resolution pure: it returns AgentDefinition, PromptDefinition, ordered Roles, ExecutionProfile, and identity from that one snapshot without reading prompt files or rendering text. A dedicated gateway admission module, `gateway/admission/instructions.py`, materializes included/file prompt content from the same snapshot under a confined global configuration root; combines the Agent Definition's declared role order and behavioral role output guidance; renders it against the frozen AG21 component context; applies final framing; and emits an immutable typed `AgentInstructionSnapshot`. Its SHA-256 is computed over the exact final persisted UTF-8 instruction bytes. Provenance fingerprints describe sources; instructions-digest proves the exact dispatched behavioural content. `AgentInstructionSnapshot.empty()` is the sole canonical direct-profile shape, avoiding duplicated empty dictionaries across API/store/tests. Before implementation, record the standards ruling that configuration-owned admitted instruction snapshots may be persisted only as bounded, sanitized, request-private authority and are excluded from public status, logs, timelines, and error projections; caller task prompts and provider conversation content remain prohibited. The store serializes that typed snapshot into the closed request-record composition object and folds composition/instruction digests into runtime identity. Record reading migrates older records to the canonical composition shape; dispatch code reads composition only and must not retain root-field-or-composition fallbacks. Dispatch reads no agent catalog after admission. A reserved agent namespace is built from the snapshot and wins over component/adapter context. Both queue dispatch and session dispatch must build the provider-facing admitted prompt through the same providers_api seam before invoking the provider/runtime. AG22's immutable authority applies to agent definition/prompt/role composition. The provider prompt-profile template retains AG16's existing digest-verified external authority until a separately scoped change snapshots template bytes at admission; AG22 must not claim otherwise. Prompt templates begin with {agent.instructions} immediately followed by their existing content, so the empty direct profile case retains current output. Preserve ordinary literal braces in behavioural content (especially JSON) while resolving recognised AG21 dotted placeholders; do not casually alter the shared renderer's semantics.
