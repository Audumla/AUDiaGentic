# Gateway request contracts and state store

## Description

Add minimal Agent LLM Gateway request/result contracts and persisted runtime state. V1 request contract uses prompt-body only because existing provider adapters consume packet_ctx['prompt-body']; messages support is deferred. Keep rollback simple: prefer a small gateway-local store over refactoring agent-jobs unless direct reuse is obvious and isolated.
