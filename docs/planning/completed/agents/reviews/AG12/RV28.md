AG12 design review — no implementation exists yet. Confirmed agents has no lifecycle-observer or lifecycle-hook in agents.yaml (current hooks are None). Foundation event bus is available via foundation.event.get_bus().

## Findings

INFO — AG12 is not implemented: no agents_gateway_events.py file exists anywhere in the codebase. The event bus infrastructure (foundation.event.event_bus) is solid and supports subscribe/publish/wait_idle patterns that AG12 needs.

MEDIUM — agents.yaml needs both status_hook AND lifecycle_hook entries for gateway support to be complete. Currently agents.yaml declares neither. AG12 must add a lifecycle_hook pointing to the observer module; AG13 (if implementing status) must add a status_hook returning ComponentStatusPayload.

NOTE — AG12's deferred subscription pattern from RV18 (register on first request instead of import time) is the safest approach given that agents_gateway_events.py will be imported by the component loading path which may not have initialized get_bus() yet.
