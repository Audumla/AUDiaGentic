# Gateway dispatch review — test failure and cancel-aware retry gaps

## Notes



## Findings

HIGH — tests/unit/agents/test_agents_gateway_dispatch.py:L50 fails because AudiaGenticError rejects unknown prefix ZZZ before classify_failure runs. Use a valid but unclassified prefix such as CFG/UNS if testing default behavior, or remove the assertion.

MEDIUM — src/audiagentic/components/agents/agents_gateway_dispatch.py:L153-L171 and L205-L215 retry/fallback loops do not check cancel_requested. AG09 says cancel should stop further retry/fallback attempts; add a persisted cancel_requested check before each attempt.

MEDIUM — src/audiagentic/components/agents/agents_gateway_dispatch.py:L220-L226 assumes last_error is not None. If candidates is empty or fallback list is malformed by future callers, this asserts instead of returning a domain error. Guard with AudiaGenticError terminal failure.

LOW — src/audiagentic/components/agents/agents_gateway_dispatch.py:L177 uses result.get('model') as attempt model-id, but final transition uses model-id=result.get('model'). If adapters return model-id instead of model, model visibility is lost. Normalize model from model, model-id, or profile model_id.

## Conclusion

Fixed. The ZZZ-prefix test failure was already resolved earlier in the same session (before this review ran) by replacing it with a full sweep of all 11 canonical ERROR_CODE_PREFIXES — confirmed still passing. Cancel-aware retry/fallback: added _raise_if_cancelled() checked at the top of each retry iteration in _try_profile_with_retries and before each fallback candidate in dispatch_request; on a persisted cancel-requested flag, dispatch stops immediately and transitions running->cancelled itself (ties into RV22's persisted-flag fix — dispatch has no access to the queue manager's in-memory state, so the persisted flag is the only channel this check can use). Added test_dispatch_stops_retrying_once_cancel_requested and test_dispatch_stops_before_fallback_once_cancel_requested. Replaced the bare 'assert last_exc/last_error is not None' with explicit AudiaGenticError (INT-AGW-001/002) guards — asserts are stripped under python -O and must never guard a reachable production path. Added _extract_model_id(result, profile) normalizing result.get('model') or result.get('model-id') or profile.get('model_id') so a differently-shaped adapter result doesn't silently lose model visibility; wired into both the attempt-record and the final completed-record model-id.
