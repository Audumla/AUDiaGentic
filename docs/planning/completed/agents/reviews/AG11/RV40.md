# Architecture standards: gateway MCP main should use shared server runner

## Notes



## Findings

MEDIUM: `src/audiagentic/components/agents/agents_gateway_mcp.py` correctly uses `mcp_server(__name__)`, but `main()` calls `mcp.run()` directly. `docs/standards/ARCHITECTURE_STANDARDS.md` requires MCP servers to use `run_mcp_server(server_factory, label)` for main/entrypoint bootstrap. Switch the gateway MCP entrypoint to the shared runner unless the standard has been superseded.

## Conclusion

Fixed, and expanded scope: the manual bootstrap+run duplication wasn't unique to the new agents_gateway_mcp.py — the two PRE-EXISTING sibling servers (agents_mcp.py, agents_manage_mcp.py) had the identical duplication already, predating this session's work. Fixing only the flagged file would have left the agents component internally inconsistent (2 old servers duplicating the pattern, 1 new one not), so all three main() functions now call run_mcp_server(mcp, label) per Standard 6.
