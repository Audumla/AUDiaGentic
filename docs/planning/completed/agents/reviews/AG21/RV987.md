# Suppress Windows consoles for source-control template context

## Notes



## Findings

AG21 source-control context launches git.exe three times per admission without Windows CREATE_NO_WINDOW. A background gateway can therefore visibly flash consoles. This is a small component-owned process-launch fix; empty in-process reader semantics are a separate future decision.

## Conclusion

Implement Windows-only CREATE_NO_WINDOW and unit coverage, then close the finding.
