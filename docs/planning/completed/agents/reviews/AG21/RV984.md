# Validate foundation context seam and ownership boundaries

## Notes



## Findings

Existing agent_jobs/prompt_context.py is legacy and job/event-specific; it must not be extended. The current gateway renderer accepts only packet context. Generic component collection can live in foundation/components without importing gateway, providers, agent_jobs, planning, or source-control implementations. Gateway may consume the finished mapping only at its prompt-build boundary. Existing renderer supports single-brace dotted paths, not Jinja syntax.

## Conclusion

Valid with a narrow one-way seam: descriptor -> foundation collector -> immutable plain mapping -> gateway packet -> renderer. Component hooks own facts; foundation owns discovery/namespacing/sanitization; gateway and providers must not discover components.
