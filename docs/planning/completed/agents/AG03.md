# Profile config file in .audiagentic folder

## Description

Agent profiles are stored in a project-scoped YAML config file. This keeps configuration out of core code and allows per-project customization.

## Config file location

`.audiagentic/config/agent-profiles.yaml` — declared in the component descriptor as `lifecycle: create-if-missing` so it's written once at install and never overwritten.

## YAML file format

```yaml
# Agent profiles — maps a named profile to a provider + model + execution parameters
# Edit this file to add, modify, or remove agent profiles for this project.
contract-version: v1
profiles:
  - profile-id: default
    provider-id: opencode
    model-id: gpt-4o
    display-name: "Default agent"
    params:
      max_concurrency: 1
      temperature: 0.1

  - profile-id: fast-coder
    provider-id: opencode
    model-id: o3-mini
    display-name: "Fast coder"
    params:
      max_concurrency: 2
      temperature: 0.0
      structured_output: true

  - profile-id: deep-review
    provider-id: claude
    model-id: claude-sonnet-4-20250514
    display-name: "Deep reviewer"
    params:
      max_concurrency: 1
      temperature: 0.1
```

## Top-level schema

| Key | Type | Required | Description |
|---|---|---|---|
| `contract-version` | string | yes | Schema version, currently `v1` |
| `profiles` | list | yes | List of profile objects |

## Profile object schema (within `profiles` list)

| Key | Type | Required | Description |
|---|---|---|---|
| `profile-id` | string | yes | Unique identifier, kebab-case |
| `provider-id` | string | yes | Registered provider id |
| `model-id` | string | yes | Provider-specific model id |
| `display-name` | string | no | Human-readable label |
| `params` | object | no | Execution parameters dict |

## Seed template

On first install, the file is created with a single `default` profile using `opencode` provider and `gpt-4o` model. This gives the project a working starting point.

## Loading behavior

- File exists and valid: return populated `AgentProfilesStore`
- File exists but invalid: raise `AudiaGenticError` with `IO-AGP-001` (parse error) or `VAL-AGP-010` (validation error), including file path and line-level details
- File does not exist: return empty `AgentProfilesStore` (profiles not yet configured)
