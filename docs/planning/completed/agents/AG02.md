# Agent profile data model and schema

## Description

Define the Python data structures for an agent profile. A profile is a named configuration that binds a provider to a specific model, with optional execution parameters.

## Steps

['Create `src/audiagentic/components/agents/models.py` with `AgentProfile` dataclass and `AgentProfilesStore`', 'Implement `validate_profile(profile: dict) -> list[str]` using the rules above', 'Implement `profile_from_dict(data: dict) -> AgentProfile` constructor with validation', 'Implement `profile_to_dict(profile: AgentProfile) -> dict` serializer for YAML round-trip', 'Implement `AgentProfilesStore` with get, list_all, add, remove methods']
