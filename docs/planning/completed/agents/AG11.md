# Gateway direct API and MCP tools

## Description

Expose Agent LLM Gateway through pure Python API and audiagentic-scoped MCP tools. Async submit returns request-id immediately; blocking run waits for terminal result or timeout. Gateway tools do not propagate to providers in v1.

## Steps

Keep these read-only and derived from in-memory queue plus persisted records.', 'submit_llm_request returns request-id plus initial state.', 'run_llm_request calls submit then wait with timeout and returns terminal result or timeout status.', 'Timeout returns timeout status and does not cancel worker. Worker may still later complete and terminal state wins.', 'Define MCP blocking cap with a simple constant/default option, e.g. 300 seconds.
