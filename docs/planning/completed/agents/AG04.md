# Profile API — CRUD operations

## Description

Pure-logic API module for agent profile CRUD. No MCP coupling — used by both the MCP server and any programmatic consumers (e.g., agent-jobs launch).

## API surface

```python
# agents_api.py

def list_profiles(project_root: Path) -> list[dict]:
    """Return all profiles as dicts (serialized for MCP/tool consumption)."""
    store = load_profiles(project_root)
    return [profile_to_dict(p) for p in store.list_all()]

def get_profile(project_root: Path, profile_id: str) -> dict:
    """Return a single profile by ID. Raises if not found."""
    store = load_profiles(project_root)
    profile = store.get(profile_id)
    return profile_to_dict(profile)

def create_profile(project_root: Path, profile_data: dict) -> dict:
    """Create a new profile. Validates uniqueness, writes to config file."""
    profile = profile_from_dict(profile_data)  # validates shape + provider
    store = load_profiles(project_root)
    if profile.profile_id in store.profiles:
        raise AudiaGenticError(
            code="VAL-AGP-005",
            kind="agents",
            message="duplicate profile_id",
            details={"profile-id": profile.profile_id},
        )
    store.add(profile)
    save_profiles(project_root, store)
    return profile_to_dict(profile)

def update_profile(project_root: Path, profile_id: str, updates: dict) -> dict:
    """Merge updates into an existing profile. Only provided keys are changed."""
    store = load_profiles(project_root)
    existing = store.get(profile_id)  # raises if not found
    merged_data = {**profile_to_dict(existing), **updates}
    if "profile-id" in updates and updates["profile-id"] != profile_id:
        raise AudiaGenticError(
            code="CON-AGP-001",
            kind="agents",
            message="profile_id cannot be changed via update",
            details={"current": profile_id, "requested": updates["profile-id"]},
        )
    merged = profile_from_dict(merged_data)
    store.remove(profile_id)
    store.add(merged)
    save_profiles(project_root, store)
    return profile_to_dict(merged)

def delete_profile(project_root: Path, profile_id: str) -> dict:
    """Remove a profile. Returns the deleted profile."""
    store = load_profiles(project_root)
    profile = store.get(profile_id)  # raises if not found
    store.remove(profile_id)
    save_profiles(project_root, store)
    return profile_to_dict(profile)

def resolve_profile(project_root: Path, profile_id: str) -> AgentProfile:
    """Resolve a profile by ID. Returns the AgentProfile dataclass (not dict).
    Used by agent-jobs to look up provider + model for execution."""
    store = load_profiles(project_root)
    return store.get(profile_id)
```

## Error handling

- Profile not found: `AudiaGenticError` with code `RES-AGP-001` ("unknown profile: {profile_id}")
- Duplicate on create: `VAL-AGP-005`
- Provider not registered: `VAL-AGP-004`
- Invalid profile data: `VAL-AGP-001` through `VAL-AGP-006` from models.py
- File I/O errors: `IO-AGP-001` (read), `IO-AGP-002` (write)

## Design notes

- All operations load the full config file, mutate in memory, and write back. For the expected profile count (<50), this is acceptable.
- `profile_id` cannot be changed via update — delete and create instead.
- `params` merge is shallow: providing `params` in updates replaces the entire params dict (not deep merge).
