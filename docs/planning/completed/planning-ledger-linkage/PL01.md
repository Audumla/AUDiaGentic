# Add plan-item-ids instruction to ledger contribution

## Description

Update ledger component's agent instruction content in `src/audiagentic/config/components/agent-ledger.yaml` under the contributions block.

Add a directive to the existing "Agent ledger process" section explaining that when recording change events for work tied to plan items, agents should include `plan-item-ids` in the event dict — linkage is automatic via event-driven subscription.

Example text to add (after existing ledger process instructions):
```
When recording a change event for work associated with one or more plan items,
include "plan-item-ids" in the event dict (e.g. {"plan-item-ids": ["CC07", "CC08"]}).
The planning component will automatically link the ledger event ID to those items.
```

This instruction appears only when ledger is enabled — natural conditional behavior, zero planning-side awareness needed.

**Depends on PL04** (event-driven linkage must exist before exposing the `plan-item-ids` parameter in instructions).
