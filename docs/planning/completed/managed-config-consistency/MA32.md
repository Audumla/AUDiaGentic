# Create user-verb-to-internal-mode translator for CLI and MCP command parsing

## Description

Create a tiny provider-blind translator for user-facing lifecycle verbs and semantic automation modes. Current code has a local `mode_map` in `src/audiagentic/commands/provider_prompt.py` mapping natural prompt verbs (`install`, `uninstall`, `repair`) to provider CLI lifecycle modes (`apply`, `prune`). `src/audiagentic/components/providers/providers_mcp.py` accepts a raw `mode: str` and casts it to `CliLifecycleMode` without shared validation. This item should centralize the mapping/validation without introducing a dispatcher or provider-specific behavior.
