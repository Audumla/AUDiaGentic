# Expose provider execution and enforce component boundaries

## Description

Remove current agents/agent_jobs imports of provider internals by routing proven provider queries, one-shot execution, and ACP launch declaration through the sanctioned providers_api. Agents remains sole owner of queue, retry, cancellation, persistent session runtime, and timelines.

## Steps

1. Freeze only proven public operations: provider query/config resolution, one-shot provider turn, and ACP launch declaration. 2. One-shot execution receives canonical project root, provider/model selection, provider-neutral runtime packet data, live gateway worker_id and attempt_epoch, and provider_isolation_tier. 3. Implement the public seam together with SH06, then migrate every agents and agent_jobs provider-internal import atomically and delete direct monkeypatch routes. 4. Keep AcpSessionTransport creation, persistence, turn serialization, retry, cancellation, and timelines agents-owned. 5. Add execution seam, import-boundary, serialization, and worker-process tests; no recipes or foundation provider facade.

## Files

[COMPONENT:providers public] execution invocation function plus semantic operation functions
[COMPONENT:providers internal] provider config/model resolution/execution adapters/registrations
[COMPONENT:agents] profile resolution, packet construction, retry/fallback/cancel/timeline only
[TEST] execution seam goldens, monkeypatch migration, import graph, events
[FORBIDDEN] agents imports of providers.services, foundation capability ports, catalog dispatch, public recipe methods

## Validation

Validated 2026-07-18: agents and agent_jobs have zero imports of providers.services, providers.descriptors, or providers.contracts; providers have zero agent_jobs imports. Typed providers_api exposes provider runtime/tier reads, one-shot turn, ACP launch preparation, and narrow prompt operations. Persistent session transport remains agents-owned. Docker focused boundary suite, clean-image architecture gate, and 65 host/49 mounted Docker migration tests pass.

## Effort & Risk

Mid. Do not remove provider integration merely for graph purity. Refactor only foreign-domain leakage and event coupling; preserve provider-specific adaptation where it is real.
