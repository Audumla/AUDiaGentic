# Migrate self-provided LSP support recipe family

## Description

Final MA08 slice. Replace self-provided LSP support provisioning with a bounded MA20-conformant family exposing only modes current callers require.

## Steps

1. Characterize the current support path and prove current modes/results.
2. Freeze minimal payload/result and supported mode subset.
3. Implement explicit definition/registration and provider adapter.
4. Migrate caller/tests.
5. Delete action-string dispatch and stale support entry points.
6. Run full Coding-LSP/provider boundary audit.

[PROVIDERS] one family definition/registration/adapter
