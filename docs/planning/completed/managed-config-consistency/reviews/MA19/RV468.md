# Lock capability-fact catalogue and MA20 boundary

## Notes



## Findings

MA19 correctly separates evidence facts from operational fields, but it does not explicitly state the required evidence catalogue or distinguish open fact identifiers from MA20's explicit executable capability declarations.

## Conclusion

Specify MA19's required fact subjects, use open stable fact ids validated against declared descriptor subjects or external facts, retain one reusable typed fact/evidence shape, and prohibit free-form capability definitions. MA20 alone enumerates executable automation capabilities.
