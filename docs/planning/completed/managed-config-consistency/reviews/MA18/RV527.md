# Bounded delivery is now a rolling FIFO window: budgets evict oldest, retain the tail

## Notes

Owner-requested refinement of RV520. Same budgets (MAX_EVENTS 10k / 8MiB / 64KiB per event), same drop accounting — but retention flips from keep-first/drop-newest to EVICT-OLDEST/keep-newest.

## Findings

1. Rationale: the tail is what matters — it carries the final report and the liveness signal the overseer's wedge detection scores (recent-suffix analysis in the agent-overseer research baseline); the head is spawn/setup noise. Memory bound identical. 2. Evicted assistant-message text is banked into the existing bounded overflow buffer (RV520), which with FIFO is always OLDER than retained events — gateway output assembly = overflow + retained, so full report text is preserved end to end. 3. Sequence numbers switched from list-length to an arrival counter, preserving the frozen 'strictly increasing per run' guarantee across evictions (retained events keep their original sequence; gaps mark evictions). 4. bytes_buffered now reports the retained window's bytes (per-event sizes released on eviction). 5. A single event exceeding the entire byte budget degrades to header-only ext rather than being dropped. 6. All pre-existing frozen-contract tests pass UNMODIFIED (caps, drop counts, terminal retention); new tests pin tail retention, overflow banking of the head, and monotonic sequences.

## Conclusion

Implemented with tests; transports + agents suites green. Closing as incorporated.
