# Replace deprecated Codex hook feature flag with current hooks flag

## Notes

A live Codex startup warning traced to the managed-hooks adapter output and the installed Hindsight/Codex configuration.

## Findings

The provider adapter still writes [features].codex_hooks = true to ~/.codex/config.toml. Current Codex reports this key deprecated and requires [features].hooks instead. The same stale contract is asserted in tests and recorded in implementation references. Existing user config was generated with the deprecated key.

## Conclusion

Implemented and validated. The Codex managed-hooks adapter now writes features.hooks, removes the deprecated owned codex_hooks key, preserves unrelated settings, and passes isolated host and clean Docker mutation tests. The installed user config was migrated in place.
