# Codex Hindsight scripts are downloaded outside the path used by hook commands

## Notes

Found during sponsor-requested revalidation of MA06's remaining artifact ownership and safety scope.

## Findings

_build_codex_desired emits hook commands under ~/.hindsight/codex/scripts/, but _download_codex_scripts removes the scripts/ prefix and writes under ~/.hindsight/codex/. The only two remaining raw component writes are these downloaded UTF-8 scripts/settings and are non-atomic.

## Conclusion

Valid bounded MA06 correction. Preserve the upstream relative path, decode the known text assets as UTF-8, and reuse foundation atomic_write_text. Add a focused fake-response test for exact destinations, content, and the existing do-not-overwrite settings rule. Do not add a binary foundation primitive for this single text-only consumer.
