## Findings

Full command: `docker build -f tests/docker/Dockerfile.packaging -t audia-packaging .` passed; `docker run --rm audia-packaging` failed.
1. `tests/docker/run_packaging.sh` contains CRLF, causing `set: pipefail\r`, `else\r`, arithmetic and exit failures. Normalize LF and enforce via repository attributes/test.
2. Installed wheel import/public CLI fail CFG-PATHS-001 when AUDIAGENTIC_REPO_ROOT is absent. `foundation.paths.package.find_repo_root()` assumes source checkout. Packaged runtime must resolve installed resources without fake repo root; do not weaken project-root semantics or rely on /app.
3. `ag-agents-gateway` server smoke fails because `components/agents/workflows.yaml` is absent from wheel. Add correct package-data inclusion and a wheel-content/startup test; do not special-case server.
4. Downloaded Linux llama-server fails version probe due missing libgomp.so.1. Packaging image must install runtime shared dependency or install path must diagnose dependency. For this Docker gate, add minimal runtime package; retain actionable production diagnostics.
5. Existing script continues after failures by design; preserve aggregate reporting. Fix only MA15 packaging/startup scope. Rebuild image and rerun entire container; complete only with all checks green.
