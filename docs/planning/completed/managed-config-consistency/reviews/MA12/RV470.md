# Freeze CLI migration decisions and registry composition

## Notes



## Findings

MA12 assessment proposed public dry_run/project_root fields, raw probe/result dictionaries, and an unresolved registry singleton. These conflict with locked semantic modes, typed payloads, and requester-safe result contracts.

## Conclusion

Use mode plan instead of dry_run; project root is invocation context captured by internal composition, not serialized payload. Remove public repair and legacy tool names without shims. Keep reconcile under MA22. Compose registry in a dedicated internal factory, not providers_api or recipe_definitions.
