# Keep Hindsight plugin recipes requester-owned

## Notes



## Findings

MA25 assigns Hindsight-specific plugin package ids, URL shape, commands, and repair logic to providers. This violates the locked requester-ownership boundary established in MA23/MA24. Providers may own only generic config adapters and capabilities; Hindsight must own its plugin recipe semantics and typed desired config.

## Conclusion

Revise MA25 before implementation: Hindsight parses typed Claude/OpenCode plugin definitions and invokes generic provider config capabilities only for provider-owned config serialization. No provider-plugin family or provider-side Hindsight handler.
