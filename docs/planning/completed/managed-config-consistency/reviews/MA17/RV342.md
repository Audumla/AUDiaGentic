# Gateway must resolve declared provider capabilities not ad hoc handler names

## Notes



## Findings

An extensible provider capability catalog only prevents direct provider coupling if MA17 gateway discovers and validates requested operations against that declaration. Otherwise components will still encode provider-specific knowledge or call arbitrary handlers.

## Conclusion

MA17 gateway must resolve neutral capability + operation through provider declaration, return declared agent-facing manifestation/constraints, and reject undeclared capability requests. Provider handler bindings remain provider-owned implementation detail.
