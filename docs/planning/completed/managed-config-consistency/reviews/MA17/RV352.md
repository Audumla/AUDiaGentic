# Keep gateway transport-neutral and separate ACP from MCP

## Notes



## Findings

MA17 gateway boundaries need explicit distinction between provider capability mutation gateway and existing agent execution gateway. ACP is provider execution transport behind a neutral port; MCP is caller exposure. Provider MCP must not call back into agent gateway. Gateway must consume canonical events without ACP/provider branches; cursor polling baseline and progress notifications optional.
