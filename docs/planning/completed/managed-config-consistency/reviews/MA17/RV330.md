# Allow provider integration dependencies; isolate only foreign domain policy

## Notes



## Findings

RV327 treated provider→coding-LSP and provider↔agent-jobs implementation dependencies as inherently forbidden. User clarified these are valid provider integration boundaries: other components may import/use provider information when managing providers; providers may implement provider-specific LSP and job behavior. Runtime migration is deferred. The real prohibition is foreign removable-domain policy/vocabulary leaking into a component, especially Hindsight into providers, plus raw managed writes.

## Conclusion

Revise MA17 to permit documented provider integration ports and focus it on dependency classification, generic reusable events, and eliminating forbidden domain leakage. Keep generic release→ledger event decoupling. Remove MA03/MA07 as MA09 completion prerequisites while retaining them as deferred work.
