# Remove providers-to-agent_jobs reverse boundary imports

## Notes

Docker architecture validation of the MA17 migration exposed existing provider adapter and surface modules importing agent_jobs prompt internals.

## Findings

providers adapters/claude/hooks.py, adapters/gemini/adapter.py and skill_surfaces.py import agent_jobs prompt_launch/parser/prompt_syntax. This violates requester-blind providers and architecture dependency boundaries; it blocks the MA17 import-boundary gate.

## Conclusion

Valid. Move the provider-owned prompt/tag interpretation needed by those adapter/surface paths behind a providers-owned semantic module or pass requester data through the public seam. Do not create a generic foundation facade.
