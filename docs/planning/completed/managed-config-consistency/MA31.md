# Normalize provider query and catalog resource APIs

## Description

Implement the frozen MA16 query/resource classification. Keep queries mutation-free, keep catalog refresh as an explicit AUDiaGentic-owned resource command, and ensure neither category uses RecipeDefinition or automation modes.

## Steps

1. Characterize providers MCP and test callers for list_providers, get_provider_status, list_provider_descriptors, describe_provider, model_source_list, list_provider_models, refresh_provider_catalog, and refresh_all_catalogs.
2. Keep list_providers, get_provider_status, list_provider_descriptors, describe_provider, model_source_list, and list_provider_models as queries with no durable mutation.
3. Remove refresh from list_provider_models; migrate callers to call refresh_provider_catalog explicitly before reading when refresh is intended. Delete the boolean flag and compatibility tests.
4. Keep refresh_provider_catalog and refresh_all_catalogs as catalog resource commands. They may perform provider-specific remote reads and write only AUDiaGentic-owned catalog cache; they do not use plan/apply/prune/status or RecipeDefinition.
5. Preserve bounded timeout, safe cached-read behavior, canonical errors, and redaction. Do not classify a provider-specific read as automation merely because it uses a provider adapter.
6. Add query non-mutation tests, cache-only mutation tests, MCP caller tests, export classification guards, and stale refresh-flag search.

## Files

[PUBLIC] providers_api query/catalog functions
[CALLER] providers_mcp.py
[INTERNAL] catalog fetch/cache services only as required
[TEST] query non-mutation, catalog cache mutation, caller and stale-flag guards

## Validation

1. Six queries are durable-mutation-free. 2. list_provider_models has no refresh flag or hidden remote write. 3. Two refresh commands mutate only AUDiaGentic catalog cache and may perform remote reads. 4. No query/resource command uses RecipeDefinition or automation modes. 5. MCP callers and tests use explicit refresh then read. 6. Errors/details are redacted and focused tests pass.

## Effort & Risk

Strong mid-level, bounded. Classification is frozen. Escalate only if a current caller requires an atomic refresh+read contract that cannot be expressed by explicit sequencing.
