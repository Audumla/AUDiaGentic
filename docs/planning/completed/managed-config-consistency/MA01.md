# Define managed mutation doctrine and guardrails

## Description

Define one decision tree for every durable mutation so generic foundation/component machinery owns lifecycle and only format-specific adapters remain custom. Add enforceable architecture tests and classify current exceptions.

## Steps

1. Add Architecture Standards section 'Managed mutation ownership' with exact taxonomy: (a) named entries in shared external config → ManagedConfigSpec + sync_managed_config + ManagedFragmentRegistry; (b) nested keys in shared structured config → ConfigPatcher + ArtifactRegistry; (c) whole recipe-owned file → WriteFileStep + ArtifactRegistry; (d) generated component/provider surface → descriptor virtual asset or registered surface renderer/managed block; (e) domain durable records → owning component store + atomic foundation IO; (f) third-party unowned repair → adapter-local explicit exemption.
2. State generic orchestration owns path resolution, ownership, collision handling, dry-run, apply/prune, reload, status, error normalization, redaction, and observability. Custom adapter owns parse/render/merge semantics only.
3. Inventory production writes under src/audiagentic and classify each into taxonomy. Store machine-checkable table with path:symbol, category, generic primitive, action, exemption rationale.
4. Exemption requires all: one external format/provider, unowned third-party artifact, no generic primitive fits, bounded function, redaction/atomicity tests, comment referencing audit item. 'Brace placeholders' and 'surgical edit' are not exemptions because ConfigPatcher accepts values without template substitution.
5. Add AST/grep architecture tests: no direct ManagedConfigSpec.writer/remover outside generic core; no provider-id branches in generic recipe builders; no component payload-type imports in generic specs; no duplicate ownership registry implementations; direct shared-config write sites must be allowlisted with item/rationale.
6. Cross-reference component creation guide with the decision tree and adapter extension contract.
