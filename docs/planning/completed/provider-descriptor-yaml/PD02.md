# Implement provider descriptor YAML loader

## Description

Implement the consolidated mechanism designed in PD01. Foundation layer only — no imports from components/runtime.

## resolver.py
```
def resolve_ref(ref: str) -> Any:
    if ':' not in ref: raise _err(1, f'ref must be module:attr, got {ref!r}')
    mod, _, attr = ref.partition(':')
    obj = importlib.import_module(mod)
    for part in attr.split('.'):  # support nested attrs
        obj = getattr(obj, part)
    return obj
```
Error factory make_error_factory('VAL','DESC','descriptors'). Then PATCH dependencies._resolve_probe_custom to: `return resolve_ref(spec[7:])` (colon syntax) — removes the duplicate dot-rsplit resolver (PD08 D1).

## steps.py
```
_STEP_BUILDERS = {'toolchain':..., 'shell':..., 'callable':..., 'sequence':..., 'select':...}
def build_step_from_spec(spec): return _STEP_BUILDERS[spec['type']](spec)
```
- toolchain -> toolchains.loader.build_step(spec['toolchain'], spec.get('action','install'), spec['package'], *spec.get('extra',()))
- shell -> ShellStep(id, command=tuple(spec['command']), timeout=spec.get('timeout',300), cwd, env)
- callable -> CallableStep(id=spec['id'], fn=resolve_ref(spec['ref']))
- sequence -> SequenceStep(id, steps=tuple(build_step_from_spec(s) for s in spec['steps']), fail_fast=spec.get('fail-fast',True))
- select -> SelectStep(id, select=resolve_ref(spec['select']), variants={k: build_step_from_spec(v)...}, fallback=...)
Unknown type -> AudiaGenticError VAL-DESC-002.

## loader.py
- `iter_descriptor_files(dir: Path) -> list[Path]`: sorted(dir.glob('*.yaml')); ignore files starting with '_'. No hardcoded names (Rule 5).
- DescriptorSpec: declares fields as kinds {data, ref, step, probe, nested:DescriptorSpec, list-of:nested}, required set, and rename map (yaml kebab -> python snake).
- `load_descriptor(path, spec, factory)`: yaml.safe_load -> validate required -> for each field apply kind handler (ref->resolve_ref, step->build_step_from_spec, probe->dependencies._resolve_probe, nested->recurse) -> factory(**resolved). Missing required -> VAL-DESC-003.

## registry.py
`DescriptorRegistry[T]` generic: _items: dict[str,T]; register(id,obj) (idempotent overwrite), get(id)->T|None, all()->dict copy, clear(). No domain knowledge.

## Provider loader stub (components layer, validated here against 1-2 sample YAMLs)
components/providers/descriptors/loader.py: defines PROVIDER_SPEC (the field map from PD01) + provider_factory building ProviderDescriptor (wrapping McpConfigSpec/LanguageServersConfigSpec/CliInstallRecipe from resolved parts), then registers via existing provider registry.register(). Discovery: iter_descriptor_files(config/providers/).

Containment gate (reviewed 2026-06-26): PROVIDER_SPEC must not include
backend-specific implementation data (`hindsight`, memory recipe rows,
backend-specific install commands, recall/retain rules). Hindsight-specific
matrix loading is owned by `components/memory/hindsight/matrix.py` from
`config/components/memory/hindsight_matrix.yaml`.
