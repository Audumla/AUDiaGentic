# Code review: implementation selection still bypasses observer reconcile

## Notes

Review of latest HM07-related lifecycle wiring after async config event change.

## Findings

['`memory_select_implementation()` in `src/audiagentic/components/memory/memory_api.py` still only returns `needs_provider_recipe_refresh` and does not publish a lifecycle/config event.', '`enable_implementation()` in `src/audiagentic/foundation/features/lifecycle.py` mutates state only; it emits no lifecycle event the memory observer can consume.', "Result: direct API callers can switch memory implementation without observer-owned Hindsight reconciliation, which violates HM07's guarantee that correctness does not depend on a specific MCP caller."]

## Conclusion

Implementation-selection path remains incomplete for HM07. Add observer-consumable event or equivalent guaranteed reconcile trigger for direct API callers.
