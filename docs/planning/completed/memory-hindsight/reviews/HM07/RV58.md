# Code review: config-change test does not prove observer execution

## Notes

Review of new HM07 validation coverage in `tests/unit/memory/test_hindsight_provision.py`.

## Findings

['`test_config_change_event_triggers_reconcile` manually calls `prov.reconcile_hindsight()` after each `memory_set_config()` call.', 'The assertion only checks that wildcard subscribers exist for `lifecycle.component.config_changed`; it does not assert that observer callback actually invoked `refresh_provider_recipes()` or `reconcile_hindsight()`.', 'A regression in observer execution would still pass this test as written.']

## Conclusion

Replace manual reconcile with a spy/assert on observer-triggered `refresh_provider_recipes()` or `reconcile_hindsight()` so HM07 validation proves the intended event-driven path.
