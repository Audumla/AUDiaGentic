# Descope: post-HM20, full convergence is code movement + adapter shims, not reduction — implement ownership fix, E402 fix, writer audit only

## Notes



## Findings

Over-engineering review 2026-07-07, after HM20/SL10 landed:
1. HM20 already removed the boilerplate that motivated this item (~400 lines: orchestration duplication, 7 sequence hand-rolls, 5 helpers). The remaining recipe classes encode genuine per-provider strategy differences (plugin arrays, URL-config files with Windows repair, installer gating) — deleting them relocates logic rather than removing it.
2. The planned ManagedMcpFragmentRecipe replacement would need a .backend compat attribute for _CompositeRecipe, introspection-only provision_steps to satisfy existing matrix-validation tests, and project_root/cwd fallback plumbing — plus a rewrite of the pinned HindsightMcpRecipe unit suite (test_hindsight_recipe.py) and boundary tests. Churn, not simplification.
3. Rules→surfaces rerouting: RulesOnlyRecipe already consumes the shared managed_block + ArtifactRegistry primitives with descriptor-driven paths; it is a consumer of the shared mechanism, not a parallel one. Rerouting adds surface coupling and deletes nothing.
4. Module split: adds files + facade re-exports to fix 12 E402 errors caused solely by HindsightStatusState being declared above the imports — fixable by moving the enum.
5. The one remaining correctness hazard is real: hindsight's MCP entry is written via the descriptor writer but never recorded in the managed-mcp ownership registry, so managed tooling cannot see it and name collisions are undetectable. Verified safe to fix: ALL production sync callers use the subset form, so registering managed_id 'ag-hindsight' cannot be stale-removed by ag-* projections.

## Conclusion

Descope HM21 to: (1) route _McpConfigAdapter and _CompositeRecipe MCP-entry configure/prune through sync_managed_provider_mcp_subset (managed id 'ag-hindsight') — closes the dual-writer/ownership gap on the SL10 engine with no new classes; (2) move HindsightStatusState below imports (kills all 12 E402s); (3) add the per-provider URL-form writer audit test from validate-first (a). Skip class deletions, rules→surfaces, and the module split as not-simplifying. Complete the item on that basis.
