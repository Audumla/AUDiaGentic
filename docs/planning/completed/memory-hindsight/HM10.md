# De-duplicate Hindsight MCP config provisioning

## Description

First cleanup item. Replace Hindsight-local MCP config mutation with generic provider MCP sync, and remove nearby duplication/fragile helpers that make later lifecycle cleanup harder. `mcp_recipe.py` keeps Hindsight-specific entry construction/recipe intent; provider config path resolution, format callbacks, managed ownership, collision handling, and reload belong to provider MCP services.
