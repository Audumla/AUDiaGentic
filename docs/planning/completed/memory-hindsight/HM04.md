# Native installer recipes (command-driven) per harness

## Description

Populate Hindsight implementation matrix/spec values for native-installer and launch-wrapper providers (claude, codex, opencode, cline, aider). No provider-component Hindsight modules and no bespoke Python recipe per provider: specs are data consumed by the HM03 builder in `components/memory/hindsight/`. Every command/path must be copied from official Hindsight docs or inspected installer source and recorded with source_url + source_checked_date. Guessed commands are blocked, not implemented.
