# Promote generic recipe machinery out of hindsight recipes (result hook, step builder, guards)

## Description

hindsight/recipes.py (~1700 lines) reimplements orchestration and helpers that belong in the generic capability layer. Validated findings (2026-07-06):
1. _RowRecipe.provision() (recipes.py:140-169) and teardown() (171-189) duplicate ProvisioningRecipe.provision/teardown (foundation/toolchains/recipe_contract.py:142-209) almost line-for-line — including re-implementing the CompensatingSequence delegation the base already performs at recipe_contract.py:160-176. The only added value is provenance stamping (_stamp → ProviderRecipeResult with source_url/source_date/action_needed). CompensatingSequence(steps).run() is additionally hand-rolled SEVEN times inside recipe class methods (lines 244, 280, 349, 382, 606, 624, 659).
2. _steps_from_defs (recipes.py:1002) — 'YAML step-def list → ProvisionStep list with auto ids/params/registry/recipe_id' — is pure mechanism belonging beside provision_step_from_dict in foundation/toolchains/provision_steps/factory.py.
3. _command_parts (recipes.py:77) — shell-metachar refusal + shlex.split — is a security guard every matrix/YAML-declared command needs; belongs in foundation/toolchains next to CommandProbe (probes.py).
4. _parameterize_command (recipes.py:966) duplicates the {KEY} placeholder substitution ProvisionSteps already do internally; expose ONE substitution helper from provision_steps and reuse it.
5. _normalize_platform/_platform_supported (recipes.py:1026-1055) — platform-constraint matching against platform_key() is generic row/step filtering; belongs in foundation/toolchains beside platform_key. (Also: the docstring demands canonical keys yet the code normalizes aliases — pick one: canonicalize the matrix data and keep a strict check.)
Goal: the generic capability layer gains these features permanently (usable by future capabilities); hindsight keeps only its domain mapping (_hindsight_params key values, matrix schema, strategy selection). Net: recipes.py shrinks by roughly 250-350 lines with behavior preserved.
