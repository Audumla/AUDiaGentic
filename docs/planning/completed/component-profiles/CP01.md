# Consolidate .audiagentic/audiagentic name resolution into one resolver

## Description

Pre-cleanup groundwork for profile support. The literal directory names '.audiagentic' (project marker) and 'audiagentic' (package root) are each hardcoded independently in four places: paths.py find_project_root, foundation/paths/package.py find_package_root, foundation/home.py audiagentic_home(), and foundation/components/registry.py marker_path(). A profile scheme needs to resolve '.audiagentic/<profile>/...' vs the base folder, and doing that safely requires a single source of truth for these names rather than editing four call sites independently and risking drift.
