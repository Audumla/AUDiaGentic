# Cache guard breaks lazy re-registration suite-wide — 67 unit-test failures; items closed with a red suite

## Notes



## Findings

The suite was left failing: python -m pytest tests/unit reports 67 FAILED (verified 2026-07-05), concentrated in tests/unit/coding_lsp/ (~30), tests/unit/memory/ (~20), plus providers/foundation. Root cause for most: the new _registration_cache in loader.py short-circuits register_all_components() on an unchanged targets key, but the ONLY cache-invalidation wiring added is an autouse fixture in tests/unit/foundation/conftest.py — tests under tests/unit/coding_lsp/, tests/unit/memory/, etc. clear the feature registry (their own fixtures/isolated_features_registry patterns) and then call register_all_components() expecting lazy re-population; the cache returns the memoized descriptor list without re-registering features, leaving registries empty. This is EXACTLY the RV96/RV106 staleness class the item existed to prevent — the hook was built but wired into only one test directory. Secondary defects: (1) foundation/components/registry.py reset() carries a stale TODO ('TODO(CP02): When CP02 lands, also call loader._cache_reset()...') even though CP02 landed in the same change and reset() still does NOT invalidate the cache — any caller of reset() outside the one conftest reproduces the bug; (2) the AUDIAGENTIC_COMPONENT_CONFIG_DIRS override parsing is duplicated verbatim in error_resolutions.py._get_component_config_dirs() instead of shared — two copies that can drift, the precise failure mode CP02's own step warned about, and a §3 violation (shared logic 2+ files → extract).

## Conclusion

Must fix before this work ships: (a) make components/registry.reset() and features/registry.clear() invalidate the loader cache (or give the loader cache a subscription to registry clears), OR add the autouse reset fixture at tests/conftest.py root scope; (b) remove the stale TODO and make reset() actually do what it says; (c) share one override-resolution function between loader.py and error_resolutions.py. Suite must be green before any of these items can honestly be called completed.
