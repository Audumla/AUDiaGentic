# Equivalence test proves LOADER parity, not CONSUMER parity; access-path degradation is unquantified

## Notes

Two under-weighted risks in the dual-read safety story:

1. The normalization-equivalence test asserts the loader produces the same ProviderDescriptor.capabilities from either shape. It does NOT prove downstream behaviour is identical UNLESS every consumer reads ONLY the normalized view. Today consumers read RAW typed fields directly: descriptor.mcp_config, descriptor.permissions, descriptor.on_lsp_enabled, descriptor.fetch_catalog_fn, descriptor.host_capabilities, etc. (e.g. managed_mcp_family.py reads descriptor.mcp_config and descriptor.automation_capability('managed-mcp') directly). Every one of those call sites must be rerouted to the normalized accessor, and the equivalence test cannot see whether a missed site still reads a field that PC03 later empties. There is no consumer/call-site inventory in the plan.

2. Access-path degradation: descriptor.mcp_config (static attribute, typed, IDE-navigable) becomes descriptor.capability('mcp-config').mechanism (dynamic key, Optional, can miss at runtime). This is a real ergonomics + type-safety regression the 'typed mechanism preserved' framing glosses — the mechanism OBJECT stays typed but the PATH to it weakens.

## Findings

Before PC02 implementation: (1) produce a call-site inventory — grep for descriptor.mcp_config / .model_config / .plugin_config / .hooks_config / .language_servers_config / .permissions / .host_capabilities / .on_lsp_enabled / .lsp_support_probe / .fetch_catalog_fn / .agent_files / .surfaces / .capability_facts / .automation_capabilit* and size the reroute; add it to PC02 files/effort. (2) Keep the typed accessors as the PUBLIC surface (descriptor.mcp_config -> property projecting from the normalized view) so consumers do NOT move to string-key lookups — preserve static attribute access, change only the backing store. (3) Extend the equivalence test to also assert a few key CONSUMER outputs (managed_mcp status, a surfaces render, capability_facts payload) match HEAD, not just the descriptor struct.

## Conclusion

The safety net is narrower than presented. Add a call-site inventory to PC02 scope, keep typed properties as the public accessor to avoid an ergonomics regression, and extend the equivalence gate to a few consumer outputs so a missed reroute is caught.
