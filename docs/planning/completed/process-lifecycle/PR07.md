# Implement foundation start-or-attach, ownership verification, drain, and guarded shutdown

## Description

Build the process-backed ManagedService operations on PR06: discover a named service, atomically attach to a compatible healthy instance or launch exactly one detached owner, verify endpoint/process ownership, and stop only after the generic lease and consumer-supplied quiescence gates pass. The API must work for the gateway, shared rig, and future local services without embedding their protocols.

## Steps

1. Define a narrow launch declaration and health/identity handshake callback contract; service-specific protocol implementation stays with the consumer. 2. Under the PR06 per-service lock, implement start-or-attach: read record, validate epoch/PID/create-time/endpoint handshake, acquire lease before releasing the lock, or launch one detached process and publish readiness atomically. 3. Ensure detached services escape the initiating host's Job Object/process group only when declared, while retaining a foundation-owned ownership proof. 4. Implement drain request, final lease re-check, consumer quiescence callback, graceful stop, bounded escalation, and cleanup verification. 5. Handle stale discovery records, PID reuse, launcher crash, failed readiness, incompatible protocol/version, and reconnect during drain without killing unowned processes. 6. Add structured status/recovery outcomes and neutral timeline facts. 7. Add fake-process and platform integration tests including concurrent cold starts, starter death, last-client race, decoy process safety, and final cleanup.
