# Implement foundation managed-service records, leases, and lifecycle state machine

## Description

Implement the first usable slice of PR05: a framework-neutral ManagedService state store and coordinator for a named shared service and its connected clients. It records durable service identity/state, ownership evidence references, endpoint/protocol metadata, redacted health facts, and renewable client leases. It does not launch a process, expose MCP tools, decide component authorization, or decide whether domain work is quiescent.

## Steps

1. Define versioned typed records for service identity, lifecycle state, process identity/ownership proof reference, endpoint/protocol compatibility, heartbeat, and client leases. 2. Implement atomic state transitions under one per-service cross-process lock, with monotonically advancing epoch/version to reject stale writers. 3. Implement acquire, renew, inspect, release, and expiry/reap of client leases; lease metadata is bounded/redacted and cannot contain prompts/secrets. 4. Implement lifecycle transitions and guarded APIs for starting/running/draining/stopping/stopped/failed, rejecting invalid transitions. 5. Add per-service timeline events and neutral status snapshots. 6. Provide test fakes for time, liveness, and locks. 7. Add multi-process race tests for simultaneous acquire/release/expiry and stale epoch writes on Windows/POSIX.
