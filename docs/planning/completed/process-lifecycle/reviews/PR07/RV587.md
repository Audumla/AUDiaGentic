# PR07 lifecycle safety, reuse, platform, and cohesion review

## Notes

Post-implementation review against PR05, Architecture Standards, Observability Standards, leverage-before-build doctrine, and the no-monolith constraint.

## Findings

1. PASS dependency boundaries: all production code is framework-neutral foundation; no component, gateway, MCP, runtime orchestration, or provider dependency. 2. PASS reuse: PR07 extends PR06 store/leases, StartupLock, pid_alive, process-tree signaling, atomic JSON, TransitionEngine-governed states, redaction, and timelines. It adds no second registry, lock, state machine, event bus, scheduler, or RPC layer. 3. PASS cohesion/no-monolith: process evidence and OS launch (managed_process), callback/result contracts, start/attach coordination, guarded shutdown, and a 72-line facade are separate. The larger store/starter files each retain one cohesive transactional responsibility. 4. PASS process safety: attach and every destructive signal require PID plus matching creation/command/group evidence; endpoint handshake additionally matches epoch, protocol, and endpoint identity. Decoy tests prove no attach or signal. 5. PASS cold-start race: one per-service cross-process lock encloses discovery, launch, readiness publication, and lease acquisition; six independent Docker clients launch exactly one owner. 6. PASS shutdown race: draining rejects new leases/attaches; final active leases, epoch, consumer quiescence, and a fresh ownership observation are rechecked before stopping; force is bounded and re-verifies ownership. 7. PASS degraded outcomes: unverified ownership, active leases, non-quiescence, unavailable quiescence, stop timeout, and signal failure are structured and secret-free; native launch/observe callback failures become registered public errors. 8. PASS scope: no restart policy, agent groups, GPU concurrency, protocol implementation, component authorization, or domain quiescence logic. 9. FIXED during Docker: POSIX zombie processes were misclassified live by os.kill(pid,0); shared pid_alive now rejects /proc Z/X states, improving both lifecycle and stale lock recovery. 10. ENVIRONMENT GATE: this Windows runner denies detached breakaway from child Job Objects. The implementation safely raises CON-MPROC-003 instead of claiming detachment; Windows fake-process coverage passes and clean Linux performs the real detached lifecycle. No unresolved implementation finding remains.

## Conclusion

Approved. PR07 provides a narrow reusable lifecycle authority with guarded ownership semantics, bounded coordination, cohesive modules, and real clean-container process validation.
