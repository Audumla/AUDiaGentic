# Migrate embedded topic strings to registered constants; enforce strict conformance

## Description

Code migration completing BU01: replace every inline bus-topic string literal in src/ with a module-level constant defined in the OWNING component's events module and registered in its events.yaml, then flip BU01's conformance test from allowlist mode to strict. Known inline-literal sites (2026-07-12 inventory, ~62 occurrences / 13 files): components/agent_jobs/event_observer.py (_GW_OUTCOME_TOPICS tuple + agents.llm.gateway.requested publish), agent_jobs/control.py (agents.llm.gateway.cancel-requested publish), agents/agents_gateway_events.py (has module constants — register + keep), agents/agents_gateway_queue.py, agents/agents_gateway_api.py, agent_jobs/prompt_launch.py, prompt_context.py (planning.item.created special-case), planning/events.py (constants exist — register + keep). CROSS-COMPONENT RULE from BU01: a consumer references the OWNER's constant only when an import dependency is already allowed by the architecture layering; where the boundary forbids the import (e.g. agent_jobs must not import agents modules — test_gateway_boundary.py forbids agents_gateway_events imports), the consumer declares its OWN mirror constant and a registry-level test asserts the mirror equals the registered owner topic (string equality via the registry, no code import — preserves events-only boundaries).

## Steps

1. Run BU01's conformance test in report mode; capture the definitive site inventory (file:line per literal).
2. For each owning component, ensure an events module exports one constant per registered topic (planning/events.py pattern); add missing constants for agents.llm.* (agents component) and job-side gateway topics.
3. Replace inline literals at every publish/subscribe site with the constant — or, across forbidden import boundaries, with a local mirror constant documented as such (comment naming the owner + registry test asserting equality). agent_jobs' _GW_OUTCOME_TOPICS and gateway request/cancel topics are the canonical mirror cases (import ban enforced by tests/unit/jobs/test_gateway_boundary.py — do NOT weaken that test).
4. prompt_context.py's planning.item.created special-case and event-trigger YAML examples/fixtures reference topics as DATA — leave YAML/config/data alone (config references topics by name by design); only Python literals migrate.
5. Empty the BU01 conformance allowlist; the test now fails on any unregistered or inline-literal publish site.
6. Full test sweep of touched components (jobs, agents, planning, foundation event tests) with the RV267-style baseline rule: zero NEW failures.
7. Replace agents_gateway_queue.py's f"agents.llm.{event_suffix}" with an explicit immutable suffix→topic-constant map; unknown suffix raises/logs a canonical internal error before publish. Migrate foundation lifecycle/interaction publishers to constants exported from foundation.event; do not mirror foundation constants in components.
