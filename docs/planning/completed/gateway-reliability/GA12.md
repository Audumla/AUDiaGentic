# Prevent alive-but-unreachable gateway owners

## Description

Ensure an unexpected HTTP server exit or hung teardown cannot leave the gateway process/registry reporting running while port 8765 is unreachable.

## Steps

- Detect unannotated server exits as service-boundary failures.
- Bound host teardown so provider cleanup cannot strand the process indefinitely.
- Fence the managed owner and close the old socket before launching a replacement.
- Add process-wrapper regression tests and verify the live listener after restart.

## Detailed Solution & Technical Design

The detached process wrapper now distinguishes explicit lifecycle exits from unexpected server returns, applies a bounded close deadline, fences a stranded owner on teardown timeout, and launches a clean replacement before terminating the stale process.
