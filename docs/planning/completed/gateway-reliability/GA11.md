# Safely adopt terminal assistant remounts during response observation

## Description

Prevent false EXT-GPTAUTO-004 failures when ChatGPT remounts the completed assistant DOM node with a different durable message id during response observation.

## Steps

- Correlate the remounted assistant to the exact submitted prompt and project conversation.
- Require one assistant in the prompt-owned ordered span, no later user turn, non-generating state, response text, and an independent terminal DOM witness.
- Adopt only the proven replacement; retain fail-closed behavior for ambiguous or streaming identity changes.
- Add regression tests and validate against the captured BigCherry failure evidence.

## Detailed Solution & Technical Design

Extend the response identity reconciliation fence with a terminal same-response-slot predicate. A durable id change is admissible only when the existing ordered prompt boundary is unambiguous and the current snapshot proves terminal completion. Synthetic activity must not satisfy this predicate because generating must be false and a terminal witness must be present.
