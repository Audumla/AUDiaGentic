# Silently reattach durable GPT conversations before continuation fallback

## Description

When a GPT-auto session has a durable project-scoped chat URL but its local transport cannot be opened, retry the exact conversation in place/silently instead of reserving a fresh conversation. Preserve the original session and request correlation; only terminalize on outer timeout, explicit cancellation, or proven provider failure.

## Steps

- Trace ordinary continuation and recovery exception paths
- Add durable-identity guard that defers exact-session rehydration instead of fresh-session replacement
- Add regression tests for explicit session-bound continuation with retained chat URL
- Run focused gateway tests and live smoke test against BigCherry
