## Detailed Solution & Technical Design

INSTALL_MAP.md is now a normative contract whose Manage/Uninstall column mandates behaviours reconcile_hindsight does not yet surface: report restart-required after changes, rely on file-watch reload, report collisions, and (gemini) surface deprecation/migration guidance. Today reconcile returns only {success, state, role} + a family-sourced action_needed, and after DE01 it receives a foundation RecipeResult that HIDES the managed family's rich result. Close the gap by (1) surfacing the family result through the recipe context, and (2) computing hints from it + the descriptor.

KEY MECHANISM (RV829 E1): the managed-* steps (DE01) must stash their family result into a mutable context bucket so reconcile can read it after execute_recipe_mode. ManagedMcpResult already carries changed, collision_ids, removed_ids, auto_refreshed, action_needed, error_code (verified). reconcile passes context={'project_root':..., 'managed_results': {}} and, after the run, reads managed_results to build hints. This is a small addition to DE01's managed-* step contract (step.run writes context.setdefault('managed_results', {})[managed_id] = result.to_mapping()).

Prefer ManagedMcpResult.auto_refreshed for the refresh signal where present; fall back to the descriptor mcp surface refresh_mode for families whose result lacks it. Deprecation is descriptor-driven, not per-provider Python.

=== _lifecycle_hint: refresh + collision + deprecation (all descriptor/result-driven) ===
from audiagentic.components.providers.descriptors.registry import get_descriptor

def _mcp_refresh_mode(pid, root):
    from audiagentic.components.providers.providers_api import describe_provider
    for s in describe_provider(root, pid).get("config_surfaces", []):
        if s.get("kind") == "mcp":
            return s.get("refresh_mode")          # RV836: CONFIRMED — _serialize_config_surface includes refresh_mode
    return None

def _lifecycle_hint(pid, root, fam):
    parts = []
    # refresh: prefer the family's auto_refreshed; else the descriptor refresh_mode.
    changed = fam.get("changed", False)
    if changed:
        auto = fam.get("auto_refreshed")
        mode = _mcp_refresh_mode(pid, root)
        if auto is False or mode == "restart-required":
            parts.append("restart the harness for the change to take effect")
    # collisions: surface even on ok (do not drop as current _map_*_status does).
    if fam.get("collision_ids"):
        parts.append(f"unmanaged entries collide: {', '.join(fam['collision_ids'])}")
    if fam.get("action_needed"):
        parts.append(fam["action_needed"])
    # deprecation (RV836, user-confirmed: boolean only — no structured block):
    desc = get_descriptor(pid)  # RV836: must read from descriptor directly; describe_provider does NOT include deprecated
    if desc is not None and getattr(desc, "deprecated", False):
        parts.append("Provider is deprecated — check annotations for migration guidance.")
    return " ".join(parts) or None
