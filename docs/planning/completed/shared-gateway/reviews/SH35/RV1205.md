# Extend shared gateway design with caller-local execution nodes

## Notes



## Findings

User clarified that centrally scheduled work should launch/control harness instances on client machines so they use the caller's existing files. Initial SH35 emphasizes server-side checkout mapping and is incomplete for this topology. Stdio is a local MCP host/server transport, not a generic reverse-execution channel; relying on a second MCP call while a submit/wait call is blocked can deadlock. Separate central admission/control from node-local execution and require explicit ownership/capability for control of an existing interactive caller harness.

## Conclusion

Add outbound authenticated execution-node channel, stable node/workspace bindings and fenced per-instance identities. Keep same-host mode. Review with Dev GPT actual worker-host/provider isolation/broker seams before finalizing protocol and lifecycle design; do not imply arbitrary remote control of parent UI or standard MCP reverse-RPC support.
