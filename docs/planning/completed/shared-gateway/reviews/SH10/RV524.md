# Delegate generic gateway service lifecycle mechanics to foundation ManagedService

## Notes



## Findings

SH10 currently defines client leases, drain sequencing, and race-safe idle shutdown as gateway work. Those mechanics are reusable and must be first-class foundation functionality under PR05–PR07. The gateway should supply only its domain-specific facts—queued/running work, live sessions, authorization, and idle policy—and consume foundation state/lease/start/stop operations. SH04 and SH05 require the same correction.

## Conclusion

Update SH04/SH05/SH10 and AS08 to consume PR06/PR07 public APIs. Foundation owns process/service identity, service records, lease mechanics, locks, ownership verification, generic drain transition, and guarded stop. Gateway owns gateway work/session quiescence and public operations; MCP/CLI remain thin adapters.
