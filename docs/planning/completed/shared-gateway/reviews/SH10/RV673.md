# Start the shared gateway from a neutral managed-service context

## Notes



## Findings

start_or_attach_gateway declared a detached process without cwd or launch environment overrides. The winner of a cold start therefore supplied the long-lived machine-scoped service’s CWD, AUDIAGENTIC_REPO_ROOT, and component-profile environment. That contradicts the shared-service design: project root and profile are request/manifest facts and must not be process-global service state.

## Conclusion

Valid. Scoped repair sets the launch cwd to the gateway ManagedServiceStore root and clears the inherited project-root and component-profile variables. The store root is created before DetachedLaunch validates the cwd. Request-level project/profile propagation remains unchanged.
