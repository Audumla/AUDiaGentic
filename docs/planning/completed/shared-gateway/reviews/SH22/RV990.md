# GPT validation: activity lease is diagnostic, not timeout failure

## Notes

Live GPT design review reproduced activity-lease expiry while provider-turn-pending remained true, followed by resumed activity and successful completion. The review validated a narrow semantic correction: lease expiry is stale-progress/reconciliation evidence only; it must not be classified as a strong timeout or terminal failure.

## Findings

Current TO-AGW-076 handling records classification=timeout and leaves that classification unresolved even after validated activity resumes. Absolute safety ceilings must remain hard and non-resetting; activity-aware leases and submission-proof progress leases remain nonterminal observations. Remove the redundant 3900-second GPT session-turn override. Count only fenced monotonic provider/session work evidence (thinking, search, tools, response progression) as activity; not heartbeats alone, provider-turn-pending, duplicates, or out-of-order events.

## Conclusion

Implement as a focused SH22/GP48 correction: stale-progress state/diagnostic semantics, resolution on resumed activity, distinct absolute-safety classification, profile cleanup, and regression tests. No new lifecycle state machine is required.
