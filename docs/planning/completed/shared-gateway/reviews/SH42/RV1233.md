# Preserve verified provider terminal results when private-home deletion is deferred

## Notes



## Findings

queue/worker.py _private_worker_home raises PermissionError after its bounded deletion retry. Because native result return unwinds that context manager, a valid completed result can be discarded solely by temporary-directory cleanup failure, and a cleanup exception can mask an original provider error. This is distinct from missing worker-exit/terminal evidence. The approved one-shot epoch barrier requires validated terminal, owned worker exit and durable producer write, not successful deletion of every temporary file.

## Conclusion

Add a focused reproduction and make deferred temporary-home cleanup diagnosable without overwriting valid terminal results or original errors. Preserve unknown worker/terminal failure fences. Keep leftover private directories protected and do not add a broad temp purge. Exact-source review and tests required; no claim this caused the observed browser completion failures.
