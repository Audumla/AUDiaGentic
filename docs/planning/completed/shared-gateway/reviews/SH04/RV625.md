# Harden standalone protocol authority, bounded state, and user-visible recovery evidence

## Notes

Parallel implementation, testing, and documentation audits were run before SH04 closure. The module split is cohesive and foundation lifecycle reuse is sound; the findings below are required corrections or explicit boundary clarifications.

## Findings

1. Enforce protocol version, owner epoch, and an active non-expired lease on every domain call; token-only and stale clients must be rejected. 2. Reattach once before a domain call when a lease expired or the owner epoch rotated; never retry a submitted mutation. 3. Canonicalize absolute project roots client-side and validate them server-side. 4. Bound managed-service lease history and gateway lease TTL; bound per-correlation event IDs as well as correlation keys, with config validation. 5. Define and prove bounded retries only for safe health/attach reads. 6. Wrap malformed endpoint/envelope types in stable AGSV errors. 7. Document concrete loopback HTTP/token/version/lease/no-fallback/retry behavior and refresh stale component/event docs. 8. Clarify that idle service process restart is proven in SH04 while durable in-flight request recovery remains SH07. 9. Add raw-client, malformed/security, expiry/rotation, concurrency, Windows-host, and Linux-Docker evidence.

## Conclusion

Implemented. Server authority now validates protocol, epoch, and active lease before domain invocation; clients canonicalize roots and boundedly reattach only after pre-invocation lease rejection; lease/event state and TTLs are bounded; endpoint/envelope errors are classified; concrete behavior and SH07 recovery boundary are documented. Windows host and clean Linux Docker gates pass.
