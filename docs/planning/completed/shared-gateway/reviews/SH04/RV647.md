# Standalone timeout regression no longer exercises client-timeout survival

## Notes

Exposed while running SH05's broad regression gate after SH04 completion.

## Findings

Confirmed. StandaloneGatewayClient._call defaulted transport_timeout to None, disabling the configured request timeout for ordinary domain calls, while run_llm_request hardcoded 305 seconds when no job timeout was supplied.

## Conclusion

Fixed. Ordinary calls and run-without-explicit-job-timeout now use the configured client request timeout; wait(timeout_seconds=None) remains explicitly unbounded; supplied job timeouts retain the five-second transport grace. Full SH04/SH05/foundation gate: 46 passed.
