# Multi-A-record localhost reconnect collapses to non-retryable OSError (node exits instead of reconnecting)

## Notes

Review-of is SH44 since this was discovered during SH44's crash-barrier work; the underlying defect lives in NodeTransportClient.connect (transport layer), not in SH44's own test harness.

## Findings

Found during SH44 live crash-barrier testing on brutus-audiagentic (2026-10-28). When the gateway process goes away, the node's reconnect attempt to wss://localhost fails because `localhost` resolves to both ::1 and 127.0.0.1; asyncio's connector collapses the two connection refusals into a single OSError with errno=None ("Multiple exceptions: [Errno 111] ... ::1 ..., [Errno 111] ... 127.0.0.1"). NodeRecipientHost.run treats any OSError that is not a ConnectionError and has no retry errno as a configuration boundary, so the node exits terminally (node-reconciliation-required) instead of retrying the reconnect -- directly breaking the "survives connector exit" guarantee this item is meant to prove, for ANY gateway hostname with multiple A/AAAA records (not just localhost -- the Windows two-machine tunnel harness used the same localhost endpoint and would hit this too).

Fix (authored by brutus-audiagentic, branch sh44-restart-recovery in /work/development/AUDiaGentic/wt-sh44, NOT YET PUSHED): NodeTransportClient.connect passes all_errors=True on Python 3.12+; when the result is an ExceptionGroup, re-raise one per-address error, preferring any error that is not a plain refusal, so the existing errno-based retry-vs-terminal logic in NodeRecipientHost.run decides correctly on a single concrete error. Python 3.10/3.11 keep current behavior (all_errors only exists on 3.12+). Regression test added: fails without the fix, passes with it. Full transport + host suites pass (93 tests), ruff clean.

## Conclusion

Resolved. The fix is on main in node/transport.py: connect() passes all_errors=True on Python 3.12+ and _representative_connect_error reduces the ExceptionGroup to one per-address error, preferring any non-refusal so an unusual failure still fails closed, so NodeRecipientHost.run's errno rule retries a plain refusal. The SH44 live restart runs (loopback and simulated two-host) exercised it. This change adds the missing unit regression tests (tests/unit/agents/test_gateway_node_connect_errors.py).
