# Name SH07 the single durable job-state authority; AS21 projection is evidence input; SH02 owns the canonical identity fingerprint

## Notes



## Findings

SH07 defines durable request state (admission, attempt identity, terminal-result uniqueness) and AS21 independently defines a lifecycle projector emitting ACTIVE/WAITING/COMPLETING/AVAILABLE/FAILED/UNKNOWN with turn_terminal/dependent_work_releasable flags. Neither item references the other; two answers to 'is this job done' can emerge. Separately, three identity concepts exist: SH02 context fingerprint, SH06 worker-reuse fingerprint, SH07 idempotency/attempt identity — without a stated canonical owner.

## Conclusion

SH07 owns the durable request/job-state record; AS21's projection is transport-independent evidence input consumed by SH07's transitions (SH07 must not consume raw transport-specific terminal events once AS21 lands). This makes gateway job-state materialization capability-driven and ACP-independent: observation fidelity comes from the AS19 declared capability level, richer transports only raise fidelity. SH02 owns the one canonical execution-context fingerprint; SH06 reuse keys and SH07 idempotency identity derive from it. Edits applied to SH07, AS21, SH02.
