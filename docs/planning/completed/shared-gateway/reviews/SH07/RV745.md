# C2 registry authority remains transitional after worker completion

## Notes



## Findings

Worker completed 76 tests and correctly added a registry seam, shared-mode admission, persisted snapshot reconstruction, and lane isolation. Its own self-review identifies the remaining production gap: InMemoryGatewayRegistry is process-local, no service-owned persistent/configured registry is wired at gateway startup, and shared mode requires an explicit set_gateway_registry call. Embedded mode still permits project-local queue limits.

## Conclusion

FIXED 2026-07-19: GatewayServiceHost.create now loads the gateway-owned profile registry from a machine-scoped config file (audiagentic_home()/config/gateway-profiles.yaml, overridable via gateway_profiles_config) and installs it with set_gateway_registry() before the store/server are constructed, so shared mode is registry-authoritative from the first admitted request. Absent config file preserves prior embedded-mode behavior (registry None). host.close() clears the registry to avoid cross-host leakage in-process. Production-path test through the real HTTP service host with two distinct project roots sharing one profile's max-concurrency=1: test_service_host_startup_wires_gateway_owned_registry_from_config in tests/integration/agents/test_gateway_standalone_service.py (plus a no-config-present regression). Embedded-mode project-local override for non-shared mode remains intentional per doctrine (EmbeddedCompatibilityRegistry is the documented fallback, not a gap).
