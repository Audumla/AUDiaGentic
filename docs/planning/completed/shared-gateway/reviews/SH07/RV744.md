# Gateway wait projection drops active ACP turn evidence

## Notes



## Findings

Repeated live diagnostics for req_example_58012f521d65c24b, req_example_324c654b602b173d, and req_example_bbd975062ddf79c9 show advancing session.turn.tool-call events and sequence numbers, while agent_llm_wait after its timeout returns phase=launching, latest-session-event=null, stale-progress=true. This makes blocking wait unsuitable for supervision and can falsely classify active work as stalled.

## Conclusion

FIXED 2026-07-19: wait_llm_request's timeout path now consults the same live session timeline as request_runtime_status via a shared _latest_session_turn_event() helper (agents_gateway_api.py). A timed-out blocking wait's progress projection now reflects active tool-call/model-active phases instead of defaulting to phase=launching with null latest-session-event. Regression test: test_wait_timeout_progress_reflects_live_session_turn_evidence in tests/unit/agents/test_agents_gateway_api.py.
