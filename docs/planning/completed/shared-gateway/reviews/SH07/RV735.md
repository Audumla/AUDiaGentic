# Surface live session turn evidence and preserve cancelled-turn diagnostics

## Notes



## Findings

Critical production test finding on 2026-07-19: delegated gateway requests appeared stuck with no output, but persisted session timelines showed active model/tool events and terminal `session.turn.result` evidence. `request_runtime_status()` did not project the session timeline, and protocol-cancelled session turns wrote blank cancelled request records with no attempt/output/completion diagnostics. This made active agent work operationally opaque.

## Conclusion

Implemented a focused source fix: project a redacted latest session-turn event into request runtime status, preserve bounded output/completion diagnostics for cancelled session turns, and allow cancelled attempt records in the request schema. Keep SH07 open for the broader cancellation acknowledgement/recovery contract and live-service reload behavior.
