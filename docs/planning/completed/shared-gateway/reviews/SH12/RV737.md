## Findings

1) INTERRUPTED MAPPING (N2): the frozen topic table omits 'interrupted' — add agents.llm.interrupted → agents.execution.interrupted (or introduce the neutral event via SH07/AS21 before cutover); every downstream job/reviewer consumer must map it (SH07/RV730 finding 5).

3) CENTRAL ROOT RESOLVER (N4): host, bootstrap, ingress publishers/consumers, lifecycle recovery, CLI, and tests all construct the gateway ManagedServiceStore key/root — a host-only migration fails (automatic bootstrap reads the new key before the host starts, misses the old live owner, starts a second service). Create one gateway-owned service-root/key resolver used everywhere.
4) LIVE-SERVICE GATE (N5): before moving the old machine root/key: inspect the old record, prove the owner stopped/dead or perform authorized drain/stop, no active leases, no active work, lock the migration, move root/token/spool atomically, then start v2. A live v1 service fails with explicit operator action — never start a second service relying on port collision.
5) BOTH-ROOTS CONFLICT (N6): the migrate-only-if-new-absent helper silently strands old records when both roots exist — define explicit conflict handling (validated merge under a proven owner rule, or fail requiring recovery); include the accidental top-level session root from C3 (note: gateway_sessions_root now lazily migrates the legacy top-level path as of 2026-07-19 and surfaces a both-roots conflict instead of merging — SH12's project migration must fold this in).
6) SPOOL TOPIC MIGRATION (N7): the durable ingress spool persists topic strings; old pending agents.llm.* files become poison under a consumer accepting only agents.execution.*. Translate the two known trigger topics under lock, preserving event IDs/idempotency identity; leave or explicitly version historical dead-letters; test crash/restart mid-migration.
7) SUBSCRIPTION/MIRROR INVENTORY (N8): project-local subscriptions/user config can hold old topic strings — inventory and migrate owned config; document the breaking change for user-owned external integrations or record a real compatibility obligation.
8) RUNTIME QUIET GATE (N9): a source-code quiet window prevents merge conflicts, not live-state corruption — the operational gate requires service drained/stopped, no active leases, no active request/session work, recovery clean, ingress paused, migration locks held, protocol v2 parity.
9) EXACT SYMBOL MAP (N10): shorthand like 'list|close_llm_session' is ambiguous for automated cutover — freeze an exact old→new table for every Python symbol, service operation, MCP tool, topic, schema stem, service key, runtime directory, config key, and test fixture.

Execute as Stage 5 — after the SH07/SH10 repairs and the AS28/AS29 neutral seam, and before SH11's final descriptors/soak. Rewrite the migration steps to add the eight gaps above before implementation.
