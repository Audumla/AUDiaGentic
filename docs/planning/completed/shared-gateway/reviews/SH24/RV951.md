# Deepen workflow-driven management and replaceable queue design

## Notes

Use the existing persistent gpt-auto conversation as an architecture sounding board. Review the exact workflow configuration, operation/target/evidence separation, backend ports, crash consistency, MQTT suitability, and sequencing into implementable slices.

## Findings

Five-stage same-conversation review found the original SH24 design conflated three authorities: management-operation workflow, execution lifecycle, and future work delivery. Corrections incorporated:
- Workflow engine needs no generic enhancement; declare only accepted -> running|failed and running -> completed|failed plus state sets.
- ManagementOperationStore is authoritative and doubles as the outbox; ManagementWorkNotifier is advisory and carries only operation-id.
- Evidence LIVE|PROVEN_DEAD|UNKNOWN and target dispositions CHANGED|UNCHANGED|BLOCKED are not workflow states.
- Use gateway/maintenance rather than conflicting gateway/management_api.py; no speculative GatewayRecordRepository.
- Existing request/session stores retain execution authority; every destructive effect revalidates ownership.
- Maintenance tools belong to operator-only ag-agents-mgmt behind GatewayServiceManagementClient, never activity gateway_mcp.py or provider tool contexts.
- Agent Definition/Role is distinct from Provider: an Execution Profile selects a Provider backend/transport for a configured agent. SH24 operates on agent executions through request/session contracts, without provider-specific branches.
- Actual broker-backed normal work scheduling, durable session retention, and machine retention policy require SH25, AS107, and SH26 respectively.
- SH11 depends only on SH24 A-D.
- Per-operation timeline.ndjson is required by observability standards.
- Live gpt-auto execution showed a fixed 3900-second ceiling cancelling a still-streaming review, reinforcing SH22.

## Conclusion

All actionable findings are incorporated into SH24 and coordinated items SH10, SH11, SH22, SH25, SH26, AS91, AS95 and AS107. SH24 remains pending implementation; this review may close.
