# SH02 leaves an undocumented pre-manifest prompt compatibility route

## Notes

Post-completion implementation audit against Architecture Standards, Architecture Guidelines, Observability Standards, plan intent, and reuse-before-build doctrine.

## Findings

HIGH — SH02 persisted only `prompt-digest` and correctly threaded the raw prompt in-memory, but dispatch still accepted an optional `dispatch_prompt` and silently fell back to `record['prompt-body']` in both stateless and session paths. That retained an undocumented pre-manifest route and allowed new callers to bypass the admission contract.

## Conclusion

Resolved by making `dispatch_prompt` required throughout the dispatch chain and deleting both persisted-record fallbacks. Direct tests now supply the explicit in-memory prompt; focused dispatch, session-dispatch, API, and gateway integration validation passes (28 tests). No compatibility shim remains.
