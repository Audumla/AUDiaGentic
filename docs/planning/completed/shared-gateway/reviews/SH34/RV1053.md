# Sidebar project selection may open a conversation route

## Notes



## Findings

- Live gateway failures included project selection did not open a project page after the sidebar action.
- The CDP route matcher accepted only /g/<project>/project.
- A regression test now covers a sidebar action landing on /g/<project>/c/<id>.

## Conclusion

ChatGPT can open a project-scoped /c/<conversation> route after the sidebar New Chat action. Treating only /project as success causes false project-selection timeouts. Accept either route while preserving exact project identity and normalize the returned project URL to the project landing route.
