# Cut over all gateway consumers and retire in-process ownership

## Description

Finish automatic shared-gateway rollout only after the free-instance scheduler and supervision prerequisites. Consumer/descriptors/conformance slices A-D have landed; remaining soak/default work must certify AS101, not the hybrid scheduler.

## Steps

1. Preserve landed consumer/descriptors/conformance slices; do not repeat migration.
2. Require AS101 and the remaining SH10 lifecycle/admission proofs.
3. Require SH24 Slices A-D only: durable maintenance workflow/store/runner plus conservative reconcile. Archive, purge, SH26 policy, AS107 relocation, and SH25 broker migration do not block default cutover.
4. Soak multiple projects and provider-neutral agents, including browser, ACP, MCP/A2A-backed providers where available, same-model sources, cancellation, source loss, restart, reconcile, and recovery.
5. Assert exact durable/public source and provider session identity after restart.
6. Define fairness/wait/reservation/failure thresholds before soak.
7. Flip automatic to default only after repeated green soak and rollback rehearsal; rollback remains at the configuration boundary.

## Detailed Solution & Technical Design

SH11 owns rollout evidence/default, not scheduler, maintenance, archive, or broker mechanics. AS101 owns current scheduling/schema. SH24 A-D supplies operator-visible conservative reconciliation required for soak. SH25 later replaces the normal work queue behind the same provider-neutral gateway contracts and is deliberately not a prerequisite. MCP remains an adapter surface, not a special provider/lifecycle path.

Large rollout risk. Primary risk is certifying the hybrid implementation and making it default.

## Standards

Single implementation authority; evidence-led rollout; bounded resources; deterministic recovery; no hidden compatibility path.

## Acceptance Criteria

- Landed consumer/descriptors/conformance slices remain green and no consumer bypasses the shared client.
- AS101 and SH10 prerequisites are complete before soak/default flip.
- SH24 A-D is complete before soak/default flip; retention and broker migrations retain their independent gates.
- Soak proves cross-project fairness, configured-agent execution across roles/profiles/providers, exact persisted source identity, cancellation, crash/restart recovery, and bounded cleanup.
- Automatic/new gateway implementation becomes the only production authority only after repeated threshold-based green runs, a full durable-history visibility comparison, and rollback rehearsal.
- The cutover removes the old implementation selector, legacy scheduler/status/read path, compatibility shims, and obsolete production tests in the same migration. No production dual-run or fallback remains.
- Embedded remains valid only for tests/dev/service-host internals; deferred mcp-gateway remains disabled.
- Rollback is a bounded pre-cutover operational recovery procedure, not a permanent configuration fallback.
