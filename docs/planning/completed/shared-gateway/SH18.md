# Split three fat gateway modules into cohesive sub-modules (no behavior change)

## Description

Deep audit of components/agents found the gateway is correctly decomposed (~30 cohesive files, cross-component coupling is event-topic strings only, no internal-import bleed) but three modules each carry a second cleanly-separable concern that inflates them and hurts navigability. This item finishes the §3 decomposition those files already imply. All changes are mechanical relocations — cut a contiguous block into a new module, add one import back; no signature or logic changes. Fully covered by existing session/store/dispatch suites (import-path fixups only).

Explicitly NOT a consolidation: file-count philosophy is unchanged; this reduces lines-per-file, it does not merge files.
