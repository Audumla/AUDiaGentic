# Bounded retention sweep for gateway work-index quarantine directory

## Description

SH07's C7 work-index quarantine (agents_gateway_work_index.py quarantine_work_index_entry) preserves malformed/mismatched entries forever for forensic analysis. Nothing ever removes old quarantine entries, so the directory grows unbounded over the life of a machine. This is cleanup/hygiene, not a correctness gap, and was split out of SH07 so SH07's closure is not blocked on it.

## Steps

1. Add a bounded-retention sweep (e.g. clear_expired_quarantine_entries(service_root, *, max_age_seconds)) that deletes quarantine entries older than a threshold, called opportunistically during recovery or on a lightweight schedule.
2. Never touch valid active-work index entries — quarantine directory only.
3. Test: old quarantine entries beyond the threshold are removed; recent ones and all active entries are untouched.
