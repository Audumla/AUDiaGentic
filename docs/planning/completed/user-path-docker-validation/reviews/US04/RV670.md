# Exclude mutable runtime state from Docker build context

## Notes

Clean Docker build collection encountered a live mutable gateway-contract runtime directory.

## Findings

The Docker context re-includes .audiagentic broadly, then only excludes one test-temp path. Mutable runtime state is user-owned and should never be part of a reproducible test build context; this can make context collection fail on active/unreadable paths.

## Conclusion

Valid. Keep explicit user config/prompts/skills/planning inclusions, but exclude all .audiagentic/runtime paths from the build context. Do not delete or alter live runtime data.
