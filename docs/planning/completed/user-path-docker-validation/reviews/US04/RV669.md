# Make session input permission failures deterministic in Docker

## Notes

The Docker user-path validation runs as root, so chmod-only permission testing did not exercise the error contract.

## Findings

load_session_data swallowed individual PermissionError under a broad inner exception, while its documented/tested contract exposes IO-CTX-002. The mutable test was environment-dependent.

## Conclusion

Valid. Re-raise PermissionError from individual input reads, preserve recovery for malformed/non-permission records, and simulate the permission boundary with a targeted test monkeypatch so Docker validates the error contract under root.
