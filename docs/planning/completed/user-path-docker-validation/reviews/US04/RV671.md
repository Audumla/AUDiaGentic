# Normalize clean Docker runner line endings

## Notes

Fresh Linux Docker image execution failed before test discovery.

## Findings

tests/docker/run_suite.sh contained CRLF line endings. Bash interpreted pipefail and pytest flags with trailing carriage returns, so the clean suite could not run.

## Conclusion

Implemented: tests/docker/run_suite.sh is LF-only. Fresh clean-image builds invoke the entrypoint successfully; focused clean Docker tests passed (ACP transport, lifecycle marker coverage, and SH06 worker protocol selection).
