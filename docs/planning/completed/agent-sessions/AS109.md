# Point GPT-auto window anchor to gateway dashboard

## Description

Update GPT-auto's provider-private dedicated-window anchor so it navigates to the gateway-owned HTTP dashboard. Preserve old data-URL dashboard/anchor tabs by reusing and repointing them at provider startup without giving the gateway browser responsibilities.

## Steps

- Publish the actual configured dashboard URL from the gateway host process.
- Resolve that URL in GPT-auto without importing gateway service internals.
- Reuse/repoint legacy dashboard and blank-anchor tabs, otherwise create a new dashboard tab in the dedicated window.
- Add deterministic runtime and host tests; do not restart the active gateway.
