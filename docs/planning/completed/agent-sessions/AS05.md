# API + MCP surface: session params on submit/run, session list/close tools, overview

## Description

Expose sessions through agents_gateway_api and the ag-agents-gateway MCP server so a coordinating client (Claude) can open a keep-alive session, continue it across requests, inspect it, and close it. The 300s MCP transport cap discipline (RV511) applies unchanged — session turns are just requests.

## Steps

1. agents_gateway_api: submit_llm_request/run_llm_request accept session_id: str|None and session_keep_alive: bool = False and session_idle_timeout_seconds: float|None; pass into build_record. Responses include 'session-id' when set.
2. New API functions: list_llm_sessions(project_root) (registry + persisted records merged: live flag from runtime, durable state from store), close_llm_session(project_root, session_id) (client-request close; idempotent; returns final session record).
3. gateway_overview: add sessions block {active-count, sessions: [session-id, agent-profile-id, provider-id, state, last-activity-at, turn-count]}.
4. MCP tools in agents_gateway_mcp: agent_llm_run/agent_llm_submit gain the three session params (documented: keep-alive opens, session-id continues, close when done or let idle timeout reap — state the defaults in the tool docstring so remote callers know sessions self-clean); new tools agent_llm_session_list, agent_llm_session_close. _mcp_capped applies to waits as today; opening a session does not change wait semantics.
5. reconcile_gateway_state extension: sessions persisted 'active' whose owning process is gone (no live handle in this process's runtime) are transitioned 'failed' with close-reason 'orphaned' (mirrors INT-AGW-ORPHANED for requests).

src/audiagentic/components/agents/agents_gateway_api.py; src/audiagentic/components/agents/agents_gateway_mcp.py

## Validation

Unit tests: run with keep-alive returns session-id; second run with that session-id hits the same runtime session; close tool idempotent; overview shows session; reconcile marks orphaned sessions failed. Existing gateway API/MCP tests unchanged.
