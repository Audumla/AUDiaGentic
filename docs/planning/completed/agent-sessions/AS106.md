# gpt-auto provider owns its browser lifecycle

## Description

The gpt-auto provider currently assumes an already-running Chrome/Brave on port 9222. It should launch and manage its own browser instance with cross-platform support, using the foundation/system managed process infrastructure.

## Steps

1. Add browser_manager.py to foundation/system/ with cross-platform binary detection and launch
2. Add GptAutoConfig fields: browser_port (default 9222), browser_profile_dir (default .audiagentic/runtime/gpt-auto-profile), browser_autostart (default true), browser_idle_timeout_seconds (default 300)
3. Wire browser_manager into session_transport.open() — start browser before CDP connect if not running
4. Add browser_manager cleanup to session_transport.close() after idle timeout or when last session closes
5. Add probe for browser binary availability in provider capability check

## Detailed Solution & Technical Design

Add foundation/system/browser_manager.py (reuses managed_process + probe):

1. **Platform detection**: Use os.name to pick strategy — Windows registry for default browser, defaults on macOS, xdg-settings on Linux
2. **Binary discovery**: Chrome → Brave → Edge → Firefox on Windows; Chrome → Safari (fallback) on macOS; Chrome → Firefox on Linux
3. **Launch command**: `browser --remote-debugging-port={port} --user-data-dir={profile_dir}` with configurable port from provider config
4. **Managed process**: Use launch_detached() from foundation/system/managed_process.py for lifecycle ownership with PID evidence and cleanup
5. **Profile isolation**: Dedicated profile under .audiagentic/runtime/gpt-auto-profile/ (configurable via browser_profile_dir)
6. **Lifecycle hooks**: Browser starts on first session open(), stays alive across sessions, stops when all sessions close after idle_timeout or provider unloads
7. **Port conflict handling**: Check if port is occupied before launch; fail gracefully with RES-AGW error if another process owns it — never kill existing processes
8. **Readiness check**: Poll http://127.0.0.1:{port}/json/version until browser responds (max 30s)
