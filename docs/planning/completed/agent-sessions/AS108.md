# Move status dashboard into gateway HTTP service

## Description

Replace the GPT-auto browser-rendered dashboard with a gateway-owned, configurable HTTP status page. The page must expose durable request history, live sessions and per-session pending work, queues, provider readiness, and failures without using browser automation.

## Steps

- Define a redacted gateway dashboard snapshot that joins durable records, live session snapshots, queue depths, and provider diagnostics.
- Serve the page and JSON snapshot from the standalone gateway HTTP service on a configurable path/port without changing the active process.
- Remove GPT-auto runtime ownership and browser/CDP dashboard refresh paths.
- Add unit/integration coverage for HTTP access, snapshot completeness, redaction, configuration, and no browser coupling.
- Validate focused gateway and GPT-auto suites.
