# Expose redacted queue-authoritative compute diagnostics

## Description

Add the bounded O2 operator view that is actually needed: per-request/session computing, queued-on-session, quiescent/idle, duration, pending count, and profile slot attribution. Queue accounting is the sole authority; diagnostics are transient read-only projections, not another scheduler state store.

## Steps

1. Inspect the current AS16 implementation in `src/audiagentic/components/agents/agents_gateway_api.py`, `agents_gateway_queue.py`, `agents_gateway_sessions.py`, `agents_gateway_sessions_store.py`, `agents_gateway_client.py`, `agents_gateway_application.py`, `agents_gateway_service_application.py`, `agents_gateway_remote_client.py`, and `agents_gateway_mcp.py` before editing. Preserve existing dirty-tree changes; do not revert or rewrite unrelated gateway/provider edits.
2. Fix the first-turn request-to-session diagnostic gap: when a keep-alive request opens a session, make the live session id observable to `request_runtime_status(project_root, request_id)` during the active first turn. Prefer an owner-epoch-protected durable update immediately after successful session open; alternatively add a request-id lookup in `SessionRuntime` if that better matches current code. Do not persist prompt/output/provider refs.
3. Add a first-turn diagnostic regression test in `tests/integration/agents/test_gateway_e2e_states.py` or the closest existing gateway session test. It must prove a running keep-alive first turn reports the live `session-id`/session availability before terminal completion.
4. Add the closed diagnostics operation through the public stack: `GatewayClient` protocol, `InProcessGatewayClient`, `GatewayApplication`, standalone service invocation, remote client, and MCP read surface should expose request runtime diagnostics without starting `SessionRuntime` for durable-only reads.
5. Add immutable-snapshot/race coverage around queue/session diagnostic counts in `tests/unit/agents/test_agents_gateway_queue.py` and/or `tests/unit/agents/test_agents_gateway_sessions.py`: no impossible slot counts, `running`, `idle`, `active_running`, pending, and session lock facts reconcile from one snapshot.
6. Validation: run the narrow new/changed tests first, then `python -m pytest tests/unit/agents tests/integration/agents/test_gateway_e2e_states.py -q` if narrow tests pass. Record a ledger event with `plan-item-ids: ["AS16"]` after source changes. Do not mark AS16 completed until overseer review confirms all RV722 gaps are closed.
