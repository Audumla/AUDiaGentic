# Circular gate: step 1 collects the evidence the item is blocked on; measurement is not a small tail of AS85

## Notes

Two-turn adversarial review, 2026-08-09. Reviewer's sharpest finding: AS85 persists the resolved manifest/fingerprint, which proves what capability was MADE AVAILABLE, not what was actually USED — so an evidence period run on AS85 alone may collect the wrong evidence. This exposes a circularity in AS104 as written: blocked-by says AS85 must have been running in practice, yet AS104's own step 1 is 'collect real job and workflow capability usage'. The item is gated on evidence it is itself responsible for collecting. Reviewer initially proposed measurement as 'a small tail of AS85' then retracted that under challenge, giving a concrete hook analysis instead: the shared MCP decorator already centrally observes every decorated AUDiaGentic tool invocation (identity/timing only, deliberately not arguments), and AS85 supplies role identity + manifest fingerprint for attribution — but provider-NATIVE behaviour (shell, native file ops, provider plugins/hooks) is not centrally observable, and making it so is a large separate project. Corroborated by adjacent plans: Pi's tool_execution_* tap frames are not transcript-proven, OpenCode tool-call behaviour is still unproven in AS97.

## Findings



## Conclusion

Split AS104's internal sequencing into two gates rather than one: (a) measurement plumbing may start once AS85's identity/manifest contract is stable; (b) presets/escalation gates/migration/role-less-default removal stay gated on real accumulated usage evidence. Scope measurement to launch/materialization evidence plus AUDiaGentic-owned operations (M); explicitly exclude universal provider-native instrumentation (L+). Adopt the governing rule: 'not observed' must never mean 'unused' — classify each capability's evidence mode (materialized / observed-use / controlled-trial / unmeasured), and require positive evidence (e.g. a representative workflow run successfully without it) to drop an unobservable capability from a preset, never telemetry silence. AS85 gains no scope: it remains responsible only for carrying role/manifest identity.
