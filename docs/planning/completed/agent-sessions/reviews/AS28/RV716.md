# Target the AS29 manifest directly; close the unknown-kind leak and raw-ref/cancel-disposition gaps (verified)

## Notes

Source: external plan/code review 2026-07-18; verified 2026-07-19 (_map_kind in foundation/transports/acp.py returns the raw kind for unknown events; SessionRuntime.request_cancel returns True on scheduling alone).

## Findings

1) DOUBLE DESCRIPTOR MIGRATION (P1): AS28 as written creates ProviderDescriptor.session_control_surfaces, which AS29 immediately replaces with session_surfaces. Required rewrite: AS28 defines the neutral transport/control contract and ACP wrapper only; its provider-factory and SessionRuntime migration target the AS29 manifest directly; remove all instructions to create session_control_surfaces.
2) UNKNOWN-KIND LEAK (Medium, C15): current ACP mapping passes unknown raw kinds through as canonical kinds despite the claimed closed vocabulary. AS28's neutral seam must not preserve this: unknown native frames map to a bounded neutral unknown/transport observation or are dropped with a diagnostic counter — never auto-promoted to a new canonical kind.
3) CANCEL DISPOSITION (Medium, C13): request_cancel is optimistic (true = signal scheduled, not provider acceptance). AS28's canonical control disposition is the repair; until it lands, status wording must say 'signal scheduling attempted', not acceptance.
4) RAW REF IN OBSERVATIONS (P12): TransportObservation.session_ref must carry canonical AG correlation (AG session id, turn/request id, sequence), never the protected provider session ref — the raw ref lives only in the AS30 protected binding.
5) STANDARDS SECTION BLANK (P23): before implementation cite the standards relied on: public provider API boundary, foundation neutrality/reuse, one durable artifact owner, explicit migration/deletion gates, redaction, event/timeline authority.

## Conclusion

AS28 remains critical and valid but must be rewritten before implementation: neutral foundation contracts first, factories/migration retargeted at AS29, no intermediate descriptor field, no raw refs in observations.
