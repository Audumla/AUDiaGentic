# Separate session supervision from machine-wide shared gateway ownership

## Notes



## Findings

AS08 currently says it will create the supervised gateway daemon and move both session and worker ownership cross-process. The newly approved requirement is broader: one machine-wide gateway for multiple projects/harnesses, explicit execution context, service discovery/self-start, durable ownership, resource arbitration, and lifecycle management. Leaving daemon ownership in AS08 would duplicate SH01–SH11 and invite scope creep. AS08 should instead own how persistent agent-session semantics integrate with the shared gateway control plane and its context-isolated workers.

## Conclusion

Narrow AS08 to session integration. Shared-gateway owns the service/control-plane and reusable process lifecycle remains in PR05; AS08 retains session registry, turn serialization, session worker ownership policy, attach/resume behavior, expiry, and no-orphan validation.
