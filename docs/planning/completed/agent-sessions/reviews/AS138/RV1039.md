## Notes



## Findings

- A durable provider identity must not bypass recovery exhaustion indefinitely.
- A failed local session must remain immutable; automatic restart recovery may create only an exact-provider receive-only successor observer.
- Ambiguous provider work must never be replayed; missing or unreadable session records must fall back to bounded recovery.
- Request completion must be deduplicated against the durable provider attempt and late exact-provider completion must win over stale local failure.

## Conclusion

Incorporated the bounded terminal-session guard and the restart-only failed-session successor path. Full live CDP validation remains dependent on an attached browser and provider transport supporting resume_existing.
