# Project selection toggles sidebar instead of opening a new chat

## Notes



## Findings

- New-session startup tries to open the Projects route through the sidebar before checking whether the configured project is already visible.
- Sidebar fallback repeatedly clicks a collapsed project row while polling, allowing expansion state to oscillate instead of performing one deliberate expansion.
- Composer insertion and Send currently use a configurable 0.15 second browser-action pause, below the observed one-second renderer settling requirement.

## Conclusion

Search the visible sidebar first across Projects and Pinned, expand at most once, navigate directly to /projects only when no exact sidebar project is available, and enforce one-second minimum page-to-entry and entry-to-send pauses.
