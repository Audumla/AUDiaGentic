# Closed GPT sessions must retain conversation focus

## Notes



## Findings

- The dashboard modeled conversation focus as a request-row action even though every request in a gateway session shares one provider conversation and browser tab.
- Closed, failed, and expired sessions can retain a valid durable ChatGPT conversation URL after no request remains active.

## Conclusion

Move the single open/focus action to the session header, resolve focus by session id and durable session provider metadata, retain request-id handling only for compatibility, and do not resume or mutate session lifecycle state.
