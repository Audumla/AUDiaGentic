# Session cleanup must preserve nonterminal request ownership

## Notes



## Findings

- The new durable idle sweep could expire a non-live session without checking whether queued or running requests still referenced it, violating the request/session lifecycle invariant.

## Conclusion

Guard all independent session expiry against durable nonterminal request ownership; terminalize or rebind requests before session closure.
