# Move AS138 recovery policy into GPT-auto workflow configuration

## Notes

This is a findings-driven correction to AS138, not a replacement of its failure-evidence semantics.

## Findings

The implementation correctly routes DOM evidence and failure classification through the GPT-auto workflow, but dispatch.py still hard-codes network-error recovery limits and prompt text, while gpt_auto_cdp.py hard-codes the action pause. This leaves the recovery behavior outside the configured workflow and makes policy changes require code edits.

## Conclusion

Add explicit, validated GPT-auto turn configuration for network-error recovery and browser action pacing. Keep request/session safety checks in dispatch code, but obtain enablement, attempt limits, prompt template, and pause duration from the resolved config.
