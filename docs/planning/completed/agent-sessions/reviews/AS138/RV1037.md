# Live restart recovery exposed bounded retry and prior-window tab gaps

## Notes

The live request was req_55873b602cca43c6; its retained tab and provider URL were verified directly through CDP. The request was not replayed.

## Findings

- A live GPT review request was interrupted with CON-AGW-084 after gateway restart even though its provider conversation URL and CDP tab remained available.
- The generic recovery-attempt bound incorrectly applied to durable provider-session reattachment.
- Exact conversation lookup was constrained to the newly recreated dedicated window, excluding the retained tab in the prior Brave window.

## Conclusion

Implement durable provider-session retry beyond the generic bound and prefer, then fall back to, exact provider-conversation matches across CDP windows. Add regression coverage for both behaviors.
