# Idle tab leases and stale lifecycle reconciliation regressions

## Notes



## Findings

- Persisted physical-tab lease digest includes process-local dom_activity_digest, so gateway restart/reattach renews unchanged tabs and defeats the 7200-second cleanup deadline.
- The live store contains 115 active-but-non-live sessions, all older than their 43200-second session idle policy; durable non-live sessions are not independently swept.
- req_example_76827029a5806633 remains running although ses_example_3956b7cbd42b35da is durably failed since 2026-10-01; restart takeover did not reconcile the terminal session/request mismatch.
- Browser CDP currently exposes 29 project conversation tabs; the durable lease store knows only 20, so legacy/unleased owned tabs are outside the current reaper authority.

## Conclusion

P0 lifecycle repair required: make lease identity restart-stable, add independent durable session idle reconciliation, and terminal/reconcile requests whose bound session is already terminal without using synthetic activity as inactivity proof.
