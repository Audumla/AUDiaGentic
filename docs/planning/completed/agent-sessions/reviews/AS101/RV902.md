# AS101 scheduler architecture review

## Notes



## Findings

The queue remains a hybrid: per-profile lanes/semaphores and legacy queue limits coexist with resource gating; mixed candidate sets fail; source identity is not durable; legacy fallback synthesizes identity; scheduler state is concentrated in queue.py; fairness/recovery tests do not prove exact source placement.

## Conclusion

Reopen scheduler and persistence slices. Implement one pending authority, source-bound durable dispatch identity, schema migration/fail-closed recovery, deterministic timing, and explicit removal of all lane/limit legacy.
