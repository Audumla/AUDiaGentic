# Architectural pivot: capacity model relocated into providers' model-sources.yaml, not a separate agents-owned taxonomy

## Notes

Owner correction 2026-08-08: 'model management should be under the provider mgmt mcp' surfaced that providers already owns a master model catalog (model-sources.yaml) with its own project-local/user-global-eligible layering and provider-projection mechanism (apply_model_sources). Building ComputeResource/ModelInstance as new agents-owned files duplicated ownership and risked a second, competing catalog.
