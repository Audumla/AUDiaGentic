# AS14 App Server event mapping and lifecycle review

## Notes



## Findings

1. **Neutral-event surface is correct** — Mapping App Server events into the frozen canonical kinds (same as ACP) means SessionRuntime and dispatch are transport-agnostic. This is exactly what AS19's YAML workflows require.

2. **External process ownership mode needs lifecycle events** — When close() detaches instead of terminating, the session lifecycle event (agents.session.closed) should distinguish 'detached' from 'terminated' so operators and AS23 replay can reconcile correctly.

3. **App Server transport is a new harness to profile for AS22** — Once this lands, it becomes a candidate for the one-harness-at-a-time probe pipeline.

## Conclusion

No blockers; event mapping is the key design decision
