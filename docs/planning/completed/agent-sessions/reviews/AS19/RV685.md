# Remove ACP from the gateway-facing observer/control contract

## Notes



## Findings

AS19 currently describes an `AcpStatusObserver` lease with `on_transport_event(AcpEvent)`, while `agents_gateway_sessions.py` imports AcpLaunch/AcpSessionTransport/AcpResult directly. This exposes ACP as the gateway control model and would force future native harness controls to imitate ACP. ACP must instead be a provider-declared execution surface behind a foundation-owned session transport/control contract. Hooks/plugins may provide observations only; they cannot become an alternate turn controller.

## Conclusion

Create a prerequisite plan item defining the neutral session transport, control, observation, capability, error, and migration semantics. Amend AS19 to consume its opaque transport observation/control contracts, leaving ACP mapping in the provider/foundation adapter.
