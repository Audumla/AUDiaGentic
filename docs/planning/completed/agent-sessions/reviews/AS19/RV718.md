# Consolidate onto the AS29 manifest with a generic neutral-observation mapper; declare delivery topology; fix preparation order

## Notes

Source: external plan/code review 2026-07-18; assessed 2026-07-19.

## Findings

1) NO SECOND DECLARATION ISLAND (P4): drop ProviderDescriptor.harness_status_observers — observer/lifecycle declaration lives in AS29 session_surfaces.lifecycle. AS19 owns ingress, managed hook/plugin reconciliation, normalized StatusEvidence, and observer leases — not another provider descriptor list.
2) GENERIC RECIPE-A MAPPER (P5): after AS28, provider adapters already map native frames to the neutral TransportObservation vocabulary. AS19/AS27/AS32 each proposing provider-local status_observer.py files re-mapping that same vocabulary is avoidable duplication. Required model: AS28 adapter (native→neutral observation); ONE generic AS19 transport observer (neutral observation→canonical StatusEvidence, constrained by the resolved AS29 surface); provider-specific AS19 normalizers only for raw hook/plugin/native-API envelopes that never passed through AS28. Test: two fake providers work with zero provider-specific mapper code.
3) DELIVERY TOPOLOGY (P6): per-session loopback collector + env token assumes same-host/same-namespace launch. Declare delivery topology in the session surface: inherited structured stream, same-network loopback HTTP, unix socket/named pipe, supported remote callback, native API subscription. Managed hooks via loopback are supported only when launch ownership and network namespace make the route reachable; external attach needs a separate probe, not an inherited claim.
4) PREPARATION ORDER (P7): current order (prepare transport → open observer lease → merge observer env into the prepared transport) mutates an allegedly frozen prepared transport. Required order: resolve immutable surface → open observer lease from the surface → prepare transport WITH the sanctioned observer launch context → open transport → bind canonical AG/session/turn correlation.

## Conclusion

Keep AS19's ingress/normalization scope; remove its descriptor field and provider-local re-mapping; add topology declaration and the corrected preparation order before implementation.
