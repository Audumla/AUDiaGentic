# AS09 event fan-out infrastructure reuse review

## Notes



## Findings

1. **Event fan-out should use EventBus, not a new mechanism** — The per-session bounded ring buffer + subscription cursor is essentially a local EventBus with persistence. Consider whether the existing EventBus + FileEventStore can serve this purpose instead of building a separate fan-out mechanism.

2. **SAFE in-flight interaction** — The RV518 constraint about not killing transport on cancel is critical. This should tie into AS20's completion arbiter (AS21) which understands coarse states and can distinguish between 'turn actively computing' and 'turn waiting'.

## Conclusion

No blockers; confirm event fan-out reuses EventBus
