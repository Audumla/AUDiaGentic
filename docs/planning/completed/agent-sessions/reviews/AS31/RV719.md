# Two incompatible persistence designs; needs coalescing, AG-only correlation, and TOOL_SUMMARY removal — do not implement as written

## Notes

Source: external plan/code review 2026-07-18; assessed 2026-07-19.

## Findings

1) CONTRADICTORY STORAGE DESIGNS (P10): the item first requires NDJSON append with an append lock and append+flush+fsync helper, then later declares that replaced by one-atomic-file-per-event with an atomic index and no NDJSON append. Step 10 is also textually joined onto step 9. Required rewrite: keep exactly one design — either the atomic event-file/index design or a deliberately chosen framed append log with recovery. Not both.
2) WRITE AMPLIFICATION (P11): one file + atomic index write per provider token/delta is severe amplification. The relay must coalesce source deltas into bounded AG output fragments by max bytes, short flush interval, final/turn boundary, and backpressure; persist AG relay sequence plus source sequence range.
3) RAW REF LEAK (P12): AgentOutputEvent.session_ref risks carrying the protected provider session ref. Use canonical AG correlation only: AG session id, AG turn/request id, relay sequence. The provider ref lives only in the protected AS30 binding.
4) TOOL_SUMMARY SPECULATIVE (P13): the item excludes tool arguments/results yet includes an optional tool-summary content kind with no cross-provider use case. Remove from v1; re-add only with two proven surfaces, a clear user-facing use case, and its own redaction policy.
5) STANDARDS SECTION BLANK (P23): cite redaction, one durable artifact owner, event/timeline authority, existing final-request-output contract before implementation.
6) Preserved strengths: content/lifecycle separation and the existing final-output contract remaining authoritative are correct — keep them.

## Conclusion

Does not hold as written. Rewrite the persistence steps to one design plus coalescing before any coding; then required tests: coalesced fragments, event-file/index crash adoption, no per-token file explosion, no provider ref in content events, no tool summary in v1.
