# Session dispatch bypasses the approved providers public API

## Notes

Post-completion implementation audit against Architecture Standards, Architecture Guidelines, Observability Standards, plan intent, and reuse-before-build doctrine.

## Findings

HIGH — `agents_gateway_dispatch.py` imports `providers.services.execution.execute_provider` and `load_acp_launch_builder` directly. Architecture Standards §1 permits cross-component access only through `providers.providers_api`; §6 forbids requester imports of provider services/adapters. AS04's functionality works, but its implementation entrenches the exact reverse/internal boundary MA17 is intended to remove.

## Conclusion

Do not add another session-specific seam. Fold both one-shot execution and ACP launch resolution into MA17's typed providers public execution boundary, migrate agents callers, then delete the direct service imports and add an architecture guard.
