# Validate session-record mutation locking against shared-service architecture

## Notes



## Findings

Controller architecture/reuse audit on 2026-07-19 found that `agents_gateway_sessions_store.py` protects `transition_session_record()` and `record_session_turn()` with process-local `threading.Lock` objects, while related request-record mutation and binding-index mutation use foundation `StartupLock`. This may be acceptable only if the standalone shared service is the single writer for all public session mutations. AS08/AS30 shared-client and race-proofing language should be made explicit in implementation or tests.

## Conclusion

Keep open until AS30/AS08 either documents and tests the single-writer invariant or changes session-record mutation to a per-session foundation cross-process lock with a two-process lost-update test.
