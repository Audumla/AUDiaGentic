# Consolidate managed-config descriptors, registry, and sync core

## Description

Extract domain-neutral managed-config types, path resolution, ownership registry, sync/reload core, and migrate MCP with public parity. LSP descriptor loading may adopt the generic spec, but LSP ownership/reconciliation migration is delegated to MA08 after core stability.

## Steps

1. Record full unit baseline and focused MCP/descriptor golden outputs before edits.
2. Add foundation ManagedConfigSpec with exact fields: config_path, reader, writer, remover, format="", refresh_mode="none", reload_fn=None, capabilities=frozenset(). Payload callables use Any/Protocol; foundation imports no components.
3. Add resolve_managed_config_path: callable result normalized to Path; string expands `~`; absolute kept; relative joins project_root. Callable returning None/non-path raises canonical VAL error.
4. ProviderDescriptor holds `managed_configs: dict[str, ManagedConfigSpec]`. One loader builder maps existing YAML `mcp_config`→`mcp`, `language_servers_config`→`language-servers`; YAML stays stable. Delete McpConfigSpec/LanguageServersConfigSpec and coding_lsp type import—no Python shim.
5. Implement ManagedFragmentRegistry(project_root, filename, top_level_key="owners", contract_version="v1") using atomic IO, schema/type validation, and shared lazy-loading support. Missing file→empty; malformed/corrupt→canonical error; never empty fallback.
6. Preserve existing managed-mcp-servers.json shape using instance filename/top_level_key="providers". Add byte/semantic roundtrip golden before deleting managed_mcp_registry.py.
7. Implement sync_managed_config(spec, registry, owner_scope, desired, managed_ids=None) over reconcile_fragments. Return normalized result {ok, changed, path, updated, removed, collisions, reload}. Define partial collision semantics exactly as ReconcileResult.
8. Implement reload_managed_config: none→no-op; file-watch→auto_refreshed; restart-required with no fn→action_needed; reload_fn success/failure normalized/redacted. No domain/provider display text in foundation—caller supplies label/action text.
9. Rewire MCP public add/remove/list/reload/sync/subset functions through core. Preserve public result keys and errors; direct user add/remove remains explicit unmanaged operation and does not enter ownership registry unless API currently promises ownership.
10. Provider descriptor exposes compatibility properties `mcp_config`/`language_servers_config` only if required by same-change consumers? Prefer update all consumers and no shim; whole-repo compile/grep decides. §10 forbids persistent shim.
11. LSP continues current direct behavior temporarily but consumes descriptor.managed_configs["language-servers"] and shared path resolver. Add explicit TODO/architecture allowlist owned by MA08; no new direct writers.
12. Delete old classes, builders, local path resolvers, managed_mcp_registry module, imports, and string patch targets atomically. Update MA01 audit rows/guard expected state.
