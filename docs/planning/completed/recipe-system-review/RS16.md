# Implement shell output redaction and safe summaries

## Description

Small execution slice for RS05. After RS15 characterization tests land, implement redaction/truncation for shell provisioning outputs without changing command execution semantics. Target only the leak paths identified by RS15.

Dependency: RS15 must be completed first. RS15 test suite serves as negative baseline; these same tests must pass with redacted output after implementation.

## Steps

1. Confirm RS15's 4 leak-characterization tests are committed and currently passing (proving the leak).
2. Create `src/audiagentic/foundation/logging/redaction.py` (NEW, shared/reusable — not under `toolchains/` so non-recipe modules can import it without pulling in recipe machinery; see OU01 which consumes this module):
```python
from __future__ import annotations
import re

_DEFAULT_PATTERNS: tuple[re.Pattern, ...] = (
    re.compile(r"bearer\s+[a-zA-Z0-9._-]{20,}", re.IGNORECASE),
    re.compile(r"\b(sk|pk|ghp|gho|ghu|ghs|ghr)-[a-zA-Z0-9]{20,}\b"),
    re.compile(r"\b[a-zA-Z0-9+/]{40,}={0,2}\b"),  # long base64-shaped tokens
    re.compile(r"(?i)\b(api[_-]?key|token|secret|password)\b\s*[:=]\s*\S+"),
)

def redact_text(text: str, extra_patterns: list[re.Pattern] | None = None) -> str:
    """Replace secret-shaped substrings with [REDACTED]. Pure function, no I/O."""
    if not text:
        return text
    patterns = (*_DEFAULT_PATTERNS, *(extra_patterns or ()))
    for pattern in patterns:
        text = pattern.sub("[REDACTED]", text)
    return text

def redact_env_like(env: dict[str, str]) -> dict[str, str]:
    """Redact values whose key looks like a secret (KEY/TOKEN/SECRET/PASSWORD)."""
    sensitive = re.compile(r"(?i)key|token|secret|password")
    return {k: ("[REDACTED]" if sensitive.search(k) else v) for k, v in env.items()}
```
Adjust the regexes to match RS15's actual test fixtures exactly (the token strings used in its tests must trigger these patterns — run RS15's tests against this module directly first before wiring it into `shell.py`).
3. Wire redaction into `shell.py::_run_argv()` and `_run_shell()`: after building the `StepResult`, apply `redact_text()` to `outputs["stdout"]` and to `reason` before returning. Preserve `outputs["command"]`, `outputs["returncode"]` (exit code is not secret) but also run `redact_text()` over the joined command string in case a literal secret was passed as an argument.

6. Run RS15's 4 tests again with the fix in place — each assertion must now be INVERTED from RS15 (assert the raw secret is NOT present, `[REDACTED]` IS present).
