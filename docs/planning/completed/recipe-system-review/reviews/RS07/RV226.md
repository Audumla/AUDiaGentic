# Missing guards for dynamic class assembly, factory completeness, and double-stamping

## Notes

Validated missing guard coverage and test path. Incorporated into RS07 and RS19.

## Findings

RS19 (and parent RS07) target architecture guard tests. Existing test_architecture_boundaries.py covers import boundaries and MCP-specific helpers.

**Gap: Missing recipe-specific regression guards**

The current architecture tests don't cover:

1. **Double-stamping detection**: No static or dynamic test verifies that a single lifecycle operation doesn't produce double-provenance results (i.e., ProviderRecipeResult fields set by both `_stamped()` and `to_result()`).

2. **Foundation step import safety**: The architecture test checks `foundation/toolchains` doesn't import providers, but doesn't check that `components/memory/hindsight/recipes.py` doesn't import individual provider adapters (e.g., `adapters/claude`, `adapters/codex`). Currently it imports only from `providers/services/mcp` and `providers/services/recipes`, which is correct.

3. **Recipe kind coverage**: RS19 should add a test that every ProviderRecipeKind in the matrix has a corresponding factory in `_RECIPE_FACTORIES` (strategies.py:244-251). Missing mapping causes silent fallback to guidance-only.

4. **Assembled recipe integrity**: The `_create_assembled_recipe_class` dynamic class creation (recipe_spec.py:273-301) binds lifecycle methods via closure over `delegate`. No test verifies that:
   - All 6 primitives (probe, install, configure, verify, uninstall, prune) are bound
   - Status overrides don't leave orphaned delegate calls
   - provision() and teardown() are inherited correctly from the base class

5. **Recipe matrix completeness**: Test that every row in HINDSIGHT_RECIPE_MATRIX has source_url and source_date when source_status == 'verified'. (Already covered at test_architecture_boundaries.py:317-328, but only as part of TestProviderRecipeTests — RS07 should reference it.)

**Recommendation**: Add to RS19 file list: "[TEST] tests/unit/memory/hindsight/test_assembled_recipes.py" for assembled recipe integrity. Add RS07 validation: "Test proves _RECIPE_FACTORIES covers all ProviderRecipeKind values present in the matrix."
