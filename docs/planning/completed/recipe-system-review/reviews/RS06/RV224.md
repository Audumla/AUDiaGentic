# Artifact registry gap in direct writes and result construction mutations

## Notes

Validated direct mutation list, managed MCP primitive, and artifact registry gap. Incorporated into RS06, RS17, and RS18.

## Findings

RS06 correctly targets direct mutations in Hindsight recipes. The grep confirms three locations:

1. `_repair_windows_plugin_mcp()` (plugin_recipes.py:276) — `mcp_path.write_text(json.dumps(...))`
2. `_PluginUrlConfigRecipe.configure()` (line 406) — `self._url_config_path.write_text(...)`
3. `_PluginUrlConfigRecipe.prune()` (line 441) — `self._url_config_path.unlink(missing_ok=True)`

**Gap: Additional indirect mutations not classified**

Beyond direct Python file I/O, there are mutation paths that deserve classification:

1. **Managed MCP sync** (`_sync_hindsight_mcp_entry` at recipes.py:48-69) — writes provider harness config via `sync_managed_provider_mcp_subset()`. This IS the sanctioned write path (per HM21/RV155), but RS06 should classify it as "intentional shared primitive" to distinguish from ad hoc writes.

2. **ProviderRecipeRegistry fallback path** (recipes.py:318-340) — creates ProviderRecipeResult with direct attribute access. Not file mutation, but it's a direct object construction that bypasses `to_result()`. RS06 notes about "direct mutation" could apply to result construction patterns.

3. **lifecycle.py _reconcile** (lines 109, 116) — constructs ProviderRecipeResult directly as fallback. Same concern as #2.

**Gap: Artifact registry integration gap**

The three direct mutations in plugin_recipes.py don't register artifacts with ArtifactRegistry. ConfigSetStep and WriteFileStep both register artifacts (lines 42-45, 53-57 of their respective files), but `_PluginUrlConfigRecipe.configure()` writes the URL config file directly without registering it for later prune. This means:
- The file IS tracked in `artifacts_owned` returned by the recipe
- But it's NOT registered with ArtifactRegistry for automated cleanup
- If teardown fails partway, the orphaned file won't be cleaned up by artifact registry

**Recommendation**: Add to RS06 classification: "_PluginUrlConfigRecipe URL config write is not ArtifactRegistry-tracked; classify as 'needs registration' or document rationale for exemption."
