# Audit and tighten recipe lifecycle contract semantics

## Description

Review the foundation recipe contract for lifecycle clarity, result semantics, and maintenance safety. The current contract is a strong base: `RecipeResult`, `RecipeState`, `ProvisioningRecipe`, `run_steps`, default `provision()`, and default `teardown()` are domain-neutral and reusable. This item makes the contract implementation-ready for downstream cleanup by locking semantics with tests and documentation.

## Steps

   - Idempotent short-circuit on already-verified probe: COVERED by `test_provision_short_circuits_when_present`.
