# SA08 — Split tracked project policy from private project configuration

## Description

Provide a safe source-controlled project policy lane (`.audiagentic-project/`) without exposing local instances or secrets. Based on SEC-10 from the security audit.

## Steps

1. Define `.audiagentic-project/` directory structure with strict schemas
2. Add schemas for `project.yaml`, `roles.yaml`, `provider-requirements.yaml`, `quality-gates.yaml`
3. Prohibit credential and endpoint-instance fields in the tracked policy schemas
4. Define merge precedence: tracked policy < user-global < project-private < machine-private < environment
5. Update documentation and CLI status to show layer source
6. Keep `.audiagentic/` always private and always ignored
7. Ensure private runtime configuration never merges back into the tracked policy files
