# Harden completion signal scoping: role-specific aria-label for completion-control, semantic .agent-turn container instead of fixed-depth parent walk

## Description

User-directed hardening pass following tonight's investigation. Two concrete improvements to reduce reliance on fragile assumptions: (1) confirmed live that [data-testid="copy-turn-action-button"] is the SAME testid ChatGPT uses on both user-message and assistant-message action bars (found live earlier tonight matching the user's own prompt copy button, not the assistant's) -- but the assistant's own copy button separately carries a role-specific aria-label="Copy response", confirmed via the user directly pasting its real markup. (2) the assistantTurn container resolution (latestAssistant.closest("article") || latestAssistant.parentElement?.parentElement) only worked by coincidence of matching DOM depth in every conversation tested tonight -- <article> has never been observed to exist in current ChatGPT markup, and the fixed 2-level parent walk has no structural guarantee for a differently-nested turn. Two independent live DOM captures tonight (the original canvas B-tree turn and the trivial single-paragraph smoke test) both showed the resolved container carries a real, semantically-meaningful class: agent-turn.

## Steps

1. Added 'button[aria-label="Copy response"]' as a second selector on completion-control, alongside the existing shared testid -- broadens matching without narrowing, and provides a role-specific signal that doesn't depend on scoping being correct at all.
2. Changed assistantTurn resolution in gpt_auto_cdp.py's _SNAPSHOT_FN to prefer latestAssistant.closest('.agent-turn') first, falling back to the legacy closest('article') || parentElement.parentElement chain for safety.
3. Both changes are additive/broadening (new selector alongside old, new primary scoping strategy with the old chain kept as fallback) -- deliberately not removing the old paths, since .agent-turn's universality across ALL ChatGPT response variants (canvas, standard bubble, etc.) has not been separately confirmed the way the two observed instances were.
