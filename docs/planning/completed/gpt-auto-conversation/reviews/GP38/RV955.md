# Second code review found two remaining gaps in the completion-groups reuse and stability-timer semantics

## Notes



## Findings

1. groups_satisfied used `any(group <= true_facts for group in completion_groups)` directly -- any() over an empty completion_groups is False, but EvidencePolicy.evaluate() treats an absent/empty any-of-groups section as NO any-of requirement at all. A future overlay legally removing any-of-groups from response-complete would silently make unresolved-turn recovery permanently impossible, diverging from the main completion gate's own semantics.
2. The elapsed-time stability check only proved 'two matching fingerprint observations were seen response_stability_seconds apart', not 'the terminal candidate was continuously eligible for that whole window'. If an observation between the two matches failed for any reason (terminal evidence disappearing, streaming/thinking reappearing, evidence temporarily unclear), the function returned False without clearing _unresolved_match_fingerprint_at -- so a stale timer could survive an intervening non-terminal observation and later be revived by an unrelated brief match, satisfying the elapsed check without real continuous stability.

## Conclusion

Both fixed 2026-08-17. (1): groups_satisfied now computed as `not completion_groups or any(...)`, matching EvidencePolicy's own empty-any-of semantics explicitly. (2): added _reset_unresolved_match_candidate() and call it on every early-return False path in _reconcile_unresolved_turn() (snapshot-observation-failed, provider-not-quiescent, prompt-correlation-failed, assistant-id/text-not-observed, completion-evidence-missing, assistant-response-not-terminal-match) -- only the two 'awaiting-second-stable-observation' paths (fingerprint mismatch, elapsed<stability) leave the timer running, since those are the legitimate in-progress-candidate states. New tests added in tests/gpt_auto/test_chat_unresolved_reconciliation.py: test_reconcile_requires_response_stability_seconds_between_matching_observations, test_reconcile_resets_stability_timer_when_terminal_evidence_disappears (directly exercises the flicker sequence: terminal observation arms the timer, a non-terminal observation clears it, a third terminal observation must start a fresh window rather than reusing the discarded timestamp), test_reconcile_treats_empty_any_of_groups_as_no_completion_requirement. Full gpt_auto + foundation/workflow suite green (225 tests) after the change.
