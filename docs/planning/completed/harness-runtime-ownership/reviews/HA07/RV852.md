# HA07 partial model-source migration leaves duplicate model writers

## Notes

Reassessed after HA11 removed per-provider runtime packages and PC launch capability work landed.

## Findings

`ag-rig` and computed discovery are present, but `public_materialize._build_rig_model_entry` still constructs a parallel entry and both Pi/OpenCode adapter install modules continue to render/write local_rig_config outputs. The computed resolver also loads harness config without the explicit project root passed to catalog resolution. Do not add another rig path; complete HA07 by making the existing model-source projection request authoritative, passing project context explicitly to computed resolution, and deleting local_rig_config only after equivalence tests prove the native output.

## Conclusion

HA07 remains the sole active item for this consolidation. Its next slice must remove writers, not add capabilities.
