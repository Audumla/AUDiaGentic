# UPD-001 — Consolidate update module constants and platform-specific code

## Description

Duplicate `GITHUB_REPO` constant in `checker.py:12` and `runner.py:15`. Hardcoded 20-line PowerShell script embedded in Python string in `runner.py:62-81`. Duplicate lazy imports repeated 5 times in `prompt.py`. Duplicate `safe_version` logic in `runner.py:21` and `runner.py:34`.

## Steps

1. Move `GITHUB_REPO` constant to `runtime/update/__init__.py`, import in `checker.py` and `runner.py`
2. Extract `safe_version()` helper from `runner.py` — used by both `_wheel_url()` and `_download_wheel()`
3. Externalize PowerShell script from `runner.py:62-81` to `_update.ps1` resource file, load via `pkgutil.get_data()`
4. Deduplicate lazy imports in `prompt.py` — consolidate at top of file
5. Extract shared install orchestration flow (`install_version` → `_handle_install_result` → exit handling) used by both `maybe_prompt_update` and `run_update_now`
6. Replace hardcoded temp filename with `tempfile.NamedTemporaryFile(delete=False)` to avoid collisions
7. Narrow `except Exception` on cleanup (`runner.py:135, 141`) to `OSError`/`PermissionError`

## Files

New: `runtime/update/_update.ps1`, `runtime/update/__init__.py` (add constants)
