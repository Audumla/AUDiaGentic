# ST-001 — Centralize path constants and fsync patterns across state layer

## Description

The path string `".audiagentic"/"runtime"/"jobs"` is hardcoded verbatim in 9 files across the codebase. Manual `flush()` + `os.fsync()` pattern duplicated in `session_input_store.py:79-94` and `control.py:49-54` despite `foundation/io.py` already providing `atomic_write_ndjson`. Duplicate `JobStoreInterface` type alias in 2 files.

## Steps

1. Create `runtime/state/paths.py` with `JOB_RUNTIME_ROOT` constant and `job_runtime_root(project_root)` helper
2. Replace all 9 hardcoded path constructions with imports from `runtime.state.paths`
3. Replace manual fsync in `session_input_store.py` with `atomic_write_ndjson` from `foundation/io`
4. Replace manual fsync in `control.py` with `atomic_write_ndjson` from `foundation/io`
5. Move `JobStoreInterface` type alias to `runtime/state/__init__.py`
6. Add module-level loggers to `jobs_store.py` and `session_input_store.py`
7. Fix `jobs_store.py:33` — log exception before re-raising (Standard #8)

## Files

New: `runtime/state/paths.py`
Modified: `session_input_store.py`, `jobs_store.py`, `control.py`, and 6 other files that construct the jobs path
Modified: `runtime/state/__init__.py` — export `JobStoreInterface`

## Validation

No hardcoded `".audiagentic"/"runtime"/"jobs"` string remains, all fsync replaced with `atomic_write_ndjson`, `JobStoreInterface` imported from single location, both files have module-level loggers

## Architecture Standards Assessment

**Standard #3 (Logic Containment):** Path string repeated 9 times, fsync pattern duplicated twice. **Standard #9 (Logging):** Both state files missing module-level loggers. **Standard #8 (Error Handling):** Exception caught without logging.

## Resolution Assessment

**Complexity: Simple.** Path constant extraction is mechanical. fsync replacement uses existing foundation utility.

**Why simple:** `atomic_write_ndjson` already exists in foundation. Path constant is a single string.

## Effort & Risk

Low — additive new file, mechanical replacements.
