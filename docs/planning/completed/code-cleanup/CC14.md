# LED-001 — Centralize ledger path constants and markdown rendering

## Description

Hardcoded path strings repeated across 6 ledger files: `".audiagentic"/"runtime"/"ledger"` (5 occurrences), `"docs"/"releases"` (4 occurrences), `"CURRENT_RELEASE_LEDGER.ndjson"` (4 occurrences). Duplicate markdown rendering structure in `current_summary.py:10-24` and `audit.py:10-22`. Duplicate `safe_json_load` pattern in `sync.py:106-108` and `ledger_api.py:113-115`.

## Steps

1. Create `components/ledger/paths.py` with `LedgerPaths` dataclass containing all path constants
2. Replace all inline path constructions across 6 files with `LedgerPaths` imports
3. Extract `render_list(title, entries, row_fn)` utility to shared module — used by `current_summary.py` and `audit.py`
4. Extract `safe_json_load(path)` helper — used by `sync.py` and `ledger_api.py`
5. Fix `fragments.py:34` — move `import random` to module scope
6. Fix `archive.py:27` — remove `import json as _json` from loop, use module-level `json`
7. Fix `archive.py:29` — replace bare `except Exception:` with specific `json.JSONDecodeError` + `OSError`
