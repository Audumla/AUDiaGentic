# Add architecture guard: assert all __all__ entries import successfully and every package has valid __init__.py

## Description

Add automated architecture guard tests to verify: (1) every __all__ entry in re-exporting __init__.py files actually imports successfully at runtime; (2) every src/audiagentic package directory has an importable __init__.py. Catches MA11-class regressions where a re-export is deleted but consumers remain unupdated.

1. For each symbol in every __all__, attempt `getattr(module, name)` and assert it succeeds. Skip lazy imports (string references) — document exclusion list.
2. Scan all Python package directories under src/audiagentic. Assert every directory has an importable __init__.py.
3. Add both checks as pytest tests in the architecture guard suite.
4. Run against current codebase to verify clean state post-fix (chg_20260714_031444).
5. Add to pre-commit or CI check list.
