# Reduce declarative recipe target to existing primitives

## Notes



## Findings

The 16-activity expansion duplicated the existing step factory and DeclaredStepRecipe lifecycle, pulled MA20 registry replacement and production migrations into CC41, and introduced parameter, secret, overlay, and ownership frameworks beyond current caller needs.

## Conclusion

Reduce CC41 to six bounded activities: strict shared schema; frozen validated template loader; string parameter/probe materialization; existing step/DeclaredStepRecipe reuse; small catalogue/owner binding; one registrar contribution seam with focused proof fixtures. Leave hardcoded-family removal to MA20 and production cutovers to owning plans.
