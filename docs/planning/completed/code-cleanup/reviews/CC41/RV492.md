# Restore config-managed shared recipe target

## Notes



## Findings

RV491 incorrectly prohibited configuration-defined executable recipe mechanics. The intended architecture is a shared declarative recipe target used by Hindsight, LSP, CLI installation, and future owners. The prohibition applies to inventing public family contracts or bypassing owner/family authorization, not to defining private recipe mechanics in configuration.

## Conclusion

Restore CC41 as a typed, schema-validated declarative recipe loader and execution target. Keep it independent from public family payloads/results. Owning components/family adapters explicitly bind loaded recipes; config supplies private probe/install/configure/verify/uninstall mechanics and typed parameters.
