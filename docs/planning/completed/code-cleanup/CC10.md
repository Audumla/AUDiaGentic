# CMD-001 — Replace if/elif command dispatch with registry tables

## Description

Two prohibited if/elif chains that branch on entity names (Standard #2 violation):
- Top-level command dispatch in `launcher.py:222-311` (10 branches: install, component, update, mcp, job-control, session-input, release-bootstrap, update-binaries, refresh)
- Component sub-commands in `component.py:32-97` (6 branches: list, status, install, uninstall, enable, disable)

## Steps

1. Create `COMMAND_REGISTRY` dict in `launcher.py` mapping command names to handler functions
2. Create `SUBCOMMAND_REGISTRY` dict in `component.py` mapping subcommand names to handler functions
3. Extract `_build_parser()`, `_bootstrap_logging()`, `_dispatch_command()` from `_main()` (212-line god object)
4. Extract shared `print_json_result(result, ok_key="ok")` helper to `cli_io.py` — used identically in `component.py` and `provider_prompt.py`
5. Remove dead nested function `_resolve_project_root` in `launcher.py:203-205`
6. Extract import-guard pattern (`try/import except ImportError → print_error → return 1`) to shared helper

## Files

Modified: `launcher.py` — registry dispatch, decompose `_main()`, remove dead code
Modified: `component.py` — subcommand registry
Modified: `cli_io.py` — add `print_json_result()` helper
Modified: `provider_prompt.py` — use shared `print_json_result()`

## Validation

No if/elif on command/subcommand names remains, `_main()` under 100 lines, `print_json_result()` used consistently, all commands dispatch via registry

## Architecture Standards Assessment

**Standard #2 (Config Over Code):** Explicitly prohibits `if/elif` chains branching on entity names. **Standard #3 (Logic Containment):** `_main()` is a god object at 212 lines with 10+ responsibilities. Both resolved by this change.

## Resolution Assessment

**Complexity: Simple.** Registry tables are straightforward dict mappings. Decomposing `_main()` is mechanical extraction.

**Why simple:** Each command handler already exists as a separate function; just need dispatch table and parser extraction.

## Effort & Risk

Low — additive dispatch tables, no behavioral change.
