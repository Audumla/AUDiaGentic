## Patterns not covered by CC50/CC51

A complete codebase sweep uncovered additional closed-vocabulary string patterns that CC50 and CC51 do not address. These are grouped below by ownership.

---

### 1. Provider Streaming Protocol Policies (providers.protocols.streaming)

**validation_policy** — {"normalize", "warn", "fail"} — used in provider_streaming.py for both control-validation and sink-error validation  
**termination_policy** — {"graceful-kill", "warn-only"} — used for timeout/exit behavior  
**overflow_policy** — {"warn-only", "truncate-head", "truncate-tail", "fail"} — used in sinks.py for buffer management  
**event_write_policy** — {"locked-append", "locked-trim"} — used in sinks.py for event writing  
**invalid_event_policy** — {"fail", "warn", ...} — used in sinks.py for malformed events

All are raw string fields on dataclass instances with hardcoded if/elif chains. These are internal to the streaming protocol layer.

### 2. Provider Descriptor Mechanism Schemas (providers.descriptors)

**mechanism_schema** — {"permissions-struct", "host-capability", "agent-file", "model-spec", "launch-spec", "callable-ref"} — used in loader.py for dispatching descriptor loading logic; also in capability_catalogue.py as a mapping dict. No Literal type defined at all.

### 3. Source Catalog Discovery & Classification (providers.services.catalog)

**discovery_mode** — {"static-catalog", "list-api"} — used in source_catalog.py for catalog discovery strategy  
**source_class** — {"local-endpoint", "remote-account"} — used in providers_api.py and models.py for source classification  
**refresh_mode** — {"restart-required", ...} — used in lifecycle/status.py for model refresh; only one value but may grow

### 4. Approval States & Review Recommendations (agent_jobs)

**approval_state** — {"approved", "rejected", "cancelled"} — used in approvals.py for approval workflow; choices=("approved", "rejected") in prompt  
**review_recommendation** — {"pass", "pass-with-notes", "fail"} — used in reviews.py and review_launch.py; Recommendation enum already exists in providers.streaming.completion but is NOT imported by agent_jobs

**aggregation_rule** — {"majority-pass", ...} — used in prompt_parser.py for review aggregation; only one value currently

### 5. Recovery Outcomes (agents_gateway_store._transitions)

**recovery_outcome** — {"replay-required", "resubmit-required"} — set by transitions.py after interrupted requests are re-evaluated  
**recovery_reason** — {"service-restart", ...} — same; only one value currently

### 6. Gateway Mode (agents_gateway_client)

**gateway_mode** — {"in-process", "remote"} — used in agents_gateway_client.py for mode selection

### 7. Profile Slot States (agents_gateway_api)

**profile_slot_state** — {"active", "idle", "pending", "queued"} — used in agents_gateway_api.py queue_state computation; note: these are NOT the same as QueueStateLabel which is about request lifecycle position

### 8. Error Kind Labels (agents)

**error_kind** — {"agents", "agent-status-validation"} — used in error payloads across agents component

### 9. ACP Transport Raw Status Strings (foundation.transports.acp)

The acp.py module uses raw string comparisons for turn status: {"completed", "finished", "failed", "cancelled"}. These overlap with AgentOutcome but are NOT instances of it — they're raw strings from the transport wire. No validation.

### 10. Worker Protocol Phase Strings (agents_gateway_work_index)

The existing `Phase` StrEnum (ADMITTED, CLAIMED, RUNNING, TERMINAL_CLEANUP) is used correctly in the work index. However the Literal["admitted", "claimed", "running", "terminal-cleanup"] type hints in the same file are redundant — they should reference Phase directly.

### 11. Boolean Parsing Strings (scattered)

**Boolean true strings** — {"true", "1", "yes"} — used in prompt_parser.py and profiles.py  
**Boolean false strings** — {"false", "0", "no"} — same  
These are utility patterns, not domain vocabularies. Low priority.
