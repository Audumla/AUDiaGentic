# SC-001 — Fix source_control dual-component lifecycle handler and copy-paste

## Description

`source_control_bootstrap.py:51-70` handles lifecycle events for TWO components (`COMPONENT_SOURCE_CONTROL` and `COMPONENT_AGENT_LEDGER`) — a dual-responsibility violation. `install_dependencies()` and `uninstall_dependencies()` in `source_control_api.py:36-53` are copy-paste (only action string differs). Duplicate `status_payload()` pattern also exists in `coding_lsp_bootstrap.py:148-181`.

## Steps

1. Split `on_component_lifecycle()` in `source_control_bootstrap.py` — source_control should only handle `COMPONENT_SOURCE_CONTROL` events; ledger integration delegated to ledger component
2. Extract shared `_run_workflow(action, names)` helper in `source_control_api.py` replacing duplicate install/uninstall functions
3. Extract shared `status_payload()` builder to foundation layer — used by both `source_control_bootstrap.py` and `coding_lsp_bootstrap.py`
4. Remove dead code `_build_warnings()` in `source_control_bootstrap.py:122-132` (defined but never called)
5. Use constants consistently instead of string literals for event types in `source_control_bootstrap.py`

## Files

Modified: `source_control_bootstrap.py`, `source_control_api.py`, `coding_lsp_bootstrap.py`
New: `foundation/status_utils.py` (optional — for shared `status_payload` builder)

## Validation

Source control bootstrap only handles `COMPONENT_SOURCE_CONTROL` events, single `_run_workflow` used by both install and uninstall, shared `status_payload` builder used by both components, `_build_warnings()` removed, event types use constants

## Architecture Standards Assessment

**Standard #3 (Logic Containment):** Dual-component handler, copy-paste install/uninstall, duplicate `status_payload()`. **Standard #3 (Dead Code):** `_build_warnings()` defined but never called.

## Resolution Assessment

**Complexity: Simple.** Split function, extract helper, remove dead code.

**Why simple:** Each change is independent and mechanical.

## Effort & Risk

Low — additive helpers, no behavioral change.

## Notes

`SOURCE_CONTROL_DEPENDENCY_IDS` hardcoded list in `source_control_bootstrap.py:17` should be derived from YAML descriptor at load time (Standard #2).
