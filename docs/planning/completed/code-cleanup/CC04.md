# Std 5: Component IDs derived from loaded descriptors

## Description

Std 5: 'Component IDs derived from loaded descriptors — not maintained as parallel Python constants.'

`foundation/components/ids.py` — IDs are also defined in component YAML descriptors. Python constants create a second source of truth.

## Steps

Derive IDs from loaded descriptors at runtime. For core components (`project`, `session`) that have no YAML descriptor, keep a minimal `CORE_IDS` set. For optional components, look up from the descriptor registry. Transitional: keep `ids.py` as a thin wrapper that reads from the registry, with deprecation notice.

## Files

`foundation/components/ids.py`, descriptor registry

## Validation

IDs match between Python constants and YAML descriptors; no drift possible.
