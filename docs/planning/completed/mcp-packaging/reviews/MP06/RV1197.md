# Read background selection inside the run fence

## Notes



## Findings

Background reconcile read Project bindings before acquiring the shared run fence. An explicit install could commit different intent while it waited, allowing stale desired-state replay after the newer installation. Defer synchronous own callbacks before acquiring the fence and read pending intent, config and target requests inside it.

## Conclusion
