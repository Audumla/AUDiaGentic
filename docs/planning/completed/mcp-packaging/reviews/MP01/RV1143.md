# Standalone bundle validation exposes broad shared-registry coupling

## Notes



## Findings

Copying entry modules or static imports alone omits descriptor-loaded provider adapters. Conservative closure and configured-hook expansion now produce functional independently installable bundles, but approximately 611 of 704 canonical Python modules are retained. These must not be described as minimal component-only packages or safe co-installable plugins.

## Conclusion

Include configured hook dependencies, isolated wheel/protocol and CRUD validation, explicit one-environment-per-bundle documentation, and track a separate architectural core/registration decoupling item before promising slim packages.
