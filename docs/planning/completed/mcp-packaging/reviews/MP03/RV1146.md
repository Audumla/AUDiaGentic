# Standardize CLI option spelling and require comprehensive contextual help

## Notes



## Findings

User review: proposed mixed -install/-harness and --install/--harness spellings create unnecessary inconsistency. Use GNU-style --kebab-case long options; reserve single dash for single-letter shortcuts, retain existing -h/-p/-s contracts, and do not implement unshipped single-dash long aliases. Require detailed command, MCP-item and harness-item help, generated from owned metadata.

Revise MP03-MP09 before implementation; cover parser rejection, examples and contextual help in acceptance tests.
