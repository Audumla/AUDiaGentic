# TP01 — Provider-owned recipe contract using generic primitives

## Description

Define the abstract recipe contract that provider surfaces implement: probe, install, configure, verify, uninstall, prune. The contract specifies interfaces only — no provider names, no component semantics. Toolchain layer provides the primitive building blocks; providers compose them into capability-specific recipes.

## Steps

['Define ProvisioningRecipe ABC with lifecycle methods: probe(), install(), configure(), verify(), uninstall(), prune()', 'Define RecipeResult dataclass: success, artifacts_owned, status, error', 'Define lifecycle state machine: absent -> installing -> configuring -> verified | error', 'Ensure no provider names, component names, or semantic knowledge leaks into the contract', 'Add docstrings and type stubs for all interfaces']
