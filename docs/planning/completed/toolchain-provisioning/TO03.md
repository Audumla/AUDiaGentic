# TP03 — Generic status recipe primitives

## Description

Build reusable status-check primitives that recipes compose: command probe, file-exists check, config-key-present check, and composite health check. These are building blocks, not a monolithic health system.

## Steps

['Implement CommandProbeStep: run command, check exit code and/or output pattern', 'Implement FileExistsCheck: verify path exists with optional content pattern match', 'Implement ConfigKeyCheck: verify key exists in TOML/JSON/YAML file with optional value', 'Implement CompositeHealthCheck: AND/OR composition of sub-checks with short-circuit', 'Ensure all checks return structured ProbeResult with pass/fail and diagnostic detail']
