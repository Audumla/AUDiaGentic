# TP02 — Generic execution step enhancements (ShellStep, SequenceStep)

## Description

Enhance the workflow step primitives with capabilities needed by all provisioning recipes: env var injection, cwd/home expansion, cross-platform command variants, idempotent probe-before-install, and structured result capture.

## Steps

['Extend ShellStep with env_vars dict, cwd resolution (including ~ expansion), and cross-platform command variants (e.g., {"linux": "command", "win32": "cmd.exe /c command"})', 'Add SequenceStep support for conditional branching based on prior step results', 'Add structured result capture: exit code, stdout/stderr, timed-out flag, duration', 'Implement idempotent probe pattern: optional pre-check step that skips install if probe succeeds', 'Add named recipe support: install, uninstall, probe as first-class step types']
