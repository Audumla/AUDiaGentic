# Planning documentation

Planning files are tracked work records, not a substitute for current source
or standards. Use the planning MCP operations to create, update, review, and
move items so frontmatter, history, and ledger links remain consistent.

- [Creating plans](CREATING_PLANS.md) — lifecycle, required fields, review
  discipline, and validation expectations.
- [Active items](active/) — work that is pending or in progress. Confirm the
  current state and dependencies before acting.
- [Completed items](completed/) — preserved implementation and review history;
  do not treat old steps or file lists as current instructions without checking
  the source tree.
- [Requests](requests/), [specifications](specifications/), and [tasks](tasks/)
  — planning inputs and supporting records.

For the distinction between current-facing documentation and historical
records, see [Documentation status](../DOCUMENTATION_STATUS.md).
