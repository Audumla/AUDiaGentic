# Shorten release gates and dispatch exact-source full validation after publication

## Description

Use targeted merge gates, focused generated-release tests and actual artifact
installation checks. Explicitly dispatch full qualification after publication.

## Detailed Solution & Technical Design

Remove main-push/release-event full triggers. Retain nightly/manual/label opt-in.
Keep exact-head release PR allowlist and privacy gates; skip duplicate application
fast suites on version-only PRs and finalized ledger commits. Keep build/install
proof for finalized source. Dispatch full CI only after successful publication,
using finalized SHA, with visible failures and unchanged full coverage audit.

## Validation

Run workflow policy and release unit tests, including executed dispatch scripts
for immutable-source acceptance and mutable-source rejection. Live GitHub release
timing and post-publication execution remain to be verified after merge.

## Standards

Authoritative planning and release ledger; exact-source provenance; no synthetic
passing checks, no ignored full failures, no git stash.
