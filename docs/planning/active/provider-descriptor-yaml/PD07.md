# Fix adapter discovery to comply with Rule 5

## Description

Fix providers/adapters/__init__.py to comply with Rule 5: "Never maintain a Python import list or `__all__` that enumerates pluggable modules."

Current state:
- providers/adapters/__init__.py uses pkgutil.iter_modules() (good)
- providers/adapters/__init__.py has `__all__ = sorted(_ADAPTER_MODULES)` (violates Rule 5)

Fix:
- Remove `__all__` from providers/adapters/__init__.py
- Keep pkgutil.iter_modules() discovery (complies with Rule 5)
- Ensure no other files maintain hardcoded lists of adapter modules

Validation:
- No `__all__` in providers/adapters/__init__.py
- No hardcoded lists of adapter modules in Python
- pkgutil.iter_modules() discovery still works
- All adapters are still discovered correctly
