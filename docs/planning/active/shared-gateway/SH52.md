# Human-safe native delivery orchestration

## Description

Slice of SH40. Queue/atomic conditional idle admission, cancellation/revocation, self-cycle protection, bounded recovery and request-specific output attribution. Depends on SH51.

## Steps

1. Extend gateway/queue/queue.py and queue/dispatch.py to serialize EXTERNAL commands per exact native session, reusing the existing FIFO and canonical request identity.
2. Admit only when the qualified endpoint proves atomic idle acceptance; otherwise keep the request in the gateway queue. Never interrupt human work.
3. Route cancellation and revocation through the existing gateway authority: cancel queued work, observe (never interrupt) work the native session already accepted.
4. Detect trusted same-session self-cycles before queue admission and return a registered refusal instead of deadlocking.
5. Extend queue/recovery.py to reconcile bounded uncertain delivery with the SH51 receipts; expiry never clears a generation fence.
6. Attribute terminal output only through request-specific native evidence; reject unsupported steering.
