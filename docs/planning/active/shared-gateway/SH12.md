# Rename the LLM gateway contract to agent execution

## Description

Replace the technology-specific `LLM` vocabulary in the agents gateway with the provider- and transport-neutral `agent execution` vocabulary. The gateway now owns queued agent execution, live sessions, ACP/native transports, tools, lifecycle, and provider-neutral evidence; `LLM` is both narrower than the implemented responsibility and an unstable public contract name. Make one direct cutover across code, events, MCP tools, service operations, schemas, runtime paths, docs, and tests. Do not retain aliases or dual topic/tool routes unless an explicit external compatibility obligation is discovered and recorded before implementation.

## Steps

Direct one-PR cutover. Inventory measured 2026-07-18: 31 files carry the old vocabulary (agents component 20, agent_jobs 3, foundation canonical_ids/topic_registry 2, config 2, tests 11 incl. cross-suite). Sequence within the PR matters; each numbered step is a commit-sized unit.

### 0. Frozen mapping (normative)
```text

               session_list,session_close} → agent_execution_{same-suffix}
API/app/client submit|get|wait|cancel|run|list_llm_request(s) → *_execution_request(s)
               list|close_llm_session → list|close_execution_session(s)

               → agents.execution.gateway.{...}; agents.session.*/agents.turn.* unchanged

               agent-llm-session → agent-execution-session; canonical_ids entries likewise
```

Protocol: rename the operation strings AND bump `PROTOCOL_VERSION` (gateway-service-v1 → v2) in `agents_gateway_service_contract.py` — a skewed old client then gets the existing clean VAL-AGSV-013 refusal instead of an unknown-operation error.

### 2. Runtime-path migration at the owner boundary
`agents_paths.py`:
```python
_GATEWAY_ROOT = Path("runtime") / "agent-execution-gateway"
_LEGACY_GATEWAY_ROOT = Path("runtime") / "agent-llm-gateway"

def gateway_root(project_root: Path) -> Path:
    new = project_root / AUDIAGENTIC_DIR / _GATEWAY_ROOT
    old = project_root / AUDIAGENTIC_DIR / _LEGACY_GATEWAY_ROOT
    if old.is_dir() and not new.exists():
        new.parent.mkdir(parents=True, exist_ok=True)
        with StartupLock(new.parent / "gateway-rename.lock"):
            if old.is_dir() and not new.exists():   # re-check under lock
                os.replace(old, new)                 # atomic same-volume dir rename
    return new
```
Same one-shot pattern for the machine service root (`<global-runtime>/machine/agent-llm-gateway` → `agent-execution-gateway`) inside `ManagedServiceStore` construction for the gateway key only — implemented in the gateway host, not foundation. Records inside need no rewrite (no self-referencing paths); resource-kind fields inside timeline files are historical evidence and stay as written. Ingress spool moves with the directory.
