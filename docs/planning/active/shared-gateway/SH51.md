# Durable native delivery intent and receipts

## Description

Slice of SH40. Implement pre-effect WAL barrier, same-command identity and acceptance correlation, uncertain-effect retention and exact-command reconciliation. Depends on SH50 and a qualified endpoint.

## Steps

1. Extend gateway/session/dispatch.py with an EXTERNAL target path using external_registry.resolve_target; keep OWNED ACP preparation unchanged.
2. In session/sessions_store.py retain, before any transmission, the immutable command id, payload digest, target generation, node epoch and authorization revision.
3. In node/receipts.py and node/execution_owner.py add native-command deduplication, durable pre-effect intent and exact native acceptance correlation, reusing the existing receipt custody and acknowledgment machinery.
4. Enforce the WAL durability barrier before any native effect (docs/design/shared-gateway-admission-recovery.md ordering).
5. After reconnect reconcile only definitive same-command evidence; persist ambiguous outcomes and fence the generation. Never blindly resend or erase an unresolved receipt.
6. Reach the qualified operation only through providers_api; reject unqualified native targets.
