# Shared gateway port and service record must not collide across AUDiaGentic homes

## Description

The shared gateway service binds a fixed port (bootstrap._DEFAULT_PORT 8765) independent of AUDIAGENTIC_HOME, while its service record lives under the home. A client using another home (for example a user-scope MCP registration from `audiagentic setup harness claude` in a session with no AUDIAGENTIC_HOME, CFG08) sees no service record, tries to start its own service on 8765 and fails with CON-MSVC-037 while the other home's service holds the port. Found 2026-10-29 in the agent-dev container: planning/ledger tools worked, gateway tools did not.

## Steps

1. Decide the rule: the home is chosen in user settings (CFG08 gap), or the default port is derived from the home, or the service record is discoverable machine-wide.
2. Implement it in the managed-service bootstrap, not in callers.
3. doctor reports a port held by another home's service with the exact fix.
