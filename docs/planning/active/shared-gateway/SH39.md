## Description

Follow-up to SH36 capability audit. Enforce static qualification plus passive current-instance proof through existing Provider capability machinery. Missing integrations remain rejected, not built automatically.

## Steps

1. Add only required typed joined-capability fields to existing declaration/resolved contracts and schema/loader.

3. Expose narrow inspect/live dispatch qualification through providers_api; preserve ordinary owned ACP semantics.
4. Derive inventory/status matrix from same authority; register only after all gates pass.
