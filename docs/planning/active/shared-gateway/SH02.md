# Define the versioned job execution context and resolved execution manifest

## Description

Define what an MCP call or event trigger must carry so a shared gateway can execute work without inheriting the submitting harness process. Separate submission intent from a validated, immutable resolved execution manifest. Cover project root, startup/cwd, workspace roots, component-profile selection, agent-profile/provider/model selection, role/capability intent, enabled components/features, configured MCPs, provider launch/config isolation, correlation/idempotency identity, environment allowlists, and secret references without copying raw secrets.

## Steps

1. Inventory implicit context currently read from cwd, environment, project-local files, process-global registries, and the active harness. 2. Define a versioned submission envelope with required/optional fields and canonical path rules. 3. Define gateway-side resolution into an immutable execution manifest, including provenance and a stable context fingerprint. 4. Define safe environment and secret-reference handling; reject raw credential persistence and ambiguous roots. 5. Map provider isolation tiers from PROVIDER_CONFIG_OVERRIDE_ANALYSIS.md into explicit launch-materialization strategies and unsupported/degraded outcomes. 6. Specify schema migration and protocol negotiation. 7. Add contract, redaction, cross-project, and tamper tests before consumers migrate.

## Files

docs/reference/PROVIDER_CONFIG_OVERRIDE_ANALYSIS.md; new shared gateway contract/schema modules and schemas identified by design; agents gateway request contracts; provider public execution contracts; tests

## Validation

Round-trip/schema tests cover Windows and POSIX path forms; identical intent resolves deterministically; two projects with different roots/MCPs/component profiles cannot bleed state; persisted records contain no raw secrets/prompts; old clients receive a stable version error or supported translation.

## Effort & Risk

Complex because much current context is process implicit. An envelope that merely carries paths without freezing resolution provenance will remain nondeterministic.
