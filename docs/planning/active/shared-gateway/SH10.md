# Implement gateway leases, graceful drain, idle self-shutdown, and continuous-service mode

## Description

Provide two operational modes over the same framework-neutral service lifecycle API. In self-managed mode, clients register renewable leases and the gateway silently exits only after all leases are gone, admitted/running work and owned sessions are complete, and a configurable idle grace expires. In continuous-service mode, an external service manager owns uptime and idle shutdown is disabled. MCP/CLI/operator endpoints only translate commands into lifecycle API calls; lease, drain, shutdown, authorization, and refusal policy stay in the service/application layer.

## Steps

1. Define client lease/session identity, renewal, expiry, disconnect, and observability contracts. 2. Define drain state and shutdown gates covering queued/running jobs, live sessions, workers, event consumers, and late reconnects. 3. Implement race-safe idle shutdown with final admission re-check and client retry on losing a shutdown race. 4. Add operator status, drain, stop, and restart commands with authorization and safe refusal/force semantics. 5. Add service-manager adapters/documentation for Windows and selected POSIX managers after self-managed mode is proven. 6. Add lease expiry, crashed client, long-running job, reconnect-at-deadline, and OS shutdown tests.

## Files

shared gateway lifecycle/lease/operations modules; client integration; CLI/service-manager assets; tests and operator docs

## Validation

With no clients but active work, the gateway stays alive and drains; after the last lease and work complete it exits after grace; a reconnect during grace cancels exit; continuous mode never self-exits; no owned process/session is orphaned. Architecture tests prove MCP/CLI/service-manager adapters do not own lease tables, drain state, shutdown gates, or process policy.

## Effort & Risk

Complex shutdown state machine and cross-OS orchestration. Force stop must be explicit and must report affected work.

## Standards

AR25; Architecture Standards §§1,3,4,6,7; PR05 lifecycle contracts.
