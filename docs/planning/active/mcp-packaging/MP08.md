# Add consistent CLI discovery installation and detailed contextual help

## Description

MP03 slice 5. Keep launcher parsing and user presentation thin; all substantive work goes through public APIs.

## Steps

1. Factor the existing root token handling once so command recognition and shipped options share one parser authority.
2. Add typed syntax-only management command parsing and contextual help.
3. Dispatch through the deliberately composed owning public surface before interactive application graph startup.
4. Qualify the exact external stdio/flag/passthrough obligations and reserved-name escape.

## Detailed Solution & Technical Design

Approved syntax uses command verbs, IDs and keyword clauses. Required install form: mcp install MCP_ID harness CSV. Optional clauses project PATH, component-profile NAME, config FILE, dry-run, non-interactive, output json occur at most once after mandatory operands; value clauses consume exactly one token even if it is a keyword. No abbreviations, describe verb, root install flags or new single-dash aliases. Parsing validates syntax only; canonical IDs, capabilities, requirements, project scope and configuration semantics are owner API checks. CSV syntax trims and deduplicates preserving order; reject empty members. Malformed recognized management syntax returns usage error and cannot launch chat. Help/list run before runtime graph construction and never require a project or credentials. Mutation requires an existing project context or explicit project PATH; never infer an arbitrary writable directory. Preserve user-required shipped -h/--help, -p/--prompt, -s/--stream, --project, --component-profile and provider/root -- passthrough. Document the specific external obligation: generated MCP launch argv uses mcp MODULE MODULE_ARGS. Reserve bare install/list/help for management, support mcp -- MODULE MODULE_ARGS for literal reserved modules, and keep ordinary module args opaque after module consumption. This is one launcher grammar with an explicit module route, not a permanent second legacy launcher or compatibility shims. Root/profile option conflicts fail deterministically instead of silently overriding. UI uses help; internal query method names need not introduce a user-facing describe command.
