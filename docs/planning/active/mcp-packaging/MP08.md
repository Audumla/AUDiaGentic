# Add consistent CLI discovery installation and detailed contextual help

## Description

MP03 slice 5. Keep launcher parsing and user presentation thin; all substantive work goes through public APIs.

## Steps



## Detailed Solution & Technical Design

Canonical management grammar uses positional verbs/IDs and explicit keyword clauses, not new flag-based aliases. User-approved examples: audiagentic mcp install ag-planning harness pi,opencode; audiagentic mcp list; audiagentic harness list; audiagentic help; audiagentic mcp help; audiagentic mcp install help; audiagentic mcp ag-planning help; audiagentic harness pi help. Help is trailing at the selected command/item path and replaces the proposed describe verb. Do not add alternative root --install or single-dash long spellings. Preserve shipped -h/--help, -p/--prompt, -s/--stream, --project and --component-profile behavior for existing commands; keyword grammar must not silently reinterpret raw prompts, tokens after -- or legacy mcp MODULE MODULE_ARGS. Installation exits without chat. Require explicit harness targets; trim/deduplicate CSV preserving order and reject unknown/empty targets before writes. Define ancillary keyword clauses project PATH, component-profile NAME, dry-run, config FILE, non-interactive and output json as proposals for reviewer validation, including repetition/order, keyword-as-value escaping, reserved IDs/help ambiguity and deterministic errors. No prefix abbreviation or accidental fallback to launching an agent after malformed management input. Generic context help comes from command grammar plus owner metadata and includes purpose, arguments, defaults/requiredness, scope, config precedence, secrets, side effects, verification, exit codes and examples. Help/list must be read-only, bounded and usable without credentials/project initialization/network. Item help includes capabilities, requirements, unavailable reasons, limitations and documentation links without secret values. JSON stdout is machine-only, stderr diagnostics. Expose every action through public APIs and use no MCP/harness-specific branches in launcher.
