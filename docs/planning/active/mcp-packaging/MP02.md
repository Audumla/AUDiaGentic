# Decouple shared registration for genuinely slim co-installable component wheels

## Description

Current conservative standalone bundles retain about 611/704 Python modules because shared feature/component/provider registration reaches the application runtime. Separate a small supported MCP/core bootstrap and component dependency declarations so planning and ledger do not carry unrelated providers, gateways, launchers or harnesses. Preserve one canonical implementation and define safe namespace/package ownership.
