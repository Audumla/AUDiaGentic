# Event jobs persist empty prompt before rendering

## Notes



## Findings

EDJ03 description requires durable job records to capture rendered instructions and prompt source. EDJ03 step 5/6 requires trigger-origin job builder path to persist provenance; EDJ11 requires file/inline template -> context -> render. In src/audiagentic/components/agent_jobs/event_observer.py:259-267, build_job_from_event is called with prompt_body="" before prompt context/rendering happens at lines 290-318. build_job_from_event then writes launch-request.json with that empty prompt at prompt_launch.py:446-458. The gateway publish later uses the rendered prompt (event_observer.py:325-334), so durable job artifacts disagree with what was dispatched.

Operator impact: job replay/audit reads an empty prompt-body even though the LLM request received non-empty instructions. This violates observability and provenance requirements.

## Conclusion

Render prompt before creating the durable job record, pass rendered prompt_body into build_job_from_event, and persist prompt source metadata (inline/file path + redacted context key summary) with tests asserting launch-request.json matches gateway payload.
