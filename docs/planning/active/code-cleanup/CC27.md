## _AutoDescFastMCP mechanism detail
File: component_server.py, class at line 225. Overrides FastMCP.tool() to auto-inject YAML descriptions.
- Detection: checks if first positional arg is a string or "description" in kwargs (lines 267-271)
- Lazy cached declaration lookup via _get_decl(): calls register_all_components(), iterates all_descriptors() finding the server whose module matches self._module_name
- Resolution: uses tool_description(decl, func.__name__) helper at line 95-102
- CRITICAL: Falls through to NO description (not docstring) when no YAML entry exists — this is intentional design, not a bug
- The mcp_server() factory at line 288 passes instructions from server_instructions(decl) to the constructor

## Gap analysis — what's NOT covered by the current architecture
1. **Tool names**: Hardcoded as Python function name. No config-driven aliasing. To rename an MCP tool, you must rename the Python function.
2. **Parameter schemas**: All types, defaults, required/optional derived from Python signature only. FastMCP auto-generates JSON Schema but does not include per-parameter descriptions.
3. **Parameter descriptions**: Not supported at all — need rich YAML format (proposed in this item).
4. **Tool enable/disable**: No conditional registration based on config flags.
5. **Tool grouping/categorization**: Tools listed flat, no namespaces or categories.
6. **Docstring fallback**: If docstring-as-fallback is desired when no YAML entry exists, requires code change to _AutoDescFastMCP.tool().

## Error-resolutions pattern — reference model detail
Data model: error code = PREFIX-COMPONENT-NNN, validated by regex at construction time
Factory pattern: make_error_factory("VAL", "AGW", "agent-gateway") returns closure; call with number + message to produce AudiaGenticError
Registry loading: load_all_error_resolutions() called during component registration at startup (loader.py line 323-327)
Envelope serialization: to_error_envelope() looks up get_error_resolution(code) and attaches resolution field
Config location: src/audiagentic/config/components/<component_id>/error-resolutions.yaml
