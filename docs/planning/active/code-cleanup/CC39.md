# Add get_items batch retrieval for full item details

## Description

Add a `get_items` tool that returns full item details (frontmatter + body sections) for multiple items in one call. Currently `list_items` returns summary dicts and `get_item` returns full details for one item — there's no batch variant.

This is useful when an agent needs to read the content of several plan items (e.g., all items in a plan, or all active items) without making repeated MCP tool calls.
