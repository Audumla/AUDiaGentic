# Reorganize providers/services into subdirectories by functional domain

## Description

The 47 files in `src/audiagentic/components/providers/services/` are flat and growing. Dependency analysis shows a clean DAG with no circular references — the modules separate cleanly into functional domains without internal restructuring.

### Key insight: `support/` is a grab-bag that needs splitting first
- `secrets.py` is cross-cutting (used by 5+ groups) → stays at root
- `public_prompt_operations.py` belongs with execution, not support
- `recipe_steps.py`, `recipe_definitions.py`, `declarative_recipe_handler.py` belong with capabilities (they define ManagedMcpStep, ManagedHooksStep, ManagedPluginStep)
- `feature_resolution.py` belongs with config (resolves provider features)
- `public_materialize.py` belongs with lifecycle (materializes config)
- `plugin_entries.py` belongs with capabilities (managed entry lifecycle alongside MCP and hooks)

### Also renaming: families → capabilities
The "family" concept is an internal pattern detail. The observable behavior is what providers can DO — install/uninstall, manage MCP, project models, manage hooks, etc. "Capabilities" describes that better.

## Steps

Update all imports OUTSIDE the services package that reference these modules (adapters, commands, other components)', '6. Verify with LSP diagnostics — no broken imports or unresolved references']

### Dependency Analysis
- No circular dependencies — clean DAG, modules separate without internal restructuring
- Cross-group edges: catalog→config, execution→catalog|config|session, capabilities→lifecycle|catalog|mcp, lifecycle→config|catalog|host|mcp, reconcile→all groups
- Leaf groups (no outbound cross-group deps): config (all leaves), mcp, host

### Migration Approach
1. Move files into directories, creating `__init__.py` in each
2. Use relative imports within the services package (`from .config.provider_config import ...`)
3. External imports remain absolute (`from audiagentic.components.providers.services.config.provider_config import ...`)
4. `reconcile.py` and `secrets.py` stay at root since they span multiple groups
5. Update all external references via find-and-replace on old module paths
