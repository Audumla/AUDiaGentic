### Pattern 5 — Surface managed markers (base.py lines 161-170)
The MANAGED_REGION_BEGIN/END comment fences are structural delimiters that could be externalized for consistency:
- `MANAGED_MARKDOWN_HEADER = "<!-- MANAGED_BY_AUDIAGENTIC: do not edit directly. -->"`
- `MANAGED_REGION_BEGIN = "<!-- ag:managed:begin -->"`
- `MANAGED_REGION_END = "<!-- ag:managed:end -->"`
- `MANAGED_REGION_NOTICE = "_Managed by AUDiaGentic — generated from component configs..._"`
The notice string is user-facing. The fence markers are structural but externalizing them ensures format consistency and allows future format changes without code modification.
