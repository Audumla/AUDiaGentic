# COMP-002 — Delete dead duplicate core/project and core/session packages

## Description

Two component package directories are dead refactor leftovers:
  - src/audiagentic/components/core/project/  (duplicate of components/project/)
  - src/audiagentic/components/core/session/  (duplicate of components/session/)

The live descriptors point at the non-core modules (module: audiagentic.components.project.project_mcp and audiagentic.components.session.session_mcp). A grep for `components.core.project` / `components.core.session` outside the core/ dirs themselves returns ZERO references. The core/ copies are unreachable. Remove them to cut confusion and garbage.

## Steps

1. Confirm dead: grep -rn 'components.core.project|components.core.session|components\\.core' across src/ and tests/, excluding the core/ dirs themselves. Expect zero hits. Also grep config/components/*.yaml for any 'core.project'/'core.session' module/dotted-path references.
2. Check core/README.md and core/__init__.py — if components/core/ contains ONLY project/ and session/ and nothing else references it, the whole core/ dir may be removable. If other live code lives under core/, scope deletion to just project/ and session/ subdirs.
3. Diff the duplicate pairs to confirm the core/ copies are stale/identical, not a newer version someone forgot to wire up. If core/ copies are actually newer, escalate instead of deleting.
4. Delete the dead directories.
5. Run the suite + register_all_components() to confirm nothing imported them implicitly (lifecycle-observer/status-hook dotted paths in yaml).

## Files

src/audiagentic/components/core/project/ — delete (if dead)
src/audiagentic/components/core/session/ — delete (if dead)
src/audiagentic/components/core/ — delete if it becomes empty
src/audiagentic/config/components/*.yaml — verify no dotted-path refs to core.*

## Validation

1. grep confirms zero references before deletion.
2. Full test suite green after deletion.
3. register_all_components() loads all components without import errors (covers lifecycle-observer/status-hook/post-install dotted paths).
4. CLI smoke: component list/status still shows project + session.

## Effort & Risk

Low. Risk: a dotted-path string reference (yaml lifecycle-observer/status-hook/post-install/module) that grep for Python imports would miss. Mitigate by grepping config YAML for 'core.project'/'core.session' strings too, and running register_all_components().
