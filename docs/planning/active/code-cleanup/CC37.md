# I18n migration — catalog of all touchpoints requiring locale integration

## Description

CC34 built the I18n infrastructure but did not refactor any existing code to use it. This item catalogs every location that must be migrated so user-facing text flows through the I18n registry instead of being hardcoded or loaded by custom YAML paths. Once this list is approved, each category becomes its own work item.

## Steps

['Audit and validate all touchpoint counts below against current code', 'For each category, decide whether to migrate via locale YAML (I18n.t) or keep as-is', 'Create child items from categories marked for migration', 'Execute migrations in dependency order: error messages first, then MCP metadata, then remaining']

## Files

['src/audiagentic/config/components/**/*.yaml', 'src/audiagentic/components/**/*_mcp.py', 'src/audiagentic/foundation/**/*.py', 'tests/unit/**/test_*.py']

## Validation

After all sub-tasks: zero inline `message="..."` on AudiaGenticError raises (all use `_t_err`); all tool-descriptions/instructions loaded from locale YAML via I18n.t(); LSP label maps load from locale; section headings load via I18n; CLI output strings go through I18n; contributions rendered through I18n.

Full I18n Migration Touchpoint Inventory

CATEGORY 1 — Error messages (highest priority)
==============================================
- 236 AudiaGenticError raise sites across the codebase
- 217 unique error codes; 288 already defined in error-resolutions YAML
- Only 5 codes missing from YAML: CFG-ACP-001, CON-EOB-001, EXT-ACP-001, IO-TRIG-001, PROV-001
- 256 raise sites do NOT use _t_err() — all pass inline `message="..."` string
- These must be refactored to: message=_t_err("CODE") or message=I18n.t("component.errors.CODE", ...)
- Top components by error count:
  - agent_jobs: 70 sites
  - agents: 26 sites (agents_api, agents_gateway_store/queue/dispatch)
  - providers/services: 23 sites
  - planning: 18 sites (items.py, reviews.py, item_store.py)
  - release: 12 sites
  - foundation + subdirs: ~25 sites total
- Action: Add missing 5 codes to locale YAML; refactor all raise sites to use _t_err()

All defined inline in component YAML under `tool-descriptions:` sections. These must move to per-component locale YAML and be loaded via I18n.t() at server registration time.

- providers: 22 tool descriptions + 1 instruction

- session: 7 tool descriptions + 1 instruction
- project: 7 tool descriptions + 1 instruction
