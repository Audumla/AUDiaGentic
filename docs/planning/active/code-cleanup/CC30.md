# Config-driven plan item section headings: ITEM_SECTION_HEADING and REVIEW_SECTIONS in item_store.py

## Description

Plan item markdown rendering uses hardcoded dict constants to map field names to `## Section Heading` titles. If the rendered heading format ever needs to change (e.g., localization, custom project conventions), these must be changed in code rather than config.

## Steps

['1. Add item-section-headings and review-sections to planning.yaml with current values as baseline\n2. Update component loader to parse these into the ComponentDescriptor or a planning-specific registry\n3. Refactor ITEM_SECTION_HEADING and REVIEW_SECTIONS from module-level constants to loaded values\n4. Verify plan item rendering is byte-identical before/after']

## Files

- item_store.py — replace module-level dict literals with YAML-loaded values
- planning.yaml — add item-section-headings: and review-sections: blocks
- frontmatter.py — update build_sectioned_body() to accept headings from config

## Validation
