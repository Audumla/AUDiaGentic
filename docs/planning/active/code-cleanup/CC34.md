# Implement I18n registry class: config-driven string lookup with locale switching

## Description

Add a thin I18n class as the standard access mechanism for all externalized user-facing text.

The class provides key-based lookup with locale switching and fallback chain. It loads
translation catalogs from YAML files at startup, making it a prerequisite for CC28–CC33
refactors that move hardcoded strings into config.

## Steps

1. **Create `foundation/i18n.py`** — the I18n class
   - `_catalogs: dict[str, dict]` — per-locale key→string maps
   - `_default_locale: str` — process-wide default (default: "en")
   - `_fallback_chain: list[str]` — ordered locale fallback list (configurable)
   - `load(directory: Path, default_locale: str = "en", fallback_locales: list[str] = None)` — reads all `.yaml` files from directory, key is filename stem
   - `t(key: str, locale: str = None, **ctx) → str` — key-based lookup with optional per-call locale override and string interpolation via `{var}` placeholders
   - `set_locale(locale: str)` — change process-wide default locale
   - `get_locale() → str` — return current default locale
   - Fallback chain: requested locale → default locale → key itself (if not found)
2. **Create config directory structure** — `src/audiagentic/config/locales/en.yaml` as the canonical source file, initially empty (will be populated by CC28–CC33 implementations)
3. **Register I18n.load() call** in component registration flow (`loader.py`), after error-resolutions loading, with locale from env var `AUDIAGENTIC_LOCALE` (default: "en")
4. **Add pluralization support** — import `babel.plural` standalone module only:
   - Extend YAML structure to support `_count` placeholder:
     ```yaml
     "files_found": "{count} file(s) found"
     "files_found_plural":
       one: "{count} file found"
       other: "{count} files found"
     ```
   - Add `t_plural(key_singular, key_plural, count)` — uses babel.plural to select correct form
5. **Add unit tests** for:
   - Basic key lookup in default locale
   - Per-call locale override
   - Fallback to default locale when key missing
   - Fallback to key itself when not found anywhere
   - String interpolation with `**ctx`
   - Plural form selection
   - Unknown locale returns key (no crash)

## Files

['/src/audiagentic/foundation/i18n.py', '/src/audiagentic/config/locales/en.yaml']

## Validation

- Unit tests cover all lookup paths: hit in locale, fallback to default, fallback to key
- `I18n.t("lsp:symbol_kind.class")` returns "Class" with en.yaml containing that entry
- `I18n.set_locale("de")` then `I18n.t("lsp:symbol_kind.class")` returns German translation
- Unknown locale does not crash, falls back to default locale
- Interpolation: `I18n.t("count", n=3)` with `{n}` placeholder returns correct string
- Plural form selection works for languages with multiple plural forms (e.g., Arabic has 6)

## Effort & Risk

**Risk**: Low. The class is trivially small (~50 lines) with no external dependencies beyond pyyaml.

**Effort**: ~2 hours including tests.
