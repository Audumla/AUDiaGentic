# Add shared config-managed declarative recipe loader

## Description

Add the smallest shared config-managed recipe target needed by Hindsight, CLI installation, LSP, and future owners. A strict YAML schema loads into a frozen validated recipe template; typed string parameters materialize existing probes and step-factory steps; existing DeclaredStepRecipe executes the lifecycle. Owners retain family-specific Request/Result contracts and explicitly select a recipe. CC41 does not migrate production callers or replace MA20 registry composition.
