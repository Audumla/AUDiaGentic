# Add profile resolution: --profile flag, env var, and profile root layout

## Description

Core feature. Depends on CP01 (single name resolver) and CP02 (real override wiring). Add a way to select a named profile at launch, resolving a profile root directory that mirrors the existing config/components/ layout under a subfolder named for the profile. When no profile is given, or the profile name is 'audiagentic', behavior must be unchanged from today - i.e. fall back to the current base folder. BLOCKING naming decision (found in deep-dive 2026-07-04): 'AUDIAGENTIC_PROFILE' collides in meaning with existing LLM/rig model-profile env vars already in use (AUDIAGENTIC_RIG_MODEL_PROFILE, AUDIAGENTIC_AG_MODEL_PROFILE, AUDIAGENTIC_RIG_PROFILE at runtime/rig/models.py:44-49, components/session/session_runtime_status.py:114, session_embedded_rig.py:19) - a user typing --profile could plausibly mean either. Use a disambiguated name, e.g. AUDIAGENTIC_COMPONENT_PROFILE / --component-profile.

## Steps
