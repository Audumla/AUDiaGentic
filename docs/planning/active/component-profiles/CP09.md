# Merge CLI composition root into runtime orchestration (move commands/ under runtime/)

## Description

Depends on CP00 landing first. Once commands/ no longer contains raw 'from audiagentic.components.X import Y' imports of specific optional components (all converted to get_capability() lookups per CP00), the only reason ARCHITECTURE_STANDARDS.md kept 'CLI / composition root' as a layer separate from 'Runtime orchestration' goes away - that separation existed specifically to let commands/ do the one thing runtime is forbidden from doing (import a specific optional component directly). With CP00 done, commands/ no longer needs that exemption, so the two layers can merge without weakening the underlying rule. This is a deliberate, small loosening of the layering constraint requested directly, not a reinterpretation of the existing standard - the standard's language must be updated to match, not just the file location.
