# Slim canonical gateway status contract

## Description

The status/state payloads returned by the gateway (agent_task_status, agent_task_gateway_overview, agent_task_session_list, etc.) have grown organically and are messy: odd/inconsistent field naming (mixed hyphen-case and terms that don't clearly convey meaning), duplicated information appearing under multiple keys, and poor functional grouping (related fields scattered rather than nested together by concern -- e.g. timing, provider metadata, watchdog/diagnostics, correlation identifiers). This makes the schema harder to consume correctly and easier to misread during live debugging, which this session did repeatedly tonight.

## Steps

- Make agent_task_status and request status/list projections use one compact V4 projector with no response-version negotiation.
- Keep routine status limited to task_id, lifecycle, activity, activity_seq, activity_at, and outcome; diagnostics are explicit and bounded, full response is server-side artifact dereference.
- Reject the retired response-version argument at service/API boundaries; do not emit V3 or dual shapes.
- Add payload-budget, no-preview, no-diagnostics, and endpoint-convergence tests.
- Keep session/overview/control surfaces purpose-specific and migrate callers in the same change.

## Detailed Solution & Technical Design

Current target (2026-08-25): public request polling has one fixed V4 projection. The gateway computes the provider-neutral AS92 snapshot internally, then projects only task_id, lifecycle, activity, activity_seq, activity_at, and outcome. agent_task_status, get_execution_request, list_execution_requests, and timeout status all use this projector. There is no response_version parameter, no V3 fallback, and no dual payload.

Diagnostics are owned by GP48/AS102 and exposed only through the bounded diagnostics operation. Full terminal text is owned by the request artifact store and exposed only through agent_task_response; no path, URI, preview, or artifact locator crosses MCP. Blocking in-process APIs may retain their terminal control record for internal orchestration, but that is not the polling contract.

Durable/session contract versions named v3 are separate persistence protocols and are not public task-status versions. Do not remove them without a storage migration plan.

#### Markdown serializer: concrete implementation shape

Keep \`assistantText()\` byte-for-byte behaviorally unchanged. Add the following helpers adjacent to it. The implementation may be factored into smaller local functions, but must preserve these semantics.

\`\`\`javascript
const MARKDOWN_MAX_CHARS = 200000;

const longestRun = (value, character) => {
  let longest = 0;
  let current = 0;
  for (const ch of String(value || "")) {
    if (ch === character) {
      current += 1;
      longest = Math.max(longest, current);
    } else {
      current = 0;
    }
  }
  return longest;
};

const normalizeInlineText = value => String(value || "")
  .replace(/\u00a0/g, " ")
  .replace(/[ \t\r\n\f\v]+/g, " ");

const escapeMarkdownText = value => normalizeInlineText(value)
  .replace(/\\/g, "\\\\")
  .replace(/([*_~\[\]#>])/g, "\\$1");

const safeHref = raw => {
  const href = String(raw || "").trim();
  if (!href) return null;
  if (/^(?:javascript|data|vbscript):/i.test(href)) return null;
  return href;
};

const codeFence = code => {
  const length = Math.max(3, longestRun(code, "\x60") + 1);
  return "\x60".repeat(length);
};

const inlineCode = code => {
  const raw = String(code || "");
  const delimiter = "\x60".repeat(Math.max(1, longestRun(raw, "\x60") + 1));
  const pad = raw.startsWith("\x60") || raw.endsWith("\x60") ? " " : "";
  return delimiter + pad + raw + pad + delimiter;
};

const blockTag = tag => new Set([
  "P", "H1", "H2", "H3", "H4", "H5", "H6", "PRE",
  "UL", "OL", "BLOCKQUOTE", "HR", "TABLE"
]).has(tag);

const directChildren = (element, tag) =>
  Array.from(element.children).filter(child => child.tagName === tag);

const languageForPre = pre => {
  const code = pre.querySelector("code");
  const candidates = [
    code?.getAttribute("data-language"),
    pre.getAttribute("data-language"),
    ...Array.from(code?.classList || [])
      .filter(name => name.startsWith("language-"))
      .map(name => name.slice("language-".length))
  ];
  const language = candidates.find(value => /^[A-Za-z0-9_+.#-]{1,64}$/.test(String(value || "")));
  return language ? String(language) : "";
};

const normalizeMarkdown = value => String(value || "")
  .split("\n")
  .map(line => line.replace(/[ \t]+$/g, ""))
  .join("\n")
  .replace(/\n{3,}/g, "\n\n")
  .trim();

const assistantMarkdown = element => {
  if (!element) return null;
  try {
    const root = element.cloneNode(true);
    root.querySelectorAll(
      'h4.sr-only, button, [role="button"], [data-markdown-copy="exclude"]'
    ).forEach(node => node.remove());
    root.querySelectorAll('[aria-hidden="true"]').forEach(node => {
      if (String(node.innerText || node.textContent || "").trim() === "…") node.remove();
    });

    const renderInline = node => {
      if (node.nodeType === Node.TEXT_NODE) return escapeMarkdownText(node.nodeValue || "");
      if (node.nodeType !== Node.ELEMENT_NODE) return "";
      const el = /** @type {Element} */ (node);
      const tag = el.tagName;
      if (tag === "BR") return "\n";
      if (tag === "CODE" && el.parentElement?.tagName !== "PRE") {
        return inlineCode(el.textContent || "");
      }
      const inner = Array.from(el.childNodes).map(renderInline).join("");
      if (tag === "STRONG" || tag === "B") return inner ? "**" + inner + "**" : "";
      if (tag === "EM" || tag === "I") return inner ? "*" + inner + "*" : "";
      if (tag === "DEL" || tag === "S") return inner ? "~~" + inner + "~~" : "";
      if (tag === "A") {
        const href = safeHref(el.getAttribute("href"));
        const label = normalizeMarkdown(inner) || (href || "");
        return href ? "[" + label + "](" + href + ")" : label;
      }
      return inner;
    };

    const renderListItem = (li, ordered, index, depth) => {
      const nested = Array.from(li.children).filter(
        child => child.tagName === "UL" || child.tagName === "OL"
      );
      const clone = li.cloneNode(true);
      Array.from(clone.children).forEach(child => {
        if (child.tagName === "UL" || child.tagName === "OL") child.remove();
      });
      const head = normalizeMarkdown(
        Array.from(clone.childNodes).map(renderInline).join("")
      );
      const prefix = ordered ? String(index + 1) + ". " : "- ";
      const indent = "  ".repeat(depth);
      const lines = [indent + prefix + head];
      for (const child of nested) {
        lines.push(renderList(child, depth + 1));
      }
      return lines.filter(Boolean).join("\n");
    };

    const renderList = (list, depth = 0) => {
      const ordered = list.tagName === "OL";
      return directChildren(list, "LI")
        .map((li, index) => renderListItem(li, ordered, index, depth))
        .filter(Boolean)
        .join("\n");
    };

    const renderTable = table => {
      const rows = Array.from(table.querySelectorAll("tr"));
      if (!rows.length) return "";
      const cells = row => Array.from(row.querySelectorAll(":scope > th, :scope > td"))
        .map(cell => normalizeMarkdown(
          Array.from(cell.childNodes).map(renderInline).join("")
        ).replace(/\n+/g, " ").replace(/\|/g, "\\|"));
      const explicitHead = table.querySelector("thead tr");
      const headRow = explicitHead || rows[0];
      const head = cells(headRow);
      if (!head.length) return "";
      const bodyRows = rows.filter(row => row !== headRow && !row.closest("thead"));
      const width = head.length;
      const fit = values => Array.from({length: width}, (_, i) => values[i] || "");
      return [
        "| " + fit(head).join(" | ") + " |",
        "| " + Array(width).fill("---").join(" | ") + " |",
        ...bodyRows.map(row => "| " + fit(cells(row)).join(" | ") + " |")
      ].join("\n");
    };

    const renderBlock = node => {
      if (node.nodeType === Node.TEXT_NODE) return normalizeMarkdown(renderInline(node));
      if (node.nodeType !== Node.ELEMENT_NODE) return "";
      const el = /** @type {Element} */ (node);
      const tag = el.tagName;
      if (/^H[1-6]$/.test(tag)) {
        return "#".repeat(Number(tag[1])) + " " +
          normalizeMarkdown(Array.from(el.childNodes).map(renderInline).join(""));
      }
      if (tag === "P") {
        return normalizeMarkdown(Array.from(el.childNodes).map(renderInline).join(""));
      }
      if (tag === "PRE") {
        const code = el.querySelector("code")?.textContent ?? el.textContent ?? "";
        const fence = codeFence(code);
        const language = languageForPre(el);
        return fence + language + "\n" + code.replace(/\n$/, "") + "\n" + fence;
      }
      if (tag === "UL" || tag === "OL") return renderList(el);
      if (tag === "BLOCKQUOTE") {
        const body = renderChildren(el);
        return body.split("\n").map(line => line ? "> " + line : ">").join("\n");
      }
      if (tag === "HR") return "---";
      if (tag === "TABLE") return renderTable(el);
      return renderChildren(el);
    };

    const renderChildren = parent => {
      const parts = [];
      let inline = "";
      const flushInline = () => {
        const normalized = normalizeMarkdown(inline);
        if (normalized) parts.push(normalized);
        inline = "";
      };
      for (const child of parent.childNodes) {
        if (child.nodeType === Node.ELEMENT_NODE && blockTag(child.tagName)) {
          flushInline();
          const block = normalizeMarkdown(renderBlock(child));
          if (block) parts.push(block);
        } else {
          inline += renderInline(child);
        }
      }
      flushInline();
      return parts.join("\n\n");
    };

    const markdown = normalizeMarkdown(renderChildren(root));
    if (!markdown || markdown.length > MARKDOWN_MAX_CHARS) return null;
    return markdown;
  } catch (_) {
    return null;
  }
};
\`\`\`

#### Acceptance refinement

Implementation is not complete merely because Markdown appears in one happy-path response. It is complete only when:
- the exact request-owned verified assistant remains the sole source of rich output;
- changing Markdown alone cannot make an unverified turn complete;
- Markdown failure/oversize cannot make a proven turn fail;
- candidate Markdown cannot be reused across assistant-id or verified-plain-text changes;
- generated Markdown is syntactically closed (no deliberate truncation of fences/tables);
- artifact bytes/hash/media type agree;
- compact V4 remains unchanged when response inclusion is disabled/nonterminal/unavailable;
- terminal status and dedicated response each require one gateway RPC from MCP;
- failed/cancelled legitimate final output remains retrievable without promoting failure diagnostics to response content;
- reconnect replay recognizes the new structured response method as read-only;
- no private artifact/provider/diagnostic material leaks across MCP or standalone service.
