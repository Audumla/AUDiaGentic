# Dedicated dashboard tab blocks new GPT session tab

## Notes



## Findings

Live gateway Test 2 admission waited for 30 seconds then rolled back without a visible GPT chat. The dashboard change caused PersistentChat to use a dashboard-tab opener. Chrome did not report an opener target for that CDP window.open path. Direct project opening in a separate browser window succeeds.

## Conclusion

Use a new dedicated ChatGPT project window for a new session; retain the dashboard as its own CDP-managed window.
