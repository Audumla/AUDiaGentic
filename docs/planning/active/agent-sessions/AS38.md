# Wire AS37 status snapshot into SH07 request status projection

## Description

AS37 Stage-1 delivered the pure foundation types (AgentStatusScope, AgentLifecycle, AgentOutcome, AgentWaitReason, StatusEvidenceConfidence, AgentStatusDecisions, AgentStatusSnapshot) in src/audiagentic/foundation/transports/agent_status.py, plus an AS21 adapter `snapshot_from_decision(...)` in agents_session_lifecycle_projection.py that maps a SessionLifecycleDecision to an AgentStatusSnapshot. Both pieces are tested and merged but nothing consumes them yet — SH07's public request-status read path still returns its own ad hoc dict shape. This item adds the public projection adapter for the `execution-request` scope only (session/turn/workflow scopes are out of scope here) so a caller of the existing request status API gets a real AgentStatusSnapshot instead of raw internal fields.

## Steps

1. Locate the existing SH07 request status read function (likely `agents_gateway_store.project_public_status` or the request status API in `agents_gateway_api.py` — confirm exact name via `rg "project_public_status|def.*request_status" src/audiagentic/components/agents`).
2. Add a pure adapter `src/audiagentic/components/agents/agents_status_projection.py` with `snapshot_for_request(record: dict, *, decision: SessionLifecycleDecision | None = None) -> AgentStatusSnapshot`. It reads only already-redacted/public record fields (request-id, state, error code, timestamps) — never raw provider fields. When a durable terminal state exists in the record (completed/failed/cancelled/interrupted) it takes priority over any AS21 decision (SH07 durable authority always wins over an ephemeral evidence-based decision per AS37 step 6).
3. Map SH07 durable states to AgentOutcome: completed→SUCCESS, failed→FAILED, cancelled→CANCELLED, interrupted→INTERRUPTED (never confuse interrupted with cancelled or failed — this is the exact case AS37 step 6 calls out).
4. When no durable terminal state exists yet and an AS21 decision is available, defer to `snapshot_from_decision(decision, scope=AgentStatusScope.EXECUTION_REQUEST, request_id=..., ...)`.
5. When neither a durable terminal state nor an AS21 decision exists, return AgentStatusSnapshot with lifecycle=UNKNOWN, outcome=None, decisions=None — never fabricate.
6. Do NOT change the existing wire format/schema of the request status API response in this item — only add the new adapter function and its tests. Wiring the adapter into the actual public API response is a follow-on item once the schema/versioning decision is made (adding a new field vs replacing the shape is a compatibility decision, not a code change to rush).
7. Add focused tests in `tests/unit/agents/test_agents_status_projection.py` covering: completed record → SUCCESS terminal snapshot; failed record → FAILED; cancelled → CANCELLED; interrupted record → INTERRUPTED (not CANCELLED, not FAILED); running record + active AS21 decision → ACTIVE; running record + no decision → UNKNOWN; queued record → PENDING.
8. Run `python -m pytest tests/unit/agents/test_agents_status_projection.py -v` then `python -m pytest tests/unit/agents/ -q --tb=no` to confirm zero regressions.

## Detailed Solution & Technical Design

The adapter is intentionally a pure function with no I/O, no gateway/store imports beyond reading a plain dict, and no persistence. It sits between two existing authorities (SH07's durable record and AS21's ephemeral decision) and never introduces a third. Priority order when both durable state and a decision are present: durable state always wins for outcome/lifecycle=TERMINAL, because SH07's record is the actual source of truth for whether a request finished — AS21's decision might be stale (e.g. computed before the finalization commit). The critical invariant this item must preserve is AS37's note: 'SH07 interrupted maps to terminal lifecycle plus outcome interrupted, never a second coarse lifecycle state' — do not add an INTERRUPTED lifecycle value, only the AgentOutcome.INTERRUPTED value paired with AgentLifecycle.TERMINAL.

The function signature takes a plain `record: dict` (matching whatever `project_public_status` or equivalent already returns) rather than a typed request-record class, because the goal is a thin adapter over the *existing* public projection, not a rewrite of SH07's store internals. If the existing public projection function turns out to already return a typed dataclass instead of a dict, adapt the signature to match — the shape source of truth is the current code, not this plan text.

## Code Samples & Guidance

```python
# src/audiagentic/components/agents/agents_status_projection.py
from __future__ import annotations

from audiagentic.components.agents.agents_session_lifecycle_projection import (
    SessionLifecycleDecision,
    snapshot_from_decision,
)
from audiagentic.foundation.transports.agent_status import (
    AgentLifecycle,
    AgentOutcome,
    AgentStatusScope,
    AgentStatusSnapshot,
)

_DURABLE_OUTCOME_MAP: dict[str, AgentOutcome] = {
    "completed": AgentOutcome.SUCCESS,
    "failed": AgentOutcome.FAILED,
    "cancelled": AgentOutcome.CANCELLED,
    "interrupted": AgentOutcome.INTERRUPTED,
}


def snapshot_for_request(
    record: dict,
    *,
    decision: SessionLifecycleDecision | None = None,
) -> AgentStatusSnapshot:
    """Project a public SH07 request-status record (+ optional AS21 decision)
    into an AgentStatusSnapshot. Durable SH07 state always wins over an
    ephemeral AS21 decision for terminal outcomes.
    """
    state = record.get("state")
    request_id = record.get("request-id")

    if state in _DURABLE_OUTCOME_MAP:
        return AgentStatusSnapshot(
            scope=AgentStatusScope.EXECUTION_REQUEST,
            lifecycle=AgentLifecycle.TERMINAL,
            outcome=_DURABLE_OUTCOME_MAP[state],
            wait_reason=None,
            decisions=None,
            request_id=request_id,
            session_id=record.get("session-id"),
            turn_id=None,
            generation=None,
            attempt=record.get("attempt-epoch"),
            observed_at=record.get("finished-at") or record.get("updated-at"),
            projected_at=_now_iso(),
        )

    if decision is not None:
        return snapshot_from_decision(
            decision,
            scope=AgentStatusScope.EXECUTION_REQUEST,
            request_id=request_id,
            session_id=record.get("session-id"),
        )

    if state == "queued":
        return AgentStatusSnapshot(
            scope=AgentStatusScope.EXECUTION_REQUEST,
            lifecycle=AgentLifecycle.PENDING,
            outcome=None,
            wait_reason=None,
            decisions=None,
            request_id=request_id,
            session_id=record.get("session-id"),
            turn_id=None,
            generation=None,
            attempt=None,
            observed_at=None,
            projected_at=_now_iso(),
        )

    return AgentStatusSnapshot(
        scope=AgentStatusScope.EXECUTION_REQUEST,
        lifecycle=AgentLifecycle.UNKNOWN,
        outcome=None,
        wait_reason=None,
        decisions=None,
        request_id=request_id,
        session_id=record.get("session-id"),
        turn_id=None,
        generation=None,
        attempt=None,
        observed_at=None,
        projected_at=_now_iso(),
    )
```

Confirm the exact `_now_iso()` helper already used elsewhere in the agents component (there should be an existing bounded UTC-ISO timestamp helper — reuse it, do not add a new one) before implementing.
