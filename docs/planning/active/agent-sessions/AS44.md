# Define generic session capability families and surface declarations

## Description

Create the common foundation/provider declaration layer that lets each harness surface advertise the generic external-management capabilities it actually supports, even when only one harness currently implements a family.

## Steps

1. Freeze the generic vocabulary, enums, request/result structures, and JSON schema in foundation.
2. Extend provider resolved-surface declarations and descriptor validation to carry per-surface capability records.
3. Project an immutable redacted snapshot into the existing session binding/status path.
4. Add contract, descriptor, resolver, projection, and architecture-boundary tests.
5. Do not wire external control endpoints here; AS43 consumes the accepted contract.
