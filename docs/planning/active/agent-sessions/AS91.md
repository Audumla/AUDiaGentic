# Recover proven-orphaned turns through task-owned cleanup

## Description

Detect a proven-dead owned harness process during an active turn and recover through the normal lifecycle — without manually releasing locks or mutating scheduler sets.

The distinction this item turns on: a timeout is policy, not proof of death. Only process-identity evidence proves a turn is orphaned.

## Steps

1. Add explicit current-turn ownership to the session handle if absent: current turn request id, turn id, owning task, owned process evidence, closing deadline.
2. Add a pure predicate `is_proven_owned_turn_dead(handle, now)`. True only when the handle owns the process and process identity proves the same child is dead during a non-terminal turn. Conservative false for: unknown process state, missing identity, external/unowned process, PID-reuse risk, timeout or silence alone, missing turn task.
3. Add the reaper entry point. It may inspect non-quiescent handles but may act only when the predicate is true.
4. On proven death: record one session timeline event on the existing `agents.session.orphaned` topic; mark the session closing/failed through existing store helpers; cancel the owning turn task or close the transport through existing seams; let the owning task's `finally` release its lock, slot and accounting exactly once.
5. Add bounded force-close after a closing deadline, only for proven owned descendants, through the existing foundation cleanup seam. Never signal external processes.
6. Coordinate the durable request outcome by calling the existing terminal transition authority exactly once. Add no second recovery API.

## Validation

- A fake owned child exiting mid-turn produces exactly one orphan event, one active->closing/failed transition, and one lock/slot release.
- Unknown process state: no orphan event, no kill, no state change.
- An external process is never signalled.
- PID reuse or stale identity: conservative no-action.
- Silence timeout alone produces no orphan event.
- A pending next turn unblocks without deadlock after cleanup.
- Docker proves real owned descendant cleanup and external-process non-interference.
