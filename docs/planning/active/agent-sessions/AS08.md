# Integrate detached session ownership with the shared gateway control plane

## Description

Phase-2 session integration. Move SessionRuntime ownership out of the submitting MCP/harness process and into the machine-wide control plane designed and delivered by SH01–SH11, so sessions survive client restarts and can be shared across clients. This item does not create a separate agents-owned daemon: shared-gateway owns service transport, discovery, durable request ownership, execution context, workers, and lifecycle; AS08 owns session registry and turn-policy integration on that control plane.

## Steps

1. After SH01/SH02 freeze the service and execution-context contracts, define the session-specific remote operations and durable session record additions. 2. Host the session registry/turn serializer in the SH04 control plane and bind owned provider transports to SH06 context-isolated workers. 3. Preserve per-session FIFO turns, bounds, expiry, external-vs-owned process semantics, and stable errors across the client boundary. 4. Integrate ownership-aware recovery/cancellation with SH07 and client lease/drain behavior with SH10. 5. Keep AS09 attach/event cursor, AS10 resume, and AS12 lifecycle events as session-domain consumers. 6. Add service/worker kill, reconnect, concurrent-client, and no-orphan tests.

## Files

Agents session runtime/store/API and shared-gateway public integration seams identified by SH01 design; no gateway-local discovery, PID journal, startup lock, or generic service manager implementation.

## Validation

A session opened from project A survives its submitting harness exit, is addressable from another authorized client, retains the exact SH02 execution context, serializes concurrent turns, recovers or terminates deterministically after service/worker failure, and leaves no owned provider process orphaned. A conflicting project B cannot attach accidentally.

## Effort & Risk

Complex session migration. Main risks are weakening current cleanup invariants, confusing service lifetime with session lifetime, and duplicating shared-gateway or PR05 ownership.
