## Agreed domain model

1. `SessionSurface` — exact provider/harness interface and validated capability truth; AS29 authority.
2. `ExecutionProfile` — reusable provider, model, selected surface, execution parameters and admission policy.
3. `Role` — reusable instructions, tools, permissions and capability requirements.
4. `AgentDefinition` — logical identity, skills and interface policy composed from one Execution Profile and one Role.
5. `InteractionSession` — persistent two-way continuity over one immutable generation.
6. `AgentTask` — externally requested work; initially maps to the existing durable request and one session turn.
7. `Turn` — one execution within an Interaction Session.
8. ACP — external interactive-session protocol adapter.
9. A2A — external agent/task federation protocol adapter.
10. MCP or harness extensions — how a running harness invokes AUDiaGentic delegation tools.

## Existing authorities that remain

- AS19: sole provider-neutral transport, control and observation contracts.
- AS21: sole lifecycle and session-reuse authority.
- AS29: sole exact session-surface/version/platform capability authority.
- AS30: sole durable AUDiaGentic-to-provider session binding/index authority.

No new item may create a parallel profile store, capability registry, session store, binding index, output lane, lifecycle engine, process manager, queue or task coordinator.
