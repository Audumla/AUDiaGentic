# Session test suite: fake ACP agent, reaper/cleanup proofs, routing, no-orphan guarantee

## Description

Dedicated unit-test coverage for the whole slim path. The catalogue lesson (CC41: shipped code with zero executed tests) must not repeat — every new module lands with its tests in the same change.

## Steps

1. Fake ACP agent: a tiny in-repo python script speaking enough ACP over stdio (initialize, new_session, prompt echoing a per-session turn counter) to exercise the REAL transport end-to-end without opencode — proves context retention (turn 2 sees state from turn 1) and real child process cleanup (psutil/handle checks that the pid is gone after close).
2. Transport tests (AS01 list) run against the fake agent.
3. Runtime tests (AS02 list) run against a fake transport class (no subprocess) for speed + the fake-agent variant for the cleanup no-orphan proof.
4. Dispatch routing tests (AS04 list) with monkeypatched runtime.
5. API/MCP tests (AS05 list).
6. Reaper time control: inject a clock (callable) into SessionRuntime rather than monkeypatching time — keeps tests deterministic and fast.

## Files

tests/unit/foundation/transports/test_acp_session.py; tests/unit/agents/test_agents_gateway_sessions.py; tests/unit/agents/test_agents_gateway_dispatch_sessions.py; tests/unit/agents/fixtures/fake_acp_agent.py

## Validation

Full suite green; the no-orphan test fails if any child pid survives close/shutdown.
