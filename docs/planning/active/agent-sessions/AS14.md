# Attach the gateway and Codex TUI to one loopback App Server thread

## Description

Deliver the proven Codex-specific shared-live-session capability on the landed SH04 control plane: gateway and human TUI connect to one externally owned loopback App Server thread, with explicit start/steer/interrupt/resume operations and correct detach semantics. Keep Codex protocol framing provider-owned.

## Steps

1. Probe the installed Codex App Server/TUI concurrency and protocol version before freezing the adapter contract. 2. Add the smallest agents-owned session transport/ownership port supporting ACP-owned and App-Server-external sessions. 3. Expose the Codex adapter through providers_api; do not add a foundation App Server transport without a second consumer. 4. Reuse SH04 auth, leases, application/client, and HTTP transport; extend its closed operations only for proven controls. 5. Persist only canonical loopback endpoint, provider thread ref, transport kind, ownership mode, and lifecycle outcome—never tokens/raw payloads. 6. External close records detached and leaves server/TUI alive; owned ACP close remains terminating. 7. Split transport binding/ownership from the session monolith.

## Files

Provider-owned Codex App Server adapter/public API; small agents transport/ownership contracts and SH04 operation extensions; session record additions; fake-server, integration, Windows/Linux/Docker tests.

## Validation

Gateway and simulated/real TUI observe one thread; start, steer, interrupt, resume, ordering, and conflicts are deterministic; non-loopback endpoints and malformed/oversized/version-mismatched frames fail stably; detach survives gateway close/restart; stale thread does not duplicate; owned ACP cleanup regresses green. Docker proves mutable CLI/App Server lifecycle and removal.

## Effort & Risk

Complex and dependency-gated on AS08 context binding plus AS17 ownership semantics. Upstream protocol and multi-client behavior must be treated as unproven until probed.

## Standards

Architecture Standards; Architecture Guidelines; Observability Standards where events/timelines are involved; docs/reference/PROVIDER_CAPABILITY_REFERENCE. Reuse foundation paths, workflow, events, process evidence, and managed-service seams before adding component-local machinery.

## Notes
