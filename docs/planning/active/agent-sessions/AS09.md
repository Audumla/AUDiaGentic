# Add bounded redacted remote event polling for active sessions

## Description

Remote send into an existing session already uses the normal `session-id` submission path and SH04 service. AS09 adds only the missing transport-neutral observation surface: authenticated, project-scoped, cursor-based polling of a bounded, metadata-only, redacted session-event stream. This is a Stage-4 item gated on AS19 normalized `StatusEvidence`, AS21 projected lifecycle decisions/state changes, and AS31 content-lane separation. It must not create durable replay, push streaming, steering, cancellation, content observation, or another request/job state authority.

## Steps

0. Gate implementation. Before coding the read surface, verify AS19, AS21, and AS31 prerequisites are landed. If not, implement only local pure buffer/cursor tests behind internal APIs and leave SH04/MCP exposure disabled.

1. Add a cohesive in-memory module, unless an equivalent already exists: `src/audiagentic/components/agents/agents_session_event_polling.py`. Do not extend `FileEventStore` or add durable event replay for this item.

2. Define the cursor/page contract in code:
```python
@dataclass(frozen=True)
class SessionEventCursor:
    session_id: str
    next_sequence: int
    issued_at: str
    generation: str

@dataclass(frozen=True)
class SessionEventPage:
    events: list[dict[str, Any]]
    next_cursor: str
    gap: dict[str, Any] | None
    has_more: bool
```
Encode cursors as opaque signed or integrity-checked tokens using an existing foundation helper if present; otherwise use a compact JSON token plus HMAC/keyed digest from existing project config/secrets only if such helper already exists. If no helper exists, use an internal structured cursor object for first-slice tests and do not expose it remotely.

3. Implement a bounded per-project/per-session buffer owner, e.g. `SessionEventPollBuffer`, with constants/defaults:
- `max_events_per_session`: 256
- `max_page_size`: 50
- `default_page_size`: 25
- retention is in-memory only; service restart changes `generation` and old cursors return a deterministic gap.
- gap response shape: `{ "reason": "expired-or-restarted", "from-sequence": <requested>, "next-available-sequence": <oldest> }`.

4. Accepted input events must be AS19/AS21/AS16 metadata-level records only. Add `append_status_evidence(...)`, `append_lifecycle_decision(...)`, and `append_diagnostic(...)` helpers if those source types exist. Each append normalizes to a redacted event dict with only: `sequence`, `timestamp`, `session-id`, `turn-id`, `kind`, `coarse-state`, `flags`, `source`, `correlation-id`, and bounded diagnostic code/message. Never store prompt text, assistant output, tool args/results, native protocol payloads, provider refs, auth, API keys, raw error objects, or stack traces.

5. Implement `poll_session_events(project_root, session_id, cursor=None, page_size=None, *, requester_context)` as a pure/application helper. It must validate project scope before reading, clamp page size, return ordered pages without duplicates, return deterministic gaps for expired history/restart generation mismatch, and never create a session/runtime as a side effect.

6. Add the SH04 closed read operation/client/MCP tool only after the pure helper is tested and prerequisite event sources exist. Suggested names: application method `poll_agent_session_events`, client method `poll_agent_session_events`, MCP tool `agent_session_events_poll`. The MCP schema accepts `session_id`, optional `cursor`, optional `page_size`; it returns the `SessionEventPage` public dict.

7. Verify remote FIFO is unchanged by adding/keeping a test where a second standalone client polls events while another submits a later `session_id` turn. Polling must not take the session turn lock, create a runtime, or advance queue state.

8. Explicit non-goals: no push/SSE/websocket, no cancel/steer/interrupt, no AS31 content channels, no durable replay, no provider-specific adapters, no raw event bus cursor platform.

## Validation

First slice validation: table-driven unit tests prove ordered pages, cursor resume without duplicates, page-size clamping, deterministic gap on generation mismatch/expired sequence, cross-project/session rejection, and redaction of content-bearing/protected fields. Remote surface validation, once enabled: a second standalone client polls pages and then submits a later turn with FIFO preserved. Docker validation should use a fake streaming ACP child only after AS19/AS21/AS31 sources exist; until then Docker is out of scope.
