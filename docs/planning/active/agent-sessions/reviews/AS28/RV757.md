# Type Safety and LSP Diagnostics Review: session_surface_resolution.py, public_execution.py, acp.py

## Notes

Type Safety and LSP Diagnostics Review: session_surface_resolution.py, public_execution.py, acp.py - LSP diagnostics revealed type safety issues including identity operators with literals, sort key None handling, Path vs str mismatch, and abstract class type issues.

## Findings

LSP diagnostics revealed type safety issues:

1. session_surface_resolution.py L329, L344: Identity operators with literals
   - 'if result is True:' should be 'if result:'
   - 'if result is False:' should be 'if not result:'

2. session_surface_resolution.py L334: Sort key None handling
   - _parse_version returns tuple[int, ...] | None
   - sort key lambda in compatible.sort doesn't handle None case

3. public_execution.py L224: Path vs str mismatch
   - launch_kwargs['request_runtime_root'] = request_runtime_root
   - request_runtime_root is Path | None, dict expects str

4. acp.py L538, L494, L955: Abstract class and type issues
   - _SessionClient missing write_text_file, read_text_file implementations from Client protocol
   - request_permission return type mismatch with Client base class (returns dict[str, Any] vs RequestPermissionResponse)
   - ag_session_id type is str | None but parameter in __init__ expects str
