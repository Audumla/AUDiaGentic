# Adversarial Review: Provider-Neutral Session Transport Contract (AS28) and Session Surface Resolution (AS29)

## Notes

Parallel adversarial review findings for the multi-file changes introducing a provider-neutral session transport contract and session surface resolution. Found issues with _enforce_validation_ceiling simplification, identity operators in session_surface_resolution.py, sort key None handling, Path vs str mismatch in public_execution.py, _SessionClient abstract class issues in acp.py, test file sink parameter name mismatches, and _parse_enum type compatibility issues in loader.py.

## Findings

Primary findings from adversarial review:

1. Correctness and Regressions:
   - Foundation neutral transport contract (foundation/transports/agent_session.py) properly defines frozen dataclasses, enum validation, scalar-only discipline, and rejects raw/native attributes like provider_session_ref, prompt, output, tool_arguments, payload.
   - ACP adapter wrapper (foundation/transports/acp.py) correctly maps ACP events to TransportObservation and maintains the private boundary - AcpAgentSessionTransport is not exported from transports.__all__.
   - Control payload validation in SessionControlRequest properly implements default-deny: only canonical keys are allowed per action, and no-payload actions reject any payload.

2. Simplification Issue Found:
   - _enforce_validation_ceiling function in session_surface_resolution.py line ~250 has redundant nested condition that can be simplified:
     Current: if effective_level.numeric >= 2 and validation_state != SurfaceValidationState.BLOCKED:
                if validation_state != SurfaceValidationState.VALIDATED:
                    return True, 'unvalidated-high-level'
     Should be: if effective_level.numeric >= 2 and validation_state not in (SurfaceValidationState.BLOCKED, SurfaceValidationState.VALIDATED):
                    return True, 'unvalidated-high-level'
