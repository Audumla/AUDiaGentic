# Expose capability-gated external session controls

## Description

Make the existing AS28/AS29 neutral session controls usable through the gateway without exposing ACP or Pi RPC native commands. Clients discover a redacted capability snapshot and invoke only declared, authorized common actions.

## Steps

1. Consume the accepted AS44 vocabulary and session capability snapshot; do not redefine it.
2. Add generic authorization, validation, dispatch, and disposition service layers.
3. Implement only validated provider adapters beginning with Pi RPC/ACP fakes.
4. Wire the gateway API/client/MCP command surface and audit/timeline records.
5. Add cross-project, idempotency, policy, topology, and no-leak tests.
6. Enable real capability actions only after AS40/AS41 Docker evidence.
