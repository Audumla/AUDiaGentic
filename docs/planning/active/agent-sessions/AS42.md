# Expose authorized live session turn events and output stream

## Description

Provide an external gateway surface for authorized clients to observe a live session turn: bounded redacted lifecycle/status events and streamed assistant output chunks. Reuse the internal event/timeline path; do not expose provider-native frames or create a separate session authority.
