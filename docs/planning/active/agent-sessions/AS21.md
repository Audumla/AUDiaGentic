# Project trusted terminal evidence into coarse session decisions

## Description

Implement a pure transport-independent projector from validated correlated terminal/activity evidence to coarse session state and explicit decision flags. It owns no durable record: SH07 gateway request records and agent-jobs workflow job records remain distinct authorities that consume the projection exactly once.

## Steps

1. Add a pure reducer module, unless an equivalent already exists: `src/audiagentic/components/agents/agents_session_lifecycle_projection.py`. Keep it importable without starting gateway runtimes, queues, providers, MCP, or file stores.

2. Define closed vocabulary types in that module using `Literal`/frozen dataclasses or typed dicts matching local style:
```python
EvidenceKind = Literal[
    "turn-started", "activity", "waiting", "tool-active", "tool-completed",
    "permission-wait", "terminal-success", "terminal-cancelled",
    "terminal-failed", "transport-closed", "transport-error",
    "finalization-committed", "finalization-failed", "blocking-work-cleared",
]
CoarseSessionState = Literal["active", "waiting", "completing", "available", "failed", "unknown"]
@dataclass(frozen=True)
class SessionLifecycleEvidence:
    session_id: str
    turn_id: str
    sequence: int
    kind: EvidenceKind
    correlation_id: str | None = None
    timestamp: str | None = None
    validation_state: Literal["validated", "candidate", "rejected"] = "validated"
    source: str = "transport"
@dataclass(frozen=True)
class SessionLifecycleDecision:
    coarse_state: CoarseSessionState
    accepts_new_turn: bool
    session_reusable: bool
    turn_terminal: bool
    dependent_work_releasable: bool
    evidence_state: Literal["accepted", "candidate-only", "contradictory", "insufficient", "rejected"]
    reason: str
```
Use existing project naming conventions if they already exist, but preserve these fields and semantics.

3. Implement `project_session_lifecycle(evidence: Iterable[SessionLifecycleEvidence]) -> SessionLifecycleDecision`. Required rules:
- Empty, rejected-only, candidate-only, missing turn correlation, duplicate/lower sequence contradiction, or mixed turn IDs returns conservative `unknown` with every release/reuse flag false.
- `turn-started`, `activity`, and `tool-active` project `active`; `waiting` and `permission-wait` project `waiting`; terminal evidence without finalization projects `completing`.
- `terminal-success` + `finalization-committed` + `blocking-work-cleared` is the only path to `available` with `accepts_new_turn=True`, `session_reusable=True`, `turn_terminal=True`, `dependent_work_releasable=True`.
- `terminal-cancelled` + `finalization-committed` may set `turn_terminal=True` and `dependent_work_releasable=True`, but `session_reusable` is true only if no failure/close evidence exists and `blocking-work-cleared` is present.
- `terminal-failed`, `transport-error`, `transport-closed`, or `finalization-failed` projects `failed` unless contradicted, with reuse false. `dependent_work_releasable` is true only after finalization has committed or failed under the owning request authority.
- A terminal protocol event alone never means `available`; commit-before-available is mandatory.

4. Add a small adapter from existing redacted session-turn projections only if it is obvious from `agents_gateway_sessions_store.latest_turn_projection()` shape. Name it `evidence_from_latest_turn_projection(...)`. It must reject/ignore content-bearing fields and provider refs. Do not read raw prompts, output, tool arguments, native protocol payloads, auth, or provider binding internals.

5. Do not integrate gateway request transitions or agent-jobs in the first slice unless the consumer seam already accepts a pure decision object. If integration is deferred, add a note to AS21 documenting exact call sites to wire later: SH07 request transition consumption and agent-jobs lifecycle mapping.

6. Add focused unit tests in `tests/unit/agents/test_agents_session_lifecycle_projection.py` covering: active, waiting, completing, available, failed, unknown-empty, candidate-only, rejected-only, mixed turn IDs, duplicate/lower sequence contradiction, terminal-before-finalization, finalization-failed, cancel-with-commit, and identical evidence from two sources projecting identically.

7. Add one redaction test for any adapter: a projection containing prompt/output/tool args/native-topic/provider-ref-like keys must produce evidence without those fields or reject it conservatively.

8. Run:
```powershell
.\.venv\Scripts\python.exe -m pytest tests\unit\agents\test_agents_session_lifecycle_projection.py -q
```
Then run the nearest existing session tests touched by imports. Record exact results in AS21 notes before marking complete.
