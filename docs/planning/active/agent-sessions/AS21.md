# Project trusted terminal evidence into coarse session decisions

## Description

Implement a pure transport-independent projector from validated correlated terminal/activity evidence to coarse session state and explicit decision flags. It owns no durable record: SH07 gateway request records and agent-jobs workflow job records remain distinct authorities that consume the projection exactly once.

## Steps

1. Define accepted evidence/correlation and contradiction rules after AS19. 2. Validate ACTIVE/WAITING/COMPLETING/AVAILABLE/FAILED/UNKNOWN with its own TransitionEngine YAML. 3. Emit accepts_new_turn, session_reusable, turn_terminal, and dependent_work_releasable flags; UNKNOWN is conservative. 4. Preserve staged O2 prompt-return behavior while migrating consumers. 5. Replace agent-jobs direct raw agents.llm outcome mapping with the projected decision contract without double dispatch. 6. Feed SH07 request transitions without creating storage. 7. Add duplicate, disagreement, candidate-only, wait, cancel, failure, and late-terminal tests.

## Files

Pure agents lifecycle projector/workflow, gateway/agent-jobs consumer adapters, existing event contracts, focused tests. No persistence module or provider-specific branching.

## Validation

Table-driven projector cases are deterministic and redacted; gateway request and agent-jobs workflow records each transition under their own authority exactly once; duplicate/late/contradictory evidence cannot release dependent work twice; transports with identical evidence project identically.

## Effort & Risk

Mid. Migration risk is duplicate terminal side effects; pure projection and idempotent consumers contain it.

## Standards

Architecture Standards; Architecture Guidelines; Observability Standards where events/timelines are involved; docs/reference/PROVIDER_CAPABILITY_REFERENCE. Reuse foundation paths, workflow, events, process evidence, and managed-service seams before adding component-local machinery.
