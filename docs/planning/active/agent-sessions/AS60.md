## Goal

Rename the existing provider/model execution configuration to `ExecutionProfile` without changing queue, admission or session behavior.

The project YAML, agents public CRUD API, and `ag-agents-mgmt` MCP are one configuration-management path. Shared-gateway mode resolves additional admission facts; it is not a second management authority.

An Execution Profile contains only provider/model, selected AS29 surface or provider default, launch parameters, queue/admission settings and existing session-lifetime settings. It does not own Role, runtime tools, permissions, skills or ACP/A2A publication.
