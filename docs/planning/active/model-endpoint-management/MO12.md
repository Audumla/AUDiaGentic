# Build normalized model-source catalog cache

## Description

Provide normalized static/list-api source catalogs, filtering, and cached degradation consumed by MO07. No provider config projection or key injection.

## Steps

1. Define SourceCatalogResult: source_id, discovery_mode, models, fetched_at, freshness (fresh|cached|missing), stale, failure_class, error_code, action_needed. Models use the neutral MO02 materialized-input fields and contain no provider-native shape.
2. Load static catalogs from config/providers/model-catalogs/<source-id>.yaml with schema validation; data changes require no code edits.
3. Add connector fetcher registry keyed by connector id; fetchers receive redacted connectivity inputs and return normalized models. No provider-id/vendor branching.
4. Cache list-api results atomically at .audiagentic/runtime/providers/source-catalogs/<source-id>.json. Validate on read/write; corrupt cache reports contract failure and is not used.
5. Apply include/exclude glob filter as a pure function after normalization. Define precedence: exclude wins; empty include means all; stable sort by model id.
6. Explicit refresh uses one bounded retry for transient failures per MO08. On failure return validated last-known-good cache with cached/stale/action_needed; no cache returns missing. Ordinary reconcile performs no network call.
7. Emit redacted provider-source-catalog timeline/operational events with correlation_id and counts only.

## Files

[COMPONENT:providers] services/source_catalog.py — normalized loader/fetch/cache/filter API
[CONFIG] config/providers/model-catalogs/*.yaml — static data

[RUNTIME] .audiagentic/runtime/providers/source-catalogs/*.json — instances
[TEST] tests/unit/providers/test_source_catalog.py

## Validation

1. Static/list-api/none modes return exact SourceCatalogResult shape.
2. Registry dispatch test adds fixture connector without core code edit.
3. 429/timeout/5xx retry once then cached result; 401/403/config/contract failures do not retry.
4. Corrupt/missing cache behavior deterministic.
5. Filter table covers include/exclude overlap and stable order.
6. Secret canary absent from results, cache, logs, timelines.
7. No network call during ordinary reconcile.

## Effort & Risk

Mid. Network/cache boundary isolated from projection. Risk: secret leakage and incompatible result shapes; schema + canary tests gate both.
