# Extend model management to remaining compatible providers

## Description

Add support or explicit unsupported/manual status for the remaining providers after the core service and first-wave adapters are stable. This covers Continue, Cline, Roo, Aider, Plandex, and native/account-derived providers.

## Steps

1. Add Continue YAML model writer for `models` entries; decide legacy JSON support separately.
2. Validate Cline extension storage; add adapter only if settings/profile file is stable.
3. Validate Roo extension storage; fix descriptor access/auth semantics before adding adapter.
4. Add Aider launch-time env/config projection if execution adapter becomes real.
5. Add Plandex custom provider/model writer after execution/config path is wired.
6. Mark Gemini, Claude, Copilot, Antigravity as native/account-derived/manual unless custom endpoint docs and config storage are validated.
7. Update provider READMEs with capability table, config surface, source docs, and AUDiaGentic support status.
