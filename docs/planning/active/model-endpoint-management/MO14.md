# Validate Qwen and Goose model config support

## Description

Bound uncertain first-wave providers. Implement Qwen structured writer only after path/merge verification; keep Goose manual unless exact contract and real execution exist.

## Steps

1. Verify installed Qwen settings path/scope, modelProviders shape, selection pointer, merge/reload behavior; record version/evidence.
2. If verified, implement Qwen reader/writer/remover through MO06 core and descriptor declaration. If any contract missing, bind NoAutomationRecipe with exact blocker.
3. Verify Goose config path/schema/reload and current execution bridge. Do not infer model config from existing MCP .goose/config.yaml.
4. Goose automation requires both verified config and non-stub execution; otherwise status remains blocked/manual.
5. Add golden tests only for verified automation; add status tests for every blocked branch.
