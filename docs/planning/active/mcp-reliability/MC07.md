# Move gateway operator tools to opt-in ag-agents-gateway-ops server

## Description

Phase 2 of MCP tool slimming (follows MC06). Ten operator tools (diagnostics, observations, evidence, observation_replay, recover, failure_response, complete_from_provider, session_purge, gateway_purge, gateway_overview) are not needed by agents that submit work, yet cost schema tokens every session. Move them to a separate worktree-scoped server ag-agents-gateway-ops with propagate none, so setup does not register it; install explicitly via mcp install. No aliases.

## Steps

1. Shared helpers to gateway_mcp_support. 2. gateway_ops_mcp module. 3. agents.yaml declarations. 4. Tests and docs.
