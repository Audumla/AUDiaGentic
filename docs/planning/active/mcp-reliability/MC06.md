# Slim agent-facing MCP schemas and deliver server instructions

## Description

The three agent-facing servers (gateway, planning, ledger) sent ~36k chars of tool schema per session (~9k tokens) and never delivered their YAML instructions. Phase 1 of MCP tool slimming: drop generated titles and null defaults, shrink the worktree argument, rewrite descriptions to the 80-180 char standard, and deliver short instructions through the shared server factory. Phase 2 (operator tools to an opt-in server) and phase 3 (merge discrete tools) follow with no aliases or shims.

## Steps

1. Strip title and default:null in the shared component server. 2. Worktree argument becomes a plain string with a 55 char description. 3. Instructions from the component YAML reach every server. 4. Rewrite gateway and planning instructions and gateway descriptions. 5. Budget test.
