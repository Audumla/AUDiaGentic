# Keep and narrow foundation/observability — prevent universal domain model

## Description

The package has a legitimate role for generic timelines and operational records.
Component-specific event topics, dead letters, and domain records should remain component-owned.
Consolidate common append/redaction/atomic-write mechanics without creating a universal observability domain model.

Keep and narrow foundation/observability — it should NOT be a universal observability domain.

  - timeline.py::record_timeline_event(path, *, component, resource_kind, resource_id, event, state=None, attributes=None, ...) is a pure generic append-only JSONL writer -- component/resource_kind/resource_id/event are all caller-supplied strings, nothing is hardcoded to a specific domain.
