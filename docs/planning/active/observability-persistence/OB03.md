# Centralize cross-process locking through shared record store seam

## Description

Centralize cross-process locking later through the same seam.

Current locks are generally process-local. Multi-process lost updates remain a separate gateway/lifecycle concern.
The shared record store should allow a future revision/CAS or interprocess lock implementation to replace one mechanism instead of three.

## Steps
