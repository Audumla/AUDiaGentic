# Run every documented recipe and verify capability outputs

## Description

Execute each supported recipe through the public command line in a clean installed environment and validate its outputs against the recipe contract, provider/harness capabilities, and user documentation.

## Steps

1. Build a canonical recipe inventory and expected-output schema. 2. Map prerequisites and supported harness/component combinations. 3. Execute positive cases and documented unsupported cases. 4. Assert output content/placement and cleanup behavior. 5. Record discrepancies as linked reviews.

## Files

tests/docker; recipe descriptors; recipe and capability docs

## Validation

Data-driven Docker matrix proves each recipe either succeeds with contracted output or fails with the documented classified error.

## Effort & Risk

Avoid brittle golden snapshots; assert stable contracts and capability facts.
