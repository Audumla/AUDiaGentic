## Description

Prevent plan, item ID, and review ID inputs from escaping configured planning roots or being interpreted as glob patterns.

## Steps

- Reject separators, absolute paths, traversal, glob metacharacters, and invalid identities.
- Replace interpolated rglob lookups with exact identity lookup and assert write containment.
- Add adversarial traversal, wildcard, separator, and duplicate-identity tests.
