# Audit duplicated Pi/OpenCode materializers and consolidate

## Description

Audit duplicated Pi/OpenCode materializers across:
- runtime/harness/*/mcp_format.py
- Install config writers
- Provider MCP adapters
- Provider surface managers

These overlap conceptually. One generic foundation projection should select entries. Each provider should have one serializer/materializer implementation. Runtime should not carry a second version of provider config formatting.
