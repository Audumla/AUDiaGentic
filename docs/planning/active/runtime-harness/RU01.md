# Complete HA02 Pi ownership migration — move serialization to providers

## Description

The package still legitimately needs:

- Native harness resolution
- Installation and lifecycle composition
- Runner argument/environment construction
- Ephemeral runtime-root allocation
- Request cleanup
- Rig attachment where still supported

It should NOT own:

- MCP selection policy
- Provider serializers
- Provider capability declarations
- Model-source ownership
- Provider/project surface writers

Move remaining Pi provider serialization and config ownership to providers.
Keep only Pi runtime assets, lifecycle, and bounded upstream patch management under runtime.
Migrate install, refresh, and uninstall together.
Prove uninstall preserves models, logs, user assets, and unrelated provider config.
