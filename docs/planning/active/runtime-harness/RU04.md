# Retain narrow runtime harness layer — remove historical custom implementation

## Description

Retain a narrow runtime harness layer, not the historical custom harness implementation.

Package should own:
- Native harness resolution
- Installation and lifecycle composition
- Runner argument/environment construction
- Ephemeral runtime-root allocation
- Request cleanup
- Rig attachment where still supported

Should NOT own:
- MCP selection policy (foundation projection)
- Provider serializers (providers component)
- Provider capability declarations (providers component)
- Model-source ownership (providers component)
- Provider/project surface writers (providers/project)
