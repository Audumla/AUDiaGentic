## Description

It is a bounded exception to the no-compatibility-paths rule and must be removed once the release after the cutover has shipped.

## Steps

2. Delete ledger/legacy_runtime.py and its calls in sync.check_current_ledger and archive.archive_current_ledger; drop the migrated-legacy-events and legacy-left-in-place result keys.
3. Delete tests/unit/ledger/test_legacy_runtime.py and the Events an older layout left behind section of docs/guides/LEDGER_MIGRATION.md.
4. Run the ledger, release and architecture suites.
