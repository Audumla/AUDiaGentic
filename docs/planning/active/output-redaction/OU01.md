# Correct output redaction: undo the in-flight fan-out, enforce at egress boundaries only

## Description

Consolidate output/log/error sensitive-content detection behind one shared matcher. foundation/contracts/errors.py has a second _REDACT_PATTERNS/redact_details implementation that can drift.

## Steps

1. Inventory all pattern definitions/helpers, including errors.py.
2. Make foundation/logging/redaction.py or approved shared module the only matcher.
3. Route error-envelope details through it; keep shape/type filtering and truncation separate.
4. Route output/logging through same matcher with context policies, not copied regex.
5. Delete local patterns after equivalence/intentional-delta tests.
6. Add architecture guard against new local secret-pattern definitions.

## Detailed Solution & Technical Design

Separate sensitive-content detection from structural projection. Shared matcher returns a typed decision/replacement; logs, envelopes, and output retain their own allowed structures and bounds. Redaction never replaces output authorization or metadata allowlisting.
