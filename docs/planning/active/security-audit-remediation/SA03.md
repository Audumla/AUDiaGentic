# SA03 — Introduce packaged configuration policy and validator

## Description

Turn portable-config conventions into enforceable tests. Create a formal policy document and a recursive scanner that validates all packaged configuration against it. Based on SEC-03, SEC-04, SEC-17 from the security audit.

## Steps

1. Create `docs/standards/PACKAGED_CONFIG_POLICY.md` documenting allowed and forbidden content
2. Implement a recursive packaged-config scanner/validator test
3. Detect and reject:
   - Private IP literals (unless allowlisted as documentation examples)
   - `C:\Users\...`, `/home/<name>/...`, `/Users/<name>/...`
   - `/srv/...` and other deployment-specific paths
   - Credential-like values
   - Known machine names
   - Runtime timestamps and identifiers
   - GPU PCI addresses and device UUIDs
4. Add allowlist support with exact file/line scope, documented reason, owner, and expiry
5. Run against all package source config and built artifacts
6. Ensure the policy is linked from configuration READMEs

## Files

- `docs/standards/PACKAGED_CONFIG_POLICY.md` (new)
- `tests/security/test_packaged_config_portability.py` (new)

## Validation

- [ ] All packaged config passes the validator
- [ ] Injected private IP or home path fails the validator
- [ ] Synthetic examples and documentation ranges (`192.0.2.x`, `198.51.100.x`, `203.0.113.x`) pass
- [ ] Allowlist entries have exact scope, reason, owner, and expiry
- [ ] New packaged configuration cannot be added without passing portability validation

## Effort & Risk

Mid complexity. Requires writing a recursive file scanner and policy document. Low risk — tests only, no production code changes.

## Standards

- SEC-03 — Ambiguous ownership of `runtime/rig/embedded/models.json`
- SEC-04 — Packaged rig defaults require mechanical portability enforcement
- SEC-17 — Packaged configuration policy is documented but not executable

## Notes

This is a prerequisite for SA04 (rig model registry) and SA09 (harness templates). The scanner should be designed to be extensible as new patterns are discovered.
