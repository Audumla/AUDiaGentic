# SA07 — Enforce private runtime write roots

## Description

Prevent prompts, sessions, logs, runtime state, and generated config from being written into tracked source paths. Introduce a central private-runtime path authority. Based on SEC-12 from the security audit.

## Steps

1. Create a shared private-path authority module that validates all resolved paths are beneath an approved root
2. Define approved roots: `~/.audiagentic/`, `<project>/.audiagentic/`, platform-specific application data directory, test `tmp_path`
3. Define rejected destinations: `<repo>/src/`, `<repo>/docs/`, `<repo>/tests/fixtures/`, `<repo root>`, package installation directory, tracked project-policy directory
4. Add canonicalization and symlink escape protection
5. Migrate all persistent writers (sessions, logs, gateway, rig, providers) to use the shared authority
6. Support `tmp_path` in tests
7. Add architecture import/use guards to detect direct ad hoc runtime path construction
8. Add path traversal and symlink escape tests

## Files

- `src/audiagentic/foundation/path_authority.py` or equivalent (new)
- All persistent writer modules (sessions, logs, gateway, rig, providers)
- `tests/security/test_path_authority.py` (new)

## Validation

- [ ] All runtime writers use the shared path authority
- [ ] Path traversal and symlink escape tests pass
- [ ] No test writes runtime state into the checkout
- [ ] Architecture tests detect direct ad hoc runtime path construction
- [ ] Tests verify no prompts, sessions, or provider identifiers are written to tracked paths
- [ ] Package, source, docs, and repository-root destinations are rejected

## Effort & Risk

Complex. Requires migrating all persistent writers to use a new shared authority. Risk of breaking runtime persistence if not carefully tested. High value — prevents the most likely accidental leak vector.

## Standards

- SEC-12 — Runtime and session records need write-boundary enforcement
- SEC-22 — Generated MCP configuration must remain private
- SEC-23 — Generated model endpoint configuration must remain private

## Notes

This is the most important operational control from the audit. Every persistent writer must be audited and migrated. Coordinate with SA05 (SecretRef) and SA06 (redaction) for complete coverage.
