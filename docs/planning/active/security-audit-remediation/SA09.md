# SA09 — Audit and harden harness templates

## Description

Ensure packaged harness home trees are authored templates rather than local snapshots. Remove any caches, sessions, auth, and local-state files from packaged templates. Based on SEC-05 from the security audit.

## Steps

1. Inventory every packaged template under `src/audiagentic/runtime/harness/pi/templates/home/agent/`
2. Remove caches, sessions, auth, and local-state files
3. Replace local values with placeholders: `${AUDIAGENTIC_HOME}`, `${PROJECT_ROOT}`, `${MCP_ENDPOINT}`, `${MODEL_ID}`, `${PROVIDER_CONFIG_PATH}`, `${SECRET_REF}`
4. Add template-source immutability tests (generation does not modify source templates)
5. Scan built distributions to confirm no local identity or topology appears
6. Validate ownership markers in generated outputs (`MANAGED_BY_AUDIAGENTIC` or equivalent)
7. Ensure generation is one-directional (generated outputs never overwrite template sources)

## Files

- `src/audiagentic/runtime/harness/pi/templates/home/agent/` (various template files)
- `tests/security/test_harness_templates.py` (new)

## Validation

- [ ] No local identity or topology appears in any packaged template
- [ ] Generation is one-directional (source templates remain unchanged after generation)
- [ ] Package artifact scan passes (no caches, sessions, auth, or local-state files)
- [ ] Generated outputs include ownership marker
- [ ] Prune removes only owned generated files
- [ ] Templates contain placeholders rather than deployment values

## Effort & Risk

Mid complexity. Requires careful inventory and replacement. Low risk — templates are authored content.

## Standards

- SEC-05 — Harness home templates are a high-risk leak surface
