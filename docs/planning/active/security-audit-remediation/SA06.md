# SA06 — Expand structural and pattern redaction

## Description

Protect all logging, audit, event, error, and operational-record egress by expanding redaction coverage beyond basic regex patterns. Based on SEC-07 from the security audit.

## Steps

1. Implement recursive key-based structural redaction for sensitive field names before serialization:
   - `api_key`, `apikey`, `access_token`, `refresh_token`, `token`, `secret`
   - `client_secret`, `password`, `authorization`, `cookie`, `private_key`
2. Expand provider token pattern coverage:
   - `github_pat_*`, GitLab tokens, Anthropic tokens, OpenRouter tokens
   - Google API keys, Google service-account private keys
   - Azure subscription/OpenAI keys, AWS access/secret keys
   - JWTs, npm tokens, PyPI tokens, Slack tokens
   - Basic authentication, cookies, session tokens, query-string credentials
3. Ensure redaction works on nested dictionaries, arrays, dataclasses, exception details, and tool payloads
4. Apply redaction before serialization across: logging, events, gateway records, provider status, MCP results, planning extracts, and release ledger inputs
5. Add adversarial tests that attempt to smuggle secrets through redaction

## Files

- Redaction module in `src/audiagentic/foundation/` or equivalent
- `src/audiagentic/config/provisioning/foundation/logging.yaml`
- `tests/security/test_redaction.py` (new)

## Validation

- [ ] Nested and free-text secrets are removed across all egress boundaries
- [ ] Authorization headers are removed regardless of formatting
- [ ] JWTs and fine-grained GitHub tokens are detected
- [ ] Redaction occurs before records are persisted or emitted
- [ ] Tests verify raw values are absent from console logs, JSON logs, audit files, operational records, and exceptions returned across public boundaries
- [ ] Coverage exists for every supported provider family

## Effort & Risk

Mid complexity. Requires careful implementation to avoid breaking legitimate logging. Low risk — redaction is additive.

## Standards

- SEC-07 — Logging redaction coverage is incomplete

## Notes

SA05 (SecretRef) is recommended as a dependency. Implement structural redaction first (Stage 1), then pattern redaction (Stage 2) as described in the audit.
