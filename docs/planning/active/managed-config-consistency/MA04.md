# Normalize adapter writer contracts and atomicity

## Description

Normalize every durable managed provider config serializer behind the MO06 adapter protocol. Keep format-specific parse/render/merge extensions; eliminate raw managed writes/removals by using foundation atomic IO, enforce deterministic errors and unmanaged preservation, and keep lifecycle orchestration outside adapters.

## Steps

1. Build parameter table directly from MA01 non-runtime rows: Codex language_servers/MCP TOML; Continue MCP JSON; Goose MCP YAML; OpenCode MCP/LSP/plugin JSON; OpenHands MCP TOML; Qwen LSP JSON. Pi runtime serializer/patch rows remain MA07 deferred and do not block current MA04 completion. Record read/write/remove refs, container, atomicity, owner handler, and tests.
2. Pin protocol fixture: `read(path)->dict[str, Any]`; missing file returns {}; malformed/root-wrong raises canonical owning-component error; `write(path, entries)` atomically upserts; `remove(path,name)->bool`; unrelated keys/order semantics preserved where format supports them.
3. Add one parameterized contract suite driven by shipped provider managed-config declarations after MO06. Fixture supplies seed, desired entry, expected serialized container, unmanaged sentinel, and gateway-handler owner per adapter.
4. Convert every listed non-runtime raw managed write/remove to foundation atomic helpers. No direct path.write_text/unlink remains in managed adapter serializers or provider capability handlers.
5. Failure injection patches atomic replace/write boundary; original bytes remain. Malformed input never replaced by empty/default config.
6. Consolidate only byte/shape-equivalent implementations; preserve custom format behavior where required. Adapter modules cannot import reconcile/registry/status/feature lifecycle; generic core cannot import adapters by provider name.
7. Update MA01 audit actions to keep only after each site passes contract suite.

4. No lifecycle imports in adapters/handlers; no provider-name adapter imports in generic core.
5. Whole-repo duplicate proof recorded for consolidation; no speculative merges.
6. Focused provider config and MO06 MCP/LSP tests green.
