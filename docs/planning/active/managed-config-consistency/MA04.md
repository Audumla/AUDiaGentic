# Normalize adapter writer contracts and atomicity

## Description

Normalize every current provider config serializer behind the MO06 adapter protocol. Keep format-specific parse/render/merge extensions; enforce atomic writes, deterministic errors, unmanaged preservation, and zero lifecycle logic.

## Steps

1. Build parameter table directly from MA01 rows: codex language_servers/mcp TOML; Continue MCP JSON; Goose MCP YAML; OpenCode MCP/LSP/plugin JSON; OpenHands MCP TOML; Qwen LSP JSON; Pi serializer after MA07. Record read/write/remove refs, container, atomicity, and existing tests.
2. Pin protocol fixture: `read(path)->dict[str, Any]`; missing file returns {}; malformed/root-wrong raises canonical owning-component error; `write(path, entries)` atomically upserts; `remove(path,name)->bool`; unrelated keys/order semantics preserved where format supports them.
3. Add one parameterized contract suite driven by shipped ProviderDescriptor.managed_configs after MO06. Fixture supplies seed, desired entry, expected serialized container, and unmanaged sentinel per adapter.
4. Convert non-atomic sites named MA04 in MANAGED_MUTATION_AUDIT.md to foundation atomic helpers. No direct path.write_text remains in managed adapter serializers.
5. Failure injection patches atomic replace/write boundary; original bytes must remain intact. Malformed input never gets replaced by empty/default config.
6. Consolidate only byte/shape-equivalent implementations. Required proof before merge: identical seed→read, upsert bytes/structure, remove bytes/structure, and error semantics. Container/casing/comment differences stay custom.
7. Adapter modules cannot import reconcile, registry, status, feature enablement, reload, or recipe lifecycle. Generic core cannot import adapter modules by provider name.
8. Update MA01 audit actions to keep only after each site passes contract suite.

1. Every shipped managed config spec is parameterized or explicitly unsupported with reason/capability.
2. All adapters pass missing/malformed/upsert/idempotent-update/remove-present/remove-absent/unmanaged/failure-atomicity cases.
3. MA01 scan shows zero non-atomic `write_text` managed adapter rows.
4. No lifecycle imports in adapter serializers; no provider-name adapter imports in generic core.
5. Whole-repo duplicate proof recorded for every consolidation; no speculative merges.
6. Focused provider config tests and MO06 MCP/LSP tests green.
