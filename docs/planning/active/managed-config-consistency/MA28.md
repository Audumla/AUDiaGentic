# Migrate language-server projection recipe family

## Description

First MA08 slice. Replace Coding-LSP language-server apply/prune calls and reverse type imports with one MA20-conformant provider family.

## Steps

1. Characterize apply/prune callers and consumed results.
2. Freeze serializable entry payload, scope, result, and supported modes.
3. Remove provider imports of coding_lsp.LanguageServerEntry.
4. Implement definitions/registrations and managed adapter.
5. Migrate callers/tests and delete old entry points.
