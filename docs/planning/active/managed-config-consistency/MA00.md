DELEGATION PROTOCOL:
1. T3 agent freezes the contract for a slice FIRST (schema/record shape/request contract/adoption policy) and defines the goldens + architecture guards that verify it. No T1/T2 work on a slice before its contract and acceptance tests are pinned.
2. T1 agents run characterization/evidence/goldens/greps/conversions; T2 agents implement one bounded slice against the frozen contract. Acceptance = the pinned goldens/guards/suites green, nothing else.
3. HARD ESCALATION RULE: any ambiguity in adoption/ownership, public payloads, secret handling, or evidence interpretation → stop, record a plan review on the owning item, escalate to T3. Never guess (matches the evidence doctrine already in MO03/MO13/MO14).
4. Every delegated slice ends with a ledger event and an MA00 progress-note update; T3 reviews Block-boundary transitions (end of B, end of C) before the next block opens.
