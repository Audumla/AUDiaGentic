# Create user-verb-to-internal-mode translator for CLI and MCP command parsing

## Description

MA12 exposed a need: user-facing verbs ("install", "uninstall", "repair") must be translated to internal MA20 modes ("apply", "prune", "status"). Currently this is a hardcoded dict in provider_prompt.py. If more command handlers or MCP tools need this mapping, a shared translator would avoid duplication and ensure consistency.

## Steps

1. Identify all user-facing verb sources: CLI prompt commands, MCP tool parameter descriptions, any other user input that uses natural-language verbs.
2. Design a small, provider-blind translator: maps user verbs to MA20 mode names with error messages for unknown verbs.
3. Wire into provider_prompt.py and providers_mcp.py.
4. Add tests for known mappings and unknown verb handling.
