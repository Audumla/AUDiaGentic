# Replace universal public provider reconcile with explicit operations

## Description

Remove reconcile_provider/reconcile_all_providers from the cross-component public API and MCP surface after recovery handoff. Preserve useful internal lifecycle composition used by install/launch/refresh flows, and preserve all MO model/vendor/catalog operations.

## Steps

1. Inventory current public, MCP, CLI, launch, refresh, post-install, and test callers. 2. Replace MCP/public cross-component use with explicit resource and typed family operations, including current MO model inventory/catalog/vendor/apply tools. 3. Keep a private provider-owned lifecycle composition function for evidenced composition-root/command callers; do not expose a universal public request/result or recipe. 4. Require SH07 ownership-aware recovery before removing startup reconciliation behavior. 5. Migrate command/runtime callers to an approved narrow provider public command or composition-root registration as their layer requires. 6. Delete only obsolete public exports/MCP tools and dead wrappers; add stale-name and behavior parity tests.

## Files

providers_api public export cleanup; providers MCP declaration/adapter; provider-owned internal lifecycle composition; command/composition callers; tests. MO model source/catalog/vendor implementation is explicitly out of deletion scope.

## Validation

Universal reconcile is absent from providers_api and MCP. Explicit typed family/resource tools remain, including all MO model/vendor/catalog functionality. Useful install/launch/refresh lifecycle behavior remains behind a private provider-owned composition path or approved narrow command. SH07 recovery replaces blanket recovery before behavior is removed. No compatibility alias or universal recipe.

## Effort & Risk

Narrow architectural cleanup after SH07. Do not delete useful lifecycle orchestration, model management, or catalog behavior merely to remove a public façade.

## Standards

- Architecture Standards: Dependency Boundaries; Public Contracts and Safety; Enforcement.
- Architecture Guidelines: Provider Platform API; Migration Validation.

## Notes

Revalidated and narrowed 2026-07-18 by RV642. Current callers prove holistic internal reconcile behavior still has value; the defect is its universal cross-component/MCP exposure and internal imports from commands, not the existence of provider-owned composition. SH11 is relevant only to gateway ownership; SH07 remains the hard recovery gate. MO code must not be removed.
