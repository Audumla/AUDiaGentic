# Keep foundation/system from becoming a utilities bucket

## Description

Keep foundation/system from becoming a utilities bucket.

It should own process and host mechanics:
- Process control
- Managed services
- Ownership and readiness
- Platform probes

It should NOT absorb generic file I/O, clocks, CLI presentation, registries, or templates merely to empty the foundation root.
