# Test real installation instead of pre-baked hosts in Docker

## Description

Base images should contain only language/runtime prerequisites (Python, Node.js, etc.).
AUDiaGentic should install supported harnesses and generate their configuration during the test.

Performance images may layer cached dependencies, but must be clearly separated from clean-install proof.
Do not allow a preinstalled harness to turn an installation test into a configuration-only test.

## Steps

['Audit base images — verify they only contain language/runtime prerequisites', 'Remove preinstalled harnesses from base images', 'Ensure AUDiaGentic installs harnesses during test, not before', 'Separate performance images (with cached deps) from clean-install proof images', 'Document the separation clearly']
