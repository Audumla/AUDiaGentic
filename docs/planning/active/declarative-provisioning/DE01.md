# Cut over Hindsight provider integrations to recipe orchestration; retire the Python family-loop

## Description

Replace the hand-rolled Python family-dispatch in reconcile_hindsight (components/memory/hindsight/provision.py) with declarative recipes that compose the managed-* steps (managed-mcp/managed-hooks/managed-plugin, built and proven this session) plus the owned-artifact steps (download/config-set). Every provider's Hindsight integration becomes ONE recipe; capability-driven family selection stays but now picks a RECIPE instead of a Python function. Goal is explicitly to DELETE the old dispatch code once each family path is on recipes.

Enabling mechanism already landed: registry-driven step schemas (foundation/steps/factory step_schema + register_step_type(schema=,accepts_params=)); slim envelope schema (config/recipes/declarative-recipe.schema.json); recipe_loader per-step fragment validation; provider-layer managed-mcp/hooks/plugin steps in components/providers/services/recipe_steps.py, self-registered on providers import, self-reverting, ownership-scoped. This item CONSUMES that to remove provision.py's family-loop.

## Detailed Solution & Technical Design

VERIFIED FACTS (checked live against the tree — no guesswork left for the executor):

- execute_recipe_mode(path, params: dict[str,str], mode, context: dict|None) exists; managed-* steps read context['project_root'] and raise ValueError without it.
- describe_provider(root, pid) returns {..., 'config_surfaces': [ {'kind','configured','format','refresh_mode','capabilities': list[str], 'resolved_path','path_scope'}, ... ]}. The mcp surface is the entry with kind=='mcp'.
- capabilities is a LIST OF STRINGS. 'remote' present => url-form supported; absent => stdio-only. Verified live: claude capabilities==['remote']; goose capabilities==[]. Constant REMOTE_CAPABILITY=='remote'.
- hindsight_ownership_scope(backend) == f'memory/hindsight/{backend.server_name}' (mcp_recipe.py:45). The scope is NAMESPACED per server, not a constant.
- CURRENT OWNERSHIP SCOPE STATE (RV834, code-verified):
  - managed-mcp: uses `hindsight_ownership_scope(backend)` → `memory/hindsight/{server_name}` (consistent for apply/prune/status)
  - managed-hooks: uses `_HINDSIGHT_OWNERSHIP = "hindsight"` (bare, consistent)
  - managed-plugin: _apply_plugin uses `hindsight_ownership_scope(backend)` (namespaced) but _prune_plugin uses `"hindsight"` (bare) — **latent orphaning bug**: apply and prune disagree
- HINDSIGHT_MANAGED_ID=='ag-hindsight'; backend.mcp_url == base_url + '/mcp'; backend.headers() == {'Authorization': 'Bearer <key>', 'X-Bank-Id': <bank>} (only present keys).

SCOPE STANDARDIZATION (user-confirmed): All families migrate to namespaced scope `memory/hindsight/{server_name}`. This is the managed-mcp standard; hooks and plugins adopt it. The cutover includes a migration step that transfers existing registrations from bare `"hindsight"` → namespaced.

DESIGN (deterministic; one recipe per provider integration):

- Providers WITH Hindsight-owned artifacts keep a provider-specific FULL recipe (in the existing _ARTIFACT_RECIPES map): codex -> hindsight-codex.yaml (managed-hooks step + script download + codex.json), pi -> hindsight-pi.yaml (managed-mcp step + host block). This map IS the 'compound' override set — no new provider-id branches.
- Every OTHER provider resolves its family and runs a GENERIC family recipe: managed-mcp -> hindsight-managed-mcp.yaml (url) or hindsight-managed-mcp-stdio.yaml (command), chosen by whether 'remote' is in the mcp surface capabilities; plugin-entry -> hindsight-plugin.yaml; no family -> guidance-only (no recipe).
- reconcile calls one helper per provider: _resolve_recipe(pid, root, backend) -> (recipe_path | None, params) which fully encapsulates the family/transport/param logic. The three reconcile loops keep their structure and_combine_summary; only the family+artifact calls are replaced by a single recipe run. Delete the Python family functions once green.

PREREQ (tiny, include here): the managed-mcp step builder should drop header entries whose value is '' after substitution (so an open-auth local backend does not emit an empty Authorization header). One line in _build_managed_mcp in recipe_steps.py.

=== LAYER 1: _resolve_recipe returns recipe-level params (template vars) ===

# These are the PARAMS dict passed to execute_recipe_mode. They substitute into

# the YAML template {PLACEHOLDER} before step builders see them

from audiagentic.components.providers.providers_api import describe_provider
from audiagentic.components.memory.hindsight.mcp_recipe import hindsight_ownership_scope

_GENERIC_MCP = "hindsight-managed-mcp.yaml"
_GENERIC_MCP_STDIO = "hindsight-managed-mcp-stdio.yaml"
_PLUGIN = "hindsight-plugin.yaml"

def _mcp_surface(pid, root):
    for s in describe_provider(root, pid).get("config_surfaces", []):
        if s.get("kind") == "mcp":
            return s
    return {}

def _resolve_recipe(pid, root, backend):
    scope = hindsight_ownership_scope(backend)          # 'memory/hindsight/{server_name}'
    base = {"PROVIDER": pid, "OWNERSHIP_SCOPE": scope, "BANK_ID": backend.bank_id or ""}
    if pid in _ARTIFACT_RECIPES:                          # compound: codex/pi full recipe
        params = {"URL": backend.base_url, "MCP_URL": backend.mcp_url,
                  "AUTH": backend.headers().get("Authorization", ""),
                  "TOKEN": backend.api_key or "", **base}
        return _RECIPE_DIR / _ARTIFACT_RECIPES[pid], params
    family = _resolve_family(pid, _provider_capability_map())
    if family == "managed-mcp":
        if "remote" in_mcp_surface(pid, root).get("capabilities", []):
            return_RECIPE_DIR /_GENERIC_MCP, {"MCP_URL": backend.mcp_url,
                     "AUTH": backend.headers().get("Authorization", ""),**base}
        return_RECIPE_DIR /_GENERIC_MCP_STDIO, {"BASE_URL": backend.base_url, **base}
    if family == "plugin-entry":
        return _RECIPE_DIR / _PLUGIN, base
    return None, {}

def _run_recipe(pid, root, backend, mode):
    path, params = _resolve_recipe(pid, root, backend)
    if path is None:
        return None
    declared = {p.name for p in load_recipe_from_yaml(path).parameters}
    return execute_recipe_mode(path, {k: v for k, v in params.items() if k in declared},
                               mode, context={"project_root": str(root)})
