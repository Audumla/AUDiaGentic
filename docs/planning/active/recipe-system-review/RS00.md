# Recipe system review inventory and implementation map

## Description

Inventory the recipe codebase and dependants covered by this review. This item exists so smaller implementation agents have a single map of what was considered, what must not be duplicated, and which RS item owns each cleanup area.

## Code considered

### Foundation recipe core

- `src/audiagentic/foundation/toolchains/recipe_contract.py` — `RecipeState`, `RecipeResult`, `ProvisioningRecipe`, `run_steps`, default `provision()`, `teardown()`, cleanup hooks.
- `src/audiagentic/foundation/toolchains/recipe_patterns.py` — `NoAutomationRecipe`, `InstallManifest`, `DeclaredStepRecipe`. Also records that `ManagedEntryRecipe` / `ConfigEntryTarget` were removed and should not be resurrected without real consumers.
- `src/audiagentic/foundation/toolchains/artifact_registry.py` — ownership sidecar, prune, dry-run, missing-artifact tolerance.
- `src/audiagentic/foundation/toolchains/config_patcher.py` — structured config key changes used by `ConfigSetStep`.
- `src/audiagentic/foundation/toolchains/managed_block.py` — managed text block changes used by `ManagedBlockStep`.
- `src/audiagentic/foundation/toolchains/fragments.py` — generic fragment reconciler used by managed MCP/config sync and managed-block style updates.
- `src/audiagentic/foundation/toolchains/probes.py` and `detect.py` — command probing and platform/source gates used by declared-step recipes.

### Foundation provisioning steps

- `src/audiagentic/foundation/toolchains/provision_steps/__init__.py` — step package imports and registry population.
- `src/audiagentic/foundation/toolchains/provision_steps/base.py` — `ProvisionStep`, step-type registry, strict `_substitute()`.
- `src/audiagentic/foundation/toolchains/provision_steps/factory.py` — `provision_step_from_dict`, `steps_from_defs`, lenient `substitute_params()`.
- `src/audiagentic/foundation/toolchains/provision_steps/sequence.py` — `CompensatingSequence`, rollback and dry-run status rules, including `outputs["steps"]` / `per_step` propagation into recipe details.
- `src/audiagentic/foundation/toolchains/provision_steps/shell.py` — `ShellProvisionStep`, stdout capture, command rendering.
- `src/audiagentic/foundation/toolchains/provision_steps/config_set.py` — structured config mutation step.
- `src/audiagentic/foundation/toolchains/provision_steps/managed_block_step.py` — managed text block step.
- `src/audiagentic/foundation/toolchains/provision_steps/write_file.py` — file write step.

### Provider recipe layer

- `src/audiagentic/components/providers/services/recipes.py` — `ProviderRecipeKind`, `ProviderRecipeResult`, `ProviderCapabilityRecipe`, `_stamped()`, `ProviderRecipeRegistry` status/install/uninstall/dry_run/repair.
- `src/audiagentic/components/providers/services/mcp.py` — existing managed MCP sync target used by Hindsight recipes.
- `src/audiagentic/components/providers/services/reconcile.py` and `status.py` — dependant surfaces that may need model/recipe status integration or should not duplicate recipe status.

### Hindsight dependants

- `src/audiagentic/components/memory/hindsight/matrix.py` — YAML-backed recipe matrix and row schema.
- `src/audiagentic/config/components/memory/hindsight_matrix.yaml` — data source for Hindsight recipe rows.
- `src/audiagentic/components/memory/hindsight/recipe_spec.py` — config-driven assembly for `no_automation` and `declared_step` patterns.
- `src/audiagentic/components/memory/hindsight/recipes.py` — `_RowRecipe`, `_McpConfigAdapter`, shared Hindsight parameters, managed MCP sync helper.
- `src/audiagentic/components/memory/hindsight/plugin_recipes.py` — plugin URL config, plugin array config, installer gates, direct writes, Windows repair.
- `src/audiagentic/components/memory/hindsight/strategies.py` — recipe strategy selection and factory dispatch.
- `src/audiagentic/components/memory/hindsight/lifecycle.py` — register/provision/teardown/prune entry-points, including no-backend fallback spec and direct fallback result construction.
- `src/audiagentic/components/memory/hindsight/provision.py` — user-facing provisioning entry-point that registers recipes and drives registry install/uninstall paths.
- `src/audiagentic/components/memory/hindsight/status.py` — status-report surface that invokes recipe probes and aggregates action-needed details.
- `src/audiagentic/components/memory/hindsight/mcp_recipe.py` and `export.py` — backend payloads consumed by recipes.

### Standards considered

- `docs/standards/ARCHITECTURE_STANDARDS.md` — layer boundaries, config-over-code, logic containment, platform independence, error handling, logging, migration doctrine, lazy initialization.
- `docs/standards/CREATING_A_COMPONENT.md` — ownership boundary: capability components own generic truth; providers own downstream rendering/config.
- `docs/standards/OBSERVABILITY_STANDARDS.md` — durable timeline and redaction expectations.

## Review incorporation

- RV218 validated against current code. Inventory now includes `fragments.py`, `CompensatingSequence` output propagation, Hindsight lifecycle/provision/status entry-points, duplicated no-backend guidance specs, and the `_PluginArrayRecipe` `resolve_ref` dispatch seam.
- `_NO_BACKEND_GUIDANCE_SPEC` in `hindsight/lifecycle.py` and `_GUIDANCE_SPEC` in `hindsight/strategies.py` must stay synchronized until RS12/RS19 either consolidate or guard the duplication.

## Implementation sequencing

1. RS07 first or alongside RS01 to create guardrails.
2. RS01 next to lock recipe contract semantics.
3. RS02 after RS01, because provider result stamping depends on base conversion guarantees.
4. RS04 and RS05 can run independently once RS07 exists.
5. RS03 and RS06 last, after helpers and tests are stable.

## Non-goals

- Do not merge `ShellProvisionStep` with workflow `ShellStep`; provisioning rollback and workflow interaction are separate concerns.
- Do not resurrect `ManagedEntryRecipe` unless at least two real consumers require it and standards justify the foundation addition.
- Do not move Hindsight matrix semantics into foundation.
- Do not move provider-specific rendering into Hindsight or generic recipe code.
