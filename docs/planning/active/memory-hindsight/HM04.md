# Native installer recipes (command-driven) per harness

## Description

Populate the per-provider declarative HindsightSpec values for the native-installer and launch-wrapper providers (claude, codex, opencode, cline, aider). No bespoke Python recipe per provider — just spec data consumed by the HM03 builder. Validate against the live behavior in Docker.
