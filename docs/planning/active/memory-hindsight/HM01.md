# Backend config + provider-agnostic export contract

## Description

Memory exposes a provider-agnostic Hindsight backend descriptor that the contained Hindsight implementation consumes. Memory core owns ONLY backend identity; it names no providers and writes no provider paths.

## Steps

['hindsight.yaml options-schema: base-url (string, required), api-key (string, optional), bank-id (string, optional), transport (enum http|sse, default http).', 'Add dataclass in memory/hindsight_export.py: @dataclass(frozen=True) class HindsightBackendConfig{ base_url:str; api_key:str|None; bank_id:str|None; transport:str; timeout_seconds:int; server_name:str="hindsight" } with property mcp_url and method headers()->dict[str,str] (Authorization: Bearer <api-key> if set; X-Bank-Id: <bank-id> if set).', 'Add build_hindsight_backend(project_root:Path)->HindsightBackendConfig|None: read active impl options via feature state; mcp_url = base-url.rstrip(/)+"/mcp"; return None when base-url empty/unset.', 'Export HindsightBackendConfig + build_hindsight_backend only. No deprecated alias, no compatibility shim, and no provider-specific fields.']
