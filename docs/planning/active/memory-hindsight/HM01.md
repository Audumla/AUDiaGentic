# Backend config + provider-agnostic export contract

## Description

Memory exposes a provider-agnostic Hindsight backend descriptor that providers consume. Memory owns ONLY backend identity; it names no providers and writes no provider paths (HI03 boundary).

## Steps

['hindsight.yaml options-schema: base-url (string, required), api-key (string, optional), bank-id (string, optional), transport (enum http|sse, default http).', 'Add dataclass in memory_api.py: @dataclass(frozen=True) class HindsightBackend{ mcp_url:str; api_key:str|None; bank_id:str|None; transport:str; server_name:str="hindsight" } with method headers()->dict[str,str] (Authorization: Bearer <api-key> if set; X-Bank-Id: <bank-id> if set).', 'Add build_hindsight_backend(project_root:Path)->HindsightBackend|None: read active impl options via existing _active_implementation_id + get_implementation_state; mcp_url = base-url.rstrip(/)+"/mcp"; return None when base-url empty/unset.', 'Export HindsightBackend + build_hindsight_backend in memory_api __all__/module surface for providers to import.']
