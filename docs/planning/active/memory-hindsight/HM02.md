# Remote (HTTP/SSE url) MCP server entry support

## Description

McpServerEntry is stdio-only (command/args/env) and cannot represent Hindsight's remote HTTP MCP server. Extend the canonical type with remote fields and teach the JSON/YAML/TOML writers to emit it. Codex and OpenCode use native installers (not mcp-config) so their writers are out of scope here; the writers that matter are the mcp-config-strategy formats.
