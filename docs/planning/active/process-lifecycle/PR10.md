# Recipe-manage OpenCode CLI installation and explicit upgrades

## Description

Converge the OpenCode CLI onto the generic provider CLI recipe lifecycle: descriptor-declared package-manager install, read-only upgrade status, explicit upgrade, version/provenance reporting, and lifecycle-facing public capability operations. Reuse the generic CLI workflow and package-manager declarations; do not create an OpenCode-only installer.

## Steps

- Extend the descriptor CLI recipe contract and workflow action model with optional explicit package-manager upgrade support.
- Declare npm upgrade semantics once in the generic toolchain catalogue and enable it for OpenCode's descriptor.
- Expose plan/status/upgrade through the existing provider capability/lifecycle seams; retain install/uninstall behavior.
- Add unit tests for descriptor loading, planning, status, successful/failing upgrade workflow, and OpenCode declaration.
- Add a Docker-gated real OpenCode upgrade verification where safe; otherwise prove command materialization and documented version probe behavior.
