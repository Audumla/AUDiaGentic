# VS Code extensions.json recommendations (A30)

## Open Item — Optional

When a provider declares `host_capabilities` for the `vscode` host, generate `.vscode/extensions.json` so VS Code surfaces 'Install Recommended Extensions' automatically. Read `package.json` from installed extensions for version/metadata.
