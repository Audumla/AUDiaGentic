# Add optional version pinning to external dependencies

## Description

The `source-control` component declares platform-specific installers but never pins versions. A package manager update could install an incompatible version.

## Proposed Solution

Add an optional `version` field to dependency declarations with semver constraints. The dependency installer checks the installed version and warns if unsatisfied.
