# Derive harness instructions from MCP server declarations

## Description

Each component declares instructions for both MCP servers and harness. These are semantically similar but expressed differently, creating a drift risk.

## Proposed Solution

Derive `harness-instructions` from MCP server declarations automatically. The harness instruction renderer reads `direct-tools` and `tool-descriptions` from MCP server declarations. Add a validation check that flags drift.
