# Shard feature state by component

## Description

All features and implementations share `.audiagentic/config/runtime/features.yaml`. Every mutation acquires the same file lock, creating contention as components grow.

## Proposed Solution

Shard state by component: `.audiagentic/config/runtime/features/{parent}.yaml`. Each component gets its own lock file. Add a lightweight index file for discovery. Backward migration: detect legacy monolithic file and migrate on first write.
