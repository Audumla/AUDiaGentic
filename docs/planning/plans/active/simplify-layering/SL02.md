# Feature descriptor type dispatch is string-based

## Description

The loader dispatches on `type` string (`feature`, `implementation`, `binding`). A typo silently falls through to `VAL-FDESC-012`. No compile-time or schema-level enforcement.

## Proposed Solution

Define an enum `DescriptorType { FEATURE, IMPLEMENTATION, BINDING }` and parse the YAML `type` field into it during loading. Reject unknown values immediately with a specific error code rather than falling through to a generic 'unsupported type' error.

## Effort & Risk

Effort: Low. Risk if unchanged: Minor robustness improvement.
