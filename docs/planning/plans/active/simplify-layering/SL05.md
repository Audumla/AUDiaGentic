# Type the contributions schema

## Description

The `contributions` field in component YAML is a raw list of dicts with no typed schema. Fields like `preferred-targets`, `config:`, and `content:` have implicit contracts. No validation that `preferred-targets` values are valid surface types.

## Proposed Solution

Define a `ContributionDescriptor` dataclass with typed fields: `id`, `owner`, `kind` (enum), `title`, `preferred_targets` (validated), `content` (union: inline or config ref), `skill_content_file`. Add post-load validation for surface types and config references.
