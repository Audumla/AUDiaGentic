# A30 (optional) — VS Code .vscode/extensions.json recommendations

## Description

Provider-declared VS Code extensions are tracked internally but not surfaced to VS Code. No version/metadata from installed extensions.

## Steps

Generate `.vscode/extensions.json` during reconcile/install/uninstall. Derived from enabled providers' `host_capabilities` with `host == 'vscode'`. Read `package.json` from `~/.vscode/extensions/<ext>/` for version/metadata.
