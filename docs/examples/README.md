# Examples and fixtures

This area contains example project material and contract fixtures. Begin with
the [fixture rules](fixtures/readme.md) before using files as test inputs.

Examples are not automatically production configuration. A fixture marked
`valid` is expected to satisfy its schema or consumer contract; a fixture
marked `invalid` intentionally exercises rejection behavior. Sample and
historical files are illustrative and are labelled accordingly.

When a schema or public contract changes, update the canonical source, its
valid/invalid examples, and the consuming validation tests together.
